## 1. 核心认知（先看这一节）

- **想继续听的话，节目后面重点讲的是 Palantir 那套数据监控逻辑，以及第三位哲学家的具体主张，这块是理解 “硅谷右翼” 最关键的一环**（2026-04）
- **这是《硅谷 101》主持人泓君与前沿科技投资人郑迪的一段对谈，核心观点是：OpenAI 必须上市，而且最好赶在 2027 年之前、也就是 2026 年完成，因为明年上半年可能是最好的窗口，下半年则要看中期选举的脸色**（2025-11）
- **他的逻辑是：在任务极难、结果不确定时，无法精确评估最强模型和第二强模型的差距，benchmark 又容易刷榜，所以最优策略就是永远选最好的模型**（2026-08）
- **核心结论一句话：作者认为它火不是因为记忆系统做得最好，而是因为它把记忆的价值变成了用户能感知到的主动性**（2026-02）
- **核心观点是：2025 年 Agent 之所以突然加速，关键不在 “会聊天”，而在模型开始能在环境里通过强化学习自主试错、调整策略，也就是作者所说的 “大语言模型的 AlphaGo 时刻”**（2025-05）
- **他举 TikTok 为例：川普第一任期要下架它，最终没成，很大程度因为它在当地有大量网红，形成了生态**（2026-01）
- **为什么社交比技能更抗替代 他的判断是：当其他技能逐渐 “褪色”、不再稀缺时，建立信任、说服他人的能力反而更关键，因为它决定了你到新环境后能最大化拿到多少东西**（2026-05）
- **为什么还做自动驾驶：他说 “因为看见所以相信”，七年里最宝贵的是 “不变性”—— 技术管理能力和行业的必然趋势，而不是每年换一个流行语的 “wantrepreneur”**（2025-05）
- **技术方向是生死线：智能体系统成本很高，很多 AI 公司的痛点是 “融了钱、增长越快、死得越快”，因为增长是入不敷出的，下一轮给投资人看毛利是负 50%，对方第一反应就是 “你什么时候能转正”**（2025-08）

1. 好的乙方则端到端承接整条流程，在关键节点主动介入、给决策建议，最后交付成品而非半成品（2025-06）

3. 最后他补了一个体验逻辑：味觉是最后才体验到的环节，气味和视觉在体感链条上更靠前，所以对吃饭这件事，气味和视觉可能比好不好吃更重要（2025-11）
4. DeepMind 的项目优先级是：强化学习通向 AGI 排第一，向人脑学习排第二，从数据中归纳排第三（2026-03）
5. 视频最后那句 “这些东西在二级市场上都是财富密码”，是访谈者的调侃式总结，指向的是上游供应链公司的行情，不是投资建议（2026-03）

7. 关键公式：温度的四次方 散热用黑体辐射（斯特藩 - 玻尔兹曼定律）计算，最要命的一点是散热功率与绝对温度的四次方成正比（2026-06）
8. 他的建议是：先利用市场已有的共识（比如 “强化学习 Agent 有未来”），再在共识之上加一个逻辑飞跃，说清楚两件事：你要解决的问题为什么有意义，以及你凭什么有 “不公平的优势”（2025-08）
9. 分化是必然的：这些公司最后会像早期的 MySQL、OpenAI、Anthropic 一样，走向不同的专注领域，因为创始人不同，决策自然不同（2025-08）

## 4. 关键零散结论

- 几位嘉宾的结论一致 ——不是必须，但对 Apple 生态用户几乎是第一选择
- 比喻成流水线：第一个人取菜，第二个人加工中间结果再传给第三个人，像心脏泵血一样逐级传递，中间省掉大量调度和调控，每个计算单元的使用率更高
- 第三代之后：Amylin 与保肌 罗氏与 Zealand 在 2025 年 3 月达成合作，潜在金额最高 53 亿美元、预付款 16.5 亿美元，开发基于 Amylin（胰岛分泌的多肽）的管线
- 鼎泰丰：美国单店年营收约 2740 万美元，据节目说法位列全美连锁餐厅单店第一，是第二名一家高端牛排馆的两倍
- 结论是专家被 AI 的泛化建议拖累，新手反而受益最大
- 结论是：这不只是 “开源好还是闭源好” 的立场之争，而是结构层面的变化—— 卖算力的、卖 API 的、卖云和流量的，各自的最优解不同，利益越来越难对齐
- 不会 “熟能生巧”：同一件事第一次一小时、第二次 45 分钟，之后就一直卡在 45 分钟，不像人或小模型那样越练越快
- 孩子第一遍写跑题了，第二遍靠 AI 查的素材写成，姥姥特别有成就感
- 评论区多是玩梗，比如用修仙小说 "练气期升筑基期" 调侃抗衰，也有人提到 "日本抗衰走在世界前列"、建议体测年龄 26 岁的人去参赛 —— 这些都属于网友个人说法，不是节目结论
- 视频里提到的 “2025 年 6 月后形势逆转、Gemini 在各测评榜表现最好” 属于嘉宾当时的判断，AI 竞赛本身是 “各领风骚三五个月”，不宜当作定论
- AI 能做 90% 的事，但 “你的想法必须人来做”，做了这部分，成本照样降下来了，观众也看到了最真的东西
- 他刻意避开证券法、国际仲裁这类记忆型课程，去上西方法律思想史、法理学和《第一哲学沉思录》，认为批判性思维这类 “元能力” 难以被替代
- 去年 11 月起用最强模型从零构建分布式数据库 DBNine，日账单曾达四五千美金（在 Claude Code Pro Max 订阅额度用尽后额外付费），但一人三个月做出千万美金级销售额的产品，认为 ROI 极高
- 第一阶段：从单 Agent 到 Agent 群组 嘉宾描述自己的演进路径：从自己搭 Agent 框架，到 OpenClaw、Hermes、Slock 这类工具
- 现场最真实的一幕：四位嘉宾里只有一位真用过 主持人开场就问 “大家真的开始用 Agent 交易了吗”，结果韩歆毅是唯一一个实际下过单的 —— 他上周用 “阿福” 买了坚果、海苔等健康零食，花了 40 多元
- 她还转述姥姥的说法：班里很多爷爷奶奶在学，学 AI 可能成为老年人摆脱老年痴呆的一种方法—— 这是投稿者的推测，不是医学结论
- 三代演化：从降糖到减重 郭霆把 GLP-1 类药物的历史分成三代：第一代半衰期极短、一天要打多针
- 第二代通过化学修饰做成一周一针的长效版（如利拉鲁肽），但减重只有约 5%，FDA 虽已批准减肥适应症，却不足以成为现象级产品
