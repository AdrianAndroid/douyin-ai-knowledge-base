## 步骤 1 · 素材抽取（规则化，可复现）

脚本：`tmp/教程素材/extract.py`
输入：`抖音关注/<作者>/*.md`；输出：`tmp/教程素材/<作者>.json`

抽取逻辑：

1. `clean_body()` 去 YAML 头、`# 标题`、`> 作者/抖音号/作品ID/标签` 元信息行、分隔线，只留 AI 文案正文。
2. `sentences()` 按 `。！？\n；` 切句，保留 12–110 字的片段（过短无信息、过长含冗余）。
3. `score()` 打分：
   - 含「核心/本质/关键/必须/记住/方法/步骤/误区/不要/错误/建议/原则/公式/技巧/逻辑/框架/结论/真相/规律/第一/第二/第三/千万/唯一/三种/四个」→ +2
   - 含数字 → +1；含「首先/然后/接着/最后」→ +1
   - 「我」「你」合计 ≥3 次 → −1（口语废话多）；长度 <18 → −1
4. 按分数降序、去重（`md5` of 去标点文本），每人保留 ≤120 条。
5. 另统计：题材词频（24 个词表，按「涉及篇数」不按出现次数）、工具词频（50 个工具名，同样按篇数）、代表作（时间倒序 30 条）。

**为什么按涉及篇数而非出现次数**：沿用在 A 档分析中的修正——按出现次数会把「Agent」算成 6,016 次而虚高，篇数口径更能反映「这个话题占多少内容」。

产出校验：49 个 json，`parsed` 合计 **11,554**，与步骤 0 的 md 数一致。

## 步骤 2 · 骨架生成

脚本：`tmp/教程草稿/build_v2.py` → `教程/NNN-<作者>.md`

分章规则（自动）：

| 章 | 规则 |
|---|---|
| 0 数据底账 | 篇数 / 字数 / 时间跨度 / 题材分布 / 高频工具 |
| 1 核心认知 | 命中「本质/核心/关键/原理/因为/所以/取决于/前提」的句子，上限 14 条 |
| 2 实操方法 | 命中「步骤/先/然后/接着/最后/配置/搭建/实现/模板/公式」的句子，上限 14 条，编号排列 |
| 3 常见误区 | 命中「不要/误区/错误/坑/避免/千万别」的句子，上限 10 条，前缀 ✗ |
| 4 关键零散结论 | 其余高分句，上限 18 条 |
| 5 学完怎么用 | **人工补写**（见步骤 3） |
| 6 代表作 | 最近 14 篇，标题 + 相对链接直达原文 |
| 7 使用说明与局限 | 自动声明「规则抽取 + 未逐篇精读 + AI 文案已是二手总结」 |

清洗：`tidy()` 去掉句首连接词（所以/但是/其实/而且/另外/那么/因此/总之/也就是说/说白了），避免每条都以废话开头。

## 步骤 3 · 人工判断（这部分不做自动化）

自动分章只能给出「句子」，给不出「这是什么号、值不值得学、按什么顺序学」。因此对 49 位逐一手写两段：

- **作者定位**：体裁（口播/访谈/教程/整活）、信息源质量、干货密度、价值档判断（A/B/C/D）、**主要风险**（时效性、立场倾向、成功者偏差、幸存者偏差）。
- **学习路径**：3-5 步，每步指向具体章节或具体标题，不写「认真阅读」这类空话。

判断依据：每位作者的题材分布、工具词频、代表作标题、Top 20 摘要句（一次性输出 294 行供横向对比）。

- 按**用途**分六组（而不是按篇数排序），因为「学东西」和「查热度」是两个需求：

## 步骤 5 · 校验

1. 篇数一致性：素材包 `parsed` 合计 11,554 = 目录 md 数 11,554。
2. TODO 残留：`grep -l "TODO:" 教程/*.md` → 0。
3. 相对链接：逐个解析教程内 `../抖音关注/...`、`../作者/...` 链接，URL-decode 后与目标路径比对 → 全部有效（见提交时校验输出）。
4. 文件命名：`NNN-<作者名>.md`，NNN 按篇数降序，与索引表一致。

## 已知局限（写进每份教程的「7」节）

1. **未逐篇精读**：结论来自规则抽取的结论句，可能错过正文中段的完整方法论。
2. **AI 文案是二手总结**：原视频的操作细节（参数、界面、口播补充）在文案里已被压缩，需回原文。
3. **打分有偏**：含「核心/关键」等词的句子得分高，可能高估标题党式表述，低估平铺直叙的干货。
4. **时效**：AI 类作者的工具结论按 2026-11 前状态，模型迭代快，超过 3 个月需复核。
5. **情感类价值观**：只做内容归纳，不代表认可其主张；涉及两性内容均加了「勿物化/勿操控」的阅读提示。

## 复跑方式

```bash
python3 tmp/教程素材/extract.py        # 1. 重算素材（约 1 分钟）
python3 tmp/教程草稿/build_v2.py       # 2. 重生成骨架（会覆盖 TODO 段）
python3 tmp/教程草稿/inject.py         # 3. 注入定位与学习路径
python3 tmp/教程草稿/build_index.py    # 4. 重建总索引
```

增量更新（新视频 / 新关注作者）：先按 `作者价值分类与后续分析计划.md` 第六章补提数据，再复跑以上四步即可，`inject.py` 里按作者序号存放文案，新作者需补一条 `W[n]`。
