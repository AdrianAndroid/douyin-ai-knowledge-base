## 怎么用这套教程

1. 先按需求选组，不要按序号顺序读。
2. 每组挑 1-2 位，先读「1 核心认知」和「5 学完怎么用」，10 分钟判断值不值得深读。
3. 值得深读的读「2 实操方法」并动手；「6 代表作」是回原文的出口。
4. 每条结论带（年-月），技术类超过 3 个月要复核。
