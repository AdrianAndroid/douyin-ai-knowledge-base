### 学习方法/认知

- [2026-09] 核心方法是一套四步讲项目公式，并用自家开源项目 Idea2Paper 完整演示了一遍
- [2026-01] AI 学习路线图定制：输入当前水平、核心目标、每天可投入时间，生成分阶段学习计划，每阶段配作业和实战项目，并整理免费资源，最后输出一个可分享的专属网站
- [2026-07] 所以真正的难点不在 “多”，而在交接处的信息是否完整、审查环节是否真的能拦住错误 —— 少了审查和记忆回写，多角色反而会放大错误
- [2026-09] 回答思路包括定调问题本质、拆开消耗来源、展开优化方法、强调架构顺序
- [2026-07] 想深入的话，可以接着聊 “审查不通过后怎么回写记忆、再触发重新规划” 这条闭环，这是面试里最容易追问的地方
- [2026-08] 视频结尾预告下期会拆解 “从 0 到 1 的四个月学习规划” 和高频面试题，并让想领资料的人在评论区扣 “agent”，评论区也确实以索取资料为主

### 大模型/LLM

- [2025-12] 作者给出的核心经验很直接：多语言 RAG 里，不管用户用什么语言提问，第一步先翻译成英语，让模型内部的数据流全程走英语，最后再把答案翻回用户的语言
- [2026-09] 核心收益是上下文隔离 —— 审查 Agent 不用看两万字原始文档，只看提炼结论，直接解决第一层的上下文腐烂
- [2026-06] 模型不再是核心，系统工程竞争成为关键，2026年的判断标准是agent loop能否长期稳定运行
- [2026-07] 大模型Agent面试技巧分享，强调回答五个关键问题：原来的问题、放弃的方案、实际的改动、系统边界和个人贡献
- [2026-01] 大模型agent训练营第一模块RAG答疑会上，强调了测试集在RAG系统中的重要性，建议根据用户反馈构造测试集，以评估和优化RAG系统性能
- [2026-06] 模型不再是核心，控制循环、停止回滚、换路径和收敛成为关键，系统工程竞争取代模型能力竞争
- [2026-08] 最后他提醒：比较两个 Harness 必须控制变量，固定模型、任务、工具集、上下文成本和权限，别把壳带来的分数变化算成模型升级
- [2026-09] 以 Idea2Paper 为例，作者给的示范是：这是一个面向科研写作的端到端研究 Agent 框架，要解决两个问题 —— 普通大模型写论文逻辑容易断、创新性无法验证、容易编造不存在的参考文献

### 其他要点

- [2026-09] 真正致命的是三个故障模式：上下文腐烂（工具返回几万 token 日志后忘了原始指令）、无界循环（两步之间反复横跳烧预算）、错误累积（第三步的幻觉变成第四步的输入事实）
- [2026-01] RAG系统框架已定好后，可通过反思、推理、现研知识、角色信息注入等方法优化性能，RAG只是其中一种路线
- [2026-03] 对人类社会来说，最好的选择可能是毁掉这样的模型，让它永远不要出现
- [2026-07] 理由很具体：一个 Agent 连输入、工具、记忆、状态、错误恢复都讲不清，就直接安排 Planner、Researcher、Coder、Critic 四个角色，看着高级，一跑起来出错都不知道是谁的问题
- [2026-07] 模型调用：重点不是会调接口，而是判断什么时候该用大模型、什么时候用固定 workflow，甚至要知道 “什么时候不要用 AI”
- [2026-07] 方法逻辑：作者主张用一个真实项目，把 “模型 — 工具 — 状态 — 评估” 四块串起来，而不是先啃算法
- [2026-08] 这是「AgentAlpha 创客星球」讲秋招 Agent 项目打磨的求职建议视频，核心观点是：项目只做 Demo 不够，面试真正拉开差距的是故障处理、状态追踪和持续迭代能力
- [2026-08] 作者的核心回答是：变的不是模型会不会，而是它能不能把会的东西稳定做对，关键在 Harness（模型外面的工程外壳）
- [2026-08] 核心公式与判断 作者认为 Agent 的实际能力约等于「模型 × Harness × 工具 × 环境 × 反馈 × 预算」的乘积关系
- [2026-08] 这条视频是 @AgentAlpha 创客星球 的 “大厂硬核面试” 系列，模拟字节 Agent 架构一面，核心观点一句话：Agent 架构的本质是控制流设计，能不能上生产，不看模型多聪明，看你能不能把它 “管明白”
