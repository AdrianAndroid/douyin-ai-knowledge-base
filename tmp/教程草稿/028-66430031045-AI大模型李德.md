## 核心干货（按题材归组，标注出现日期）

### 大模型/LLM

- [2026-05] 这条视频是博主「AI 大模型李德」给出的大模型自学路线，核心主张是：普通人想真正搞懂大模型，按四个阶段、约 11—16 周执行，最终能独立交付 AI 应用
- [2026-07] 如果你真想按这个路线走，最值得先弄明白的是第二阶段里的 ReAct—— 它到底怎么让模型 “边想边做”，和单纯的 CoT 有什么区别，这块要不要展开讲讲
- [2026-07] 第三阶段・两大核心技能：RAG（搭建私有知识库，让模型基于自己的资料回答）和 Agent（让大模型自主决策、执行任务），再配合 LangChain 这类应用开发框架上手实际场景
- [2026-08] 想真正上手的话，第一阶段那四个组件（LLM、规划、记忆、工具调用）是最值得先弄明白的，它们决定了 Agent 能做什么、为什么会 “跑偏”
- [2026-05] 这是一条讲自学大模型路线的短视频，作者「AI 大模型李德」把学习拆成四个阶段，并给出每阶段的时间投入和要达到的标准，核心结论是：企业要的是能把大模型落地到业务里的工程化人才，不是只会调 API 的人
- [2026-05] 这是博主「AI 大模型李德」的一条 AI 小技巧视频，核心是教大家用豆包“反推提示词”：把一张喜欢的图丢给豆包，让它拆解成可以直接复用的文生图提示词，再拿去生成风格相近的新图
- [2026-06] 第一阶段・夯实基础：吃透大模型底层逻辑，掌握提示词工程、API 调用
- [2026-06] 第一阶段・夯实基础：吃透大模型底层逻辑，掌握提示词工程和 API 调用

- [2025-09] 基础核心（15 天）：先啃 Transformer 架构和 Attention 机制，再上手 Hugging Face Transformers 库，并实践 LoRA、P-tuning 这类微调方法
- [2026-06] 程序员如何快速实现就业的方法，包括投简历和面试两个关键步骤
- [2026-07] 全片只有 26 秒，核心是给出一条从零入门的学习顺序，最后引导观众留言领取资料
- [2026-05] 作者的核心观点是：别再从机器学习老课啃起，直接按他给的三阶段路线走，最后背面试题冲 offer
- [2026-07] 他给出的核心判断是：方法对，30 天够
- [2026-07] 方法不对，3 个月都够呛，因为 “agent 不是学出来的，是搭出来的”

- [2026-07] 打牢地基：吃透 Transformer 架构的底层机制、神经网络运转原理、自然语言处理的核心方法

### 编程/开发

- [2026-07] 核心逻辑是：从底层原理到应用开发，再到训练微调，最后形成能落地业务的完整能力
- [2026-07] 如果你真按这个框架学，第一阶段建议先补 Python 和 HTTP 请求基础，否则 “调通 API” 会卡住
- [2026-08] 如果你是想真的入门 agent，那张架构图里的感知 — 决策 — 行动闭环就是最核心的框架，可以顺着这个思路再往下学
- [2026-07] 所以这条视频本质上是用三个月路线做钩子，引导评论互动、发放资料，路线本身只给了框架和名词，没有讲具体怎么学、每个阶段花多久、需要什么前置基础
- [2026-05] 把它当作路线框架参考可以，但 “6 周吃透” 属于博主的夸张说法，别当成可验证的结论

### RAG/知识库

- [2026-05] 想先动手的话，第二阶段里 RAG 是最容易出成果的入口，需要我把它拆成具体的学习步骤吗
- [2026-07] 如果你打算照着走，最值得先确认的是第二阶段里 RAG 和微调哪个更贴合你想投的岗位方向，这两条路的准备成本差别不小
- [2026-07] 第二阶段 RAG 的关键其实是切分策略和召回评估，不只是 “会用向量数据库”
- [2026-04] 做完整项目：智能客服、企业级知识库等，作者认为这是最关键的一步，理由是企业要的是工程化人才—— 能把 AI 接进实际业务的人
- [2026-05] 结论：作者强调代码不复杂，按步骤就能在电脑上跑起专属知识库
- [2026-07] 掌握主流微调技术（如 LoRA），最后把 RAG 和微调串起来，亲手跑通 1—2 个项目，比如智能客服、企业级知识库
- [2026-07] 第一阶段：从 0 到 1 搭建一套完整的 RAG，要弄懂它的工作原理、增强索引和知识库搭建，博主强调 “老老实实把 RAG 啃下来”
