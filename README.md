本仓库归档抖音关注作者的作品 AI 总结、提取脚本、作品清单、进度记录和校验报告。文案成品为 Markdown，按“作者目录 / 创作日期-作品ID-标题.md”组织。

AI 文案由抖音 AI 生成，仅供学习和检索使用；“无 AI”表示对应作品没有可用 AI 总结，不等同于提取失败。
