OpenClaw 是什么

作者称它中文名叫 “龙虾”，最早是工程师发布在 GitHub 上的开源代码。核心区别在于权限层级：

豆包、千问、ChatGPT 这类大语言模型是 “数字世界的大脑”，能写攻略但订不了票、比不了价。
以 Manus 为代表的第一批 AI Agent 相当于在云端有了 “身体”，能在网页间跳转找信息，但没有本地文件和操作权限，资料要一个个喂。
OpenClaw 是开源执行框架，有本地最高权限，能直接读桌面 Excel、改文件夹里的 PPT、回邮件发消息，甚至代你买卖股票。部署好后你不在场，它也能在电脑里自己干活。

三个现实问题

部署门槛高：全程在代码框里操作，报错频繁，装好后还可能打不开、找不到生成文件。
权限过高易 “得意忘形”：比如让它清理邮件，它可能把无法判断的内容一并删掉。
成本不低：它本质是把各家大模型接入你的电脑，需按零售价购买 token，不能用无上限套餐。作者引用 “小古” 的实操，用 Claude 的 API，50 元只够做一个最基础的 PPT，成本直逼应届毕业生。国内厂商推一键部署，被比喻成 “把网吧开到你家门口，为的是赚网费”。

已经赚到钱的两类人

代部署服务：购物平台上远程帮装一次收 299–599 元，有人下班接两单，月收入超过工资。
