这个视频是博主小哲讲多 Agent 辩论的工程原理，核心结论是：三个 Agent 辩论后投票，默认并不能保证答对，关键要看论点是否独立、是否引入新证据、收敛依据是票数还是证据强度。

默认机制为什么会跑偏

常规做法是每个 Agent 先给初始答案，再互相审视推理、修正，循环几轮后投票。问题在于 Agent 天然倾向附和多数意见。如果两个 Agent 的初始错误来自同一份脏检索结果，它们会在辩论中互相引用对方的错误论据，形成错误证据的闭环强化，越辩越自信，最后把少数正确的一方压垮。这就是作者说的 “辩论极化”。

三个关键机制

论点独立性校验：辩论开始前先查论据来源。若两个 Agent 引用同一份文档、同一数据源或同一段检索结果，论点标记为非独立项，投票时合并成一个权重，避免同一份噪声被重复计票。
信息不对称与证据引入：辩论不是看完对方答案就改口，而是每轮必须引入一条新证据（新检索结果、新计算结果或反例），谁能推翻对方推理链，谁的权重就上升。
收敛判定看证据链：不看投票数，而看证据链的完整性和可验证性。

作者举的例子是事实核查系统：三个 Agent 从不同数据源检索，两个引用了同一篇被污染的文章，论点被合并，真正用一手数据的那个反而权重更高 —— 辩论比的是证据扎实程度，不是谁声音大。
