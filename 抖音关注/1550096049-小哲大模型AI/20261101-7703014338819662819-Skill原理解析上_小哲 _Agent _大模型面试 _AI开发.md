这是博主小哲讲 Agent Skill 的科普视频：Skill 就是把固定的工作流程和专业标准打包成 “技能” 交给 AI，让它一次做对，而不是反复改。作者认为，拉开 AI 使用差距的关键在于会不会给 Agent 装 Skill，而不只是会不会用 Agent。

Skill 是什么、从哪来 作者介绍，Skill 由 Anthropic 率先提出，2025 年 10 月发布、同年 12 月开源。官方类比是 “给新员工写入职指南”：大模型逻辑强，但不懂行业规则，Skill 就是补上这块。

在 Agent 里的位置 完整 Agent 有四大模块：大模型（大脑，负责思考推理）、记忆（存用户信息和偏好）、工具（手脚，能联网、跑代码、改文件）、Skill（专属打法）。前三者解决 “能不能干”，Skill 解决 “能不能专业地干好”。

三个容易混的概念

Skill 与记忆：记忆存客观事实（比如你毕业于哪所学校）；Skill 管做事方法（比如写简历先核实经历再优化、投递时自动匹配公司）。
Skill 与系统提示词：系统提示词是全局基调，塑造 AI 的性格和说话风格，塞太多会拖慢响应甚至失效；Skill 是按需调用的专项能力，本地存上万个也不会逐个查阅，只在触发场景时生效。
一句话总结：系统提示词定 AI 的性格，Skill 定 AI 的专业水平。

核心设计：分层加载 第一层只存技能简介和适用场景，几乎不占内存；第二层在需要时完整加载流程；第三层针对 PDF 批量填表等细分场景调度附属细则。所以技能可以无限细化，也不拖慢速度。

作者推荐的三类技能 一是提升专业质感类（UI、网页、PPT、文案，比如下载 iOS 风格 UI 技能）；二是预装底层技能（如记忆管理，每次对话后自动归纳沉淀）；三是沉淀个人经验 —— 让 AI 把刚才的对话流程整理成一套技能，下次直接复用。
