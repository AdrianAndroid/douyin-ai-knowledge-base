这段视频是张小珺对月之暗面创始人杨植麟的访谈片段，核心观点是：AI 能力从 L1 到 L5 的分级，不一定是串行关系。

分级与作者的理解

访谈里提到的 L1—L5 大致是：L1 是 Chatbot（对话），L2 是 Reasoner（推理），L3 是 Agent（智能体），L4 是 Innovation（创新），L5 是 Organization（组织）。杨植麟认为，这套分级更像一把 “刻度尺”，用来衡量模型能力到了哪一档，而不是必须一级一级通关的关卡。

为什么不必串行

能力之间是相互支撑的关系，不是先后依赖：Agent 的上限取决于推理能力有多强，但研发路径上并不必然先做透推理再做智能体。
他以 Claude 的路线举例：可能在 reasoning 上投入不算多，但在 agent 上做得很好，同样能跑出很强的产品。
关于 L4、L5，他判断 Innovation 最可能出现在 “模型能参与自身研发” 的时候；有了一个 agent 之后，可以扩展成多 agent 系统，让不同 agent 各做不同的事。他认为 reasoner 和 agent 会是 innovation 与 organization 的前提。

一个容易误解的点

“不串行” 不等于 “可以跳过基础能力”。他的意思更接近：不同技术路线会让短期路径有差异，而市场是动态的，所以这几项能力最终都要持续提升，只是先后顺序和侧重可以不同。
