这是张小珺主持的学习播客，请来清华大学计算机系博士孙宇涛领读 Kimi K3 技术报告。全片约两小时，核心是：K3 是一个把总参数有效扩展到 2.8T、激活约 100B、上下文达百万级并全量开源的 MoE 模型，而它的架构亮点几乎都能在孙宇涛自己及业界过去几年的研究脉络里找到源头。

主线一：从线性注意力到混合注意力 孙宇涛自 2023 年起研究大模型架构与预训练，重点解决推理低效。他讲了自己几份工作的递进：早期线性注意力（如 Raptor）引入 chunking 和 "块递归" 计算形式，既保住复杂度收益又能打满 GPU 算子密度；但纯线性注意力在长上下文上难以匹敌全注意力，于是转向混合注意力—— 按约 3:1 混入全注意力，实验上可做到长文无损甚至更好，代价是加速比被混合比例锁死（最多约 4 倍）。后续 Uformer 改为所有层共用一份 KV cache、把计算与存储解耦，prefill 阶段可直接跳过全注意力；再往后把 loop 单元放在线性注意力段，避免 KV cache 随深度膨胀。

主线二：K3 具体用了什么

Kimi DeltaNet：在 Gated DeltaNet 基础上把衰减项从标量改成 channel-wise，表达上限严格更强，代价是 kernel 更难写；为此加了 lower-bound 衰减，把数值控制在 bf16 精度范围内（约 16 token 窗口），思路类似 RoPE 用绝对位置表示相对位置。
KDA + MLA：全注意力部分沿用 K2 的 MLA，并叠加 gated 操作，主要图的是训练稳定性—— 作者认为稳定性比单点能力更值钱，一次训崩代价太大。
连接方式：Hyper Connection（在残差分支上用更大容量表示深度状态，推理几乎免费）、DenseNet 思路演化来的 block 版 zero-rec。
Latent MoE：先把 hidden state 压到低维再分发，降低 all-to-all 通信量，配合 RMS Norm 控制两个矩阵连乘的稳定性；FFN 用带 tanh 上下界的激活函数压住 outlier。
Quantile Balancing：用可推导的分位数 bias 替代 loss-free 的启发式更新，不用调学习率类参数，也让最底层不必改成 dense。
长上下文：混合架构下把全注意力部分的 RoPE 换成 NoPE，扩长文不用调位置参数。作者特别纠正一个常见误解：RoPE 带来的是 recency bias，对短文本有效，对长文并无帮助甚至有害。

主线三：训练与工程 预训练用 cosine decay 而非 WSD，理由是超参更好调；K3 相对 K2 的 scaling efficiency 约 2.5 倍。低精度训练放在 SFT 阶段引入 QAT，而非从头 FP8。后训练用 on-policy distillation（自己蒸馏自己）合并多个专项模型。推理侧大量篇幅讲 EP 负载均衡（冗余专家 + online planning）、CPU offloading、通信与 shared expert 计算重叠、多模态 PP 排布等细节。
