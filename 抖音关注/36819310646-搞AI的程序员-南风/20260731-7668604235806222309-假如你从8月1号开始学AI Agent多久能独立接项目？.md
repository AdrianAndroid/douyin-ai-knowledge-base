这是博主「搞 AI 的程序员 - 南风」的一条30 天学 AI Agent 路线图视频。作者的核心观点很直接：Agent 不是学出来的，是搭出来的—— 方法对 30 天够用，方法不对 3 个月也够呛。

三阶段计划

第 1—10 天 认知层：先搞懂 Agent 的四个核心模块 —— 感知、决策、执行、记忆，建立基本概念框架。
第 11—20 天 实战层：在 Coze 或 Dify 上搭三个 Agent：知识库问答 Agent（练 RAG 接入）、工具调用 Agent（练 API 调用）、多步骤工作流 Agent（练复杂任务的多轮交互）。作者称做完这三个就超过 80%“自称在学 Agent” 的人。
第 21—30 天 项目层：找一个真实业务场景，独立完成一个企业级 Agent，从需求拆解、知识库构建、工作流设计到上线测试全流程走一遍，作为接单的 “可演示作品”。

关于接单：作者提到做完项目后接单报价大致在 5000 到 5 万不等，但强调关键不是学了多久，而是有没有一个能演示的项目证明自己。视频结尾说 30 天学习计划、每日实操任务、三个 Agent 教程和一个企业级项目可以 “评论区扣学习” 领取。

需要说明的是，30 天、80%、5000—5 万这些数字都是作者的经验判断和宣传口径，不是行业统一标准；Coze、Dify 确实是目前主流的低代码 Agent 搭建平台，路径本身是可行的，但零基础 30 天到能接企业单，实际难度通常比视频里说的高。
