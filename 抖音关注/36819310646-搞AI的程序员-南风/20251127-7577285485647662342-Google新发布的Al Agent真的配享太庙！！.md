ReAct 到底是什么意思

ReAct 是 Reasoning（推理）+ Acting（行动）的合成词，不是 “反应”。它的思路是让大模型在 “想一步、做一步” 之间循环：先推理当前该干什么，再调用工具或检索去执行，拿到结果后继续推理，直到能给出答案。所以视频里 “模型生成下一个动作” 这一步，实际是模型在推理后决定调用哪个工具、传什么参数。这也是它比单纯 “一问一答” 更能处理多步任务的原因。
