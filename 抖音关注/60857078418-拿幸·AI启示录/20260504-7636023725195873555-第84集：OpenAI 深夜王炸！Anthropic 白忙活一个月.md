视频讲了哪几件事

ChatGPT 账号直通 OpenClaw：作者称从 5 月 2 日起，ChatGPT Plus 用户不用单独注册、单独付费，直接用同一账号登录 OpenClaw，额度从订阅里扣，不走 API 按量计费；原有配置、历史记录也能无缝沿用。
Anthropic 的封杀 “荒诞化”：作者引用开发者 Theo 的测试 —— 建一个空仓库，只在 git commit 信息里写一句含 openclaw.json 的话，打开 Claude Code 只说一句 “hi”，账号就被断联、额度清零。评论区也有网友调侃 “网页源码里藏个关键词就能挡爬虫”。
Codex 电子宠物：输入 /pet 唤醒像素风宠物，可从 8 种预设里选，也能用 hatchpet 技能按描述生成专属宠物；它会同步 Codex 的工作状态，相当于 “长了眼睛的状态栏”。作者提到 Claude Code 源码泄露时曾有过类似内置宠物系统，但没上线，被 OpenAI 抢先。
自主迭代功能：/go 加目标描述，Codex 会自己拆任务、写代码、跑测试、修 bug，遇到解决不了的问题会停下来求助；ralphloop++ 进一步强化循环迭代。作者认为这让开发者从 “下指令的人” 变成 “管目标和审核的人”。
一键迁移：在设置通用面板点 “导入 agent 配置”，把其他 AI 代码工具的插件、agent、项目配置几秒内搬进 Codex—— 作者把这看作对 Anthropic 此前 “60 秒搬家” 功能的原样回敬。
