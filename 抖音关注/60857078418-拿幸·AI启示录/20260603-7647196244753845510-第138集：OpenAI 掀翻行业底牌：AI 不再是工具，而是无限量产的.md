视频讲了什么

作者先回顾互联网二十年：谷歌解决搜索、Facebook 解决连接、微信解决沟通、TikTok 解决内容分发、ChatGPT 解决理解。但 OpenAI 这次宣布 ChatGPT 与 Codex 融合，并上线 Agent 插件、批注系统、Sites，作者认为这是 ChatGPT 诞生以来最重要的一次战略转向 —— 最值钱的不是模型，而是劳动力。

接着他抛出五个 “认知反转”：

先被重构的不是程序员，而是办公室。Codex 周活突破 500 万，其中知识工作者占比约 20%，增速是开发者的三倍。PPT、调研、数据分析、会议纪要这类 “处理信息” 的工作，恰好是 AI 最擅长的。
AI 在吞掉软件。首批 Agent 插件覆盖数据分析师、创意设计师、销售顾问、产品经理、投资分析师、投行顾问六类角色，软件从 “功能导向” 变成 “角色导向”，用户只说一句话，Agent 自己调用工具、执行、交付。
AI 在模仿组织。批注系统让修改连续化，改一句能理解全篇，作者认为这相当于给 Agent 装上了 “工作记忆”，它从工具变成同事。
AI 帮所有人造软件。Sites 让一句 prompt 加一个 URL 就能上线应用，作者称之为 “软件民主化”，代码变廉价、创意变昂贵。
默认存在最重要。OpenAI 有接近十亿级用户入口，别人要下载、学习、迁移，而 ChatGPT 已经在那里 —— 就像 Windows、Chrome、微信靠 “默认” 成为霸主。

最后他给出时间线预测：三年内 Agent 成为知识工作者标配，五年内十人管理上百个 Agent、重复性白领岗位消失，十年后人与人竞争变成人与 Agent 集群的竞争。
