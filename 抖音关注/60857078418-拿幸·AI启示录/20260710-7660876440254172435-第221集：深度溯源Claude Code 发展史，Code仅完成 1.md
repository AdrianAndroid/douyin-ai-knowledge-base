发展主线

2021 年前后，Anthropic 内部就在想：AI 不能只待在聊天框里，得进入真实工作流，能读项目、用工具、执行命令、出错自己修。早期有个叫 Clyde 的内部工具，笨重、慢、不稳定，更像研究团队的玩具。
2024 年 9 月，Boris Cherny 加入 Anthropic Labs，接到的任务不是做 “今天能卖的产品”，而是 “为 6 个月后的模型构建”。他先做了个极简 CLI 原型，把 Claude 放进终端。后来他把一个 issue 丢进去，直接生成了 5–10 行的 PR，他说那种感觉 “像看见了未来”。
2025 年 2 月，Claude Code 随 Claude 3.7 Sonnet 以研究预览形式发布；2025 年 5 月 Claude 4 发布后转为正式可用，并接入 VS Code、JetBrains、GitHub Actions 等。

核心机制：agentic loop 作者讲得最清楚的一点是，编程是 AI 智能体最天然的试验场：代码世界有明确目标、可执行环境、测试反馈和版本管理，模型写错了不用靠人主观打分，读报错、改代码、再跑就行。这个 “收集上下文 → 采取行动 → 验证结果 → 再循环” 的闭环，就是 agentic loop。所以它和传统代码助手的区别是：Copilot 像副驾驶补全你正在写的那一行，Claude Code 更像一个初级工程师，你给任务，它自己找文件、改多处代码、跑测试、看失败再修。

为什么说只完成 1% 作者的解释是：它已经会行动，但还没有稳定的长期记忆；上下文窗口很快被填满，官方最佳实践也提醒性能会随上下文填满而下降；敏感操作仍要靠权限系统和人工审查。所以作者判断，工程师的核心竞争力会从 “亲手写代码” 转向定义问题、拆解任务、设计验证标准、审查结果 —— 从代码打字员变成系统指挥官。
