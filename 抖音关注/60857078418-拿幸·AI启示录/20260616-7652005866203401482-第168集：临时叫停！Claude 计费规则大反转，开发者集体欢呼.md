发生了什么

Anthropic 原本宣布 6 月 15 日起调整规则：Claude Agent SDK、claude -p 和第三方应用不再从 Pro/Max 订阅额度里扣，而是改用单独的 Agent SDK 月度信用额度 ——Pro 20 美元、Max 5X 100 美元、Max 20X 200 美元；额度用完后，开了 usage credits 就按标准 API 价继续计费，没开就直接停请求。

结果在开发者准备接受时，官方页面更新显示这些变更先暂停：目前 Agent SDK、claude -p 和第三方应用仍从订阅额度扣，新的月度额度池暂不开放。官方说法是正在重新优化方案，以便更好支持基于 Claude 订阅的开发。

为什么开发者反应这么大

关键不在调价本身，而在 “包月价还能不能驱动一个几乎不间断工作的 Agent”。普通聊天是一问一答，但开发者手里的 Claude Code 会读代码、改文件、跑测试、修 bug，是持续循环调用，背后每次都是真实的 GPU 推理成本。作者认为 Anthropic 两头为难：一边 Claude Code 是它在程序员圈爆火的关键入口，不能得罪开发者；一边又没法无限补贴算力。所以暂停只是把矛盾往后推了一步。

同一天的另一场风波

据公开报道，华盛顿特区用户 Karl Kahn 在加州北区联邦法院提起集体诉讼，指控 Anthropic 在 Max 5X / Max 20X 的用量宣传上涉嫌误导消费者。需要强调，这只是原告指控，法院并未认定违法。官方帮助页确实写明 Max 5X 是 Pro 每 session 的 5 倍、Max 20X 是 20 倍，同时 Max 计划还有每周用量限制；原告称自己升级 Max 20X 专用于高强度写代码，一次 5 小时冲刺就消耗约 15% 周额度。

核心矛盾：5X、20X 到底怎么算

官方说明里，Claude 的用量限制不只跟消息条数有关，还跟消息长度、文件长度、当前对话长度、所用模型和功能有关，Pro 和 Max 还有 5 小时 session 限制、每周限制等容量管理。作者由此点出真正的信任问题：用户不是不接受限制，而是不知道限制怎么算。人类按月付费，机器按 token、算力、时间烧钱，一旦 AI 从聊天机器人变成 Agent，包月模式就开始松动。

作者给普通用户的建议

买 AI 订阅别只看 “最强模型”“无限使用”“几倍用量”，重点看三件事：有没有 5 小时限制、有没有每周上限、超额后是等恢复还是自动转额外计费。用 Claude Code、Agent SDK、自动化脚本的，更要确认调用走订阅池还是 API 账单。

评论区里，开发者普遍吐槽额度消耗快，有人称一周额度两天就用掉 75%；也有人提到 GLM 5.2 可作为替代，作者也建议想换掉 Claude/GPT 的可以试试。作者自己的落点是：AI 行业正从 “抢用户” 进入 “算账时代”，AI Agent 的第一张账单已经摆上桌。
