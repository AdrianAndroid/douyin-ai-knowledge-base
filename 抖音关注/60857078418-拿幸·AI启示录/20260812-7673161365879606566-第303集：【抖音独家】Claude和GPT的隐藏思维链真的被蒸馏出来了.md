这条视频讲的是 《Stealing Reasoning Traces from Proprietary LLM APIs》 这篇 116 页论文：它指出，大模型最值钱的可能是答案出现前那段隐藏的思考过程，而这段过程可以被批量 “偷看” 出来。

论文说了什么

作者是来自 ELLIS 图宾根研究所、马克斯・普朗克智能系统研究所、MATS Research 和 Snyk 的 8 位研究者。他们声称，从 Anthropic、OpenAI、Google 的商业 API 里大规模恢复出了本该隐藏的推理轨迹，而且没有破解权重、没有入侵服务器，也没有硬碰加密算法。

漏洞在哪

同一家公司的模型之间为了让推理跨会话延续，设计了一条内部通道，推理块被加密后可以转交。研究者的思路是：不逼最强的模型自己交代，而是把它的加密推理块转给防护更弱的小模型，再让小模型复述读到的内容。论文中 Claude 用 Haiku 4.5 解码，GPT 用 GPT-5.6，Gemini 用 Gemini Robotics 1.6。结果最弱的模型成了偷看最强模型内部推理的窗口。按当时 Haiku 4.5 的 API 价格估算，处理 1 万条、每条约 1.2 万 token 的轨迹，名义成本只要约 720 美元，已经可以规模化。

关于 “蒸馏” 的边界

这部分作者很谨慎。他们把恢复出的 Claude Opus 4.8、GPT-5.6 Sol 推理轨迹喂给开放模型，发现只给 Kimi-K3 喂 Opus 推理开头约 1%（5 个 token），最终答案前 100 个 token 与 Opus 的最高 n-gram 重合度就从 0.17 涨到 0.33，输出风格明显向 Claude 靠。但论文明确强调：行为相似不等于记忆，更不能单独证明存在训练关系，也没找到逐字复现完整专有推理的证据。所以这不是 “蒸馏案宣判”，而是一种新的行为取证手段。

更值得警惕的一组数字

团队从 GitHub 和 Hugging Face 收集 6708 条公开智能体轨迹，恢复出 315320 个推理块，其中 328 条会话含真实敏感信息，约占 4.9%：62 个 API 密钥、33 个密码、24 个访问令牌、7 个私钥，还有邮箱、姓名和邮政地址。你可能删掉了聊天记录里的密码、隐藏了最终回答里的密钥，但模型解题时已把它写进内部推理，再被封装成看不懂的加密字符，开发者就容易误以为没风险。

核心结论

加密≠安全。加密只解决 “别人能不能直接读懂”，解决不了 “拿到密文的人能不能转手交给有解密权限的系统”。作者认为这不是密码学失效，而是权限边界的设计失效：钥匙没被破解，问题是太多扇门都认同一把钥匙。研究团队已向相关厂商、微软和 Hugging Face 做负责任披露，厂商修复后原攻击方式已失效。他们建议推理块要与具体用户、会话、模型和完整上下文绑定，换地方就自动失效。

评论区里有人提到 GPT Business 版本用了两个月比较稳，也有人讨论 “AI 断案” 必须公开透明展示推理过程 —— 这其实和论文的落点一致：推理过程正在成为需要被守住的新资产。
