三档模型与定位

Sol：旗舰版，主打高难度推理和编程，官方称是目前最强的编程模型；在 Artificial Analysis 的 coding agent 榜单上，Max 模式得 80 分，Terminal-Bench 2.1 拿到 88.8%，Ultra 模式 91.9%。
Terra：均衡版，面向日常工作，兼顾性价比。
Luna：低成本版，用于大规模、高频的基础任务。
API 定价按每百万 token 计：Sol 输入 5 美元、输出 30 美元；Terra 2.5 美元、输出 15 美元；Luna 1 美元、输出 6 美元。

Codex 并未消失，只是被并入 ChatGPT 作者强调，Codex 应用并入新的 ChatGPT 桌面端后，代码能力仍然保留，但不再作为独立工具存在，而是变成 ChatGPT 里的一个工作模式。ChatGPT Work 能跨应用和文件收集信息、连续跟进项目数小时，生成表格、幻灯片、文档、网页应用，并接入 Slack、Teams、Google Drive、邮箱、日历等。作者的说法是：Codex 从 “程序员的专属武器” 变成了 “所有人的幕后引擎”。

两个容易被忽略的变化

多 Agent 并行：新增 Max 和 Ultra 两档设置，Ultra 默认让四个 Agent 同时开工，复杂任务还能扩展更多并发工作流，官方称在 BrowseComp、Terminal-Bench 2.1 等评测中结果更强、耗时更短。
视觉交付能力：模型能检查自己渲染出的界面，发现按钮突兀、布局混乱、信息层级不清等问题后自行修正，让产出更接近 “能直接给客户看” 的成品。

作者也提醒了边界 榜单成绩不等于真实场景表现，企业落地还要面对权限、安全、数据质量、流程复杂度、结果验收和责任归属；Agent 能写报告，不代表能替你承担决策后果。视频中作者也明确说 “不要简单理解成榜单赢了就彻底碾压”。
