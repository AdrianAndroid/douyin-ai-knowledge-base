这是一期对 OpenClaw 2.0 的行业复盘：作者认为这次 “龙虾史上最大更新” 技术上是认真的，但产品窗口期已经关上，属于退潮后的复盘，不是翻盘。

它怎么火的，又怎么退潮的 OpenClaw 最初靠一个 “漏洞” 爆发：花 20 美元订阅 Claude Pro，借 OAuth 通道 24 小时调用价值几千美元的算力，有人用 200 美元套餐跑出 5000 美元用量。今年 4 月 4 日 Anthropic 堵死这条路，重度用户账单涨了几十倍。随后创始人 Peter Steinberger 加入 OpenAI，项目交给新成立的 OpenClaw 基金会，安全问题集中爆发 ——Snyk 审计近 4000 个第三方技能包，三成六存在提示词注入风险。

2.0 做了什么 过去 7 周团队 “用 OpenClaw 开发 OpenClaw”，消息、记忆、技能、模型、插件、安全几乎全部重做，933 名贡献者提交超 16000 个 PR，其中 569 人是首次参与。官方博客标题很实在：《OpenClaw 2.0 不小心做出来的》。安装会自动扫描已有订阅和密钥，浏览器控制台启动从 1.6 秒压到 575 毫秒，插件安装要验证来源凭证，还新增了共享云端会话。

作者的核心判断

PR 数量不再说明问题：创始人更愿意叫它们 “prompt request”，很多是架好流水线让智能体扫仓库批量交代码碰运气。维护者现在看的是对话记录、跑过的测试和 “为什么做这个功能”。
价值在 Harness 不在模型：Harness 指包在模型外面的工具调度、权限管理、会话记忆和执行沙箱。模型能力趋同后，决定 Agent 好不好用的正是这层。OpenClaw 先画出了赛道轮廓，但没赢下它 —— 作者拿 VisiCalc 与 Lotus 1-2-3 作比。
国内水土不服：OpenClaw 要交出整台电脑的文件系统和聊天账号，而飞书今年 3 月开源的 CLI 覆盖 11 个业务域、200 多条命令，权限跟着企业管控走，背后是 2500 多个 API 和企业级鉴权审计。
没回答真问题：2.0 解决的是 “装不上” 和 “不敢用”，但没人回答 “装完第二周为什么还要打开它”。生活助理跑一天可能只转发几封邮件，省下的时间抵不过配置成本。

结尾的落点 作者认为它用 9 个月替行业验证了三件事：Agent 的界面该长在聊天窗口里、真正价值在 Harness、安全从来补不回来。同时提到 Nous Research 的 Hermes Agent 靠 “任务做完自动沉淀可复用技能” 的自学习闭环，在退潮期涨到近 24 万星，编程类榜单冲到第一。

评论区里也有呼应：不少人说已经转用 Hermes，越用越顺手；还有人提醒 OpenClaw 别一直更到最新版，容易出致命 bug。另外有个高赞调侃是 “用 OpenClaw 刷简历”，指的是 HR 拿它筛简历。
