这期是播客「漫谈 Light the Star」主理人卫诗婕对谈百度智能云 AI 计算首席科学家王雁鹏，主题是 Agent Infra—— 也就是支撑 AI Agent 跑起来的底层基础设施。核心观点是：我们正从 “模型时代” 过渡到 “Agent 时代”，而这一轮基建的形态还没定型，谁先抽象出那一层，谁就占住入口。

Infra 是什么，这一代变了什么 王雁鹏把 Infra 理解为 “抽象出一个足够通用的层次”：往大了说台积电做制造也是 Infra，往互联网说，早年是操作系统、数据库，后来是云。他 2011 年进百度，是国内第一批在互联网公司做硬件的人，一路做 SSD、自研 CPU 到 GPU 这条线，习惯从应用、Infra 到硬件做全栈优化。

关键变化在于：上一代 Infra 是纯软件视角，因为 CPU 能均衡地跑任何应用，芯片层面已经固定好了；这一代以 GPU 为核心，GPU 极大释放算力却牺牲了通用性，想在各算法场景里把算力用满需要大量工作，于是 Infra 从偏软件变成软硬一体。

Agent 卡在哪 他判断 Agent 已经能完成真实任务，但要完成任务就得有完整环境 —— 今天人操作的各种基础设施和软件，都要被 Agent 去用，用法和人不一样，所以工具怎么搭、基建怎么做是当前最重要的事。目前 Agent“可用但不够好用、不够放心用”：做个 demo 容易，做成能稳定运行、覆盖边界条件的线上系统很难；完成某项工作可以，替代一个岗位还不行。制约点是模型能力边界尚未探明 —— 边界在哪，最终基建就长什么样。

为什么基建还没定型 他举了两波被模型能力 “吃掉” 的创业：早期做 prompt 模板、生成海报广告片的公司，模型一升级就不那么重要了；之后又转向 context engineering，把复杂任务拆到不同上下文和工作流里。底层模型一直在变，抽象层该抽成什么就不确定，“新时代的数据库是什么” 也还没有答案。他用了个比喻：像青春期的孩子不停长身体，没法量身定做一套合身的衣服。

不变的部分 百度云坚持的 “芯云一体、四层架构” 属于不变项：模型智力≈算力≈电力，要更强模型就要更强算力，要更低单位 token 成本，这条推导不变；此外还需要一套 runtime，让 Agent 在生产环境大规模运行、可控可信任、执行结果可重复。

关于 OpenClaw 这类爆火 他说第一反应是 “好像没什么特别”，因为程序员圈子几个月前已被 Claude 4.5 加配套工具震过一轮，前端、简单网站和 App 已能被替代。这类产品整体仍是同一套 harness 范式：主循环、调用的工具、memory 系统，只是把这几个部分相对固定下来了。

评论区不少观众觉得这种一线工程视角的访谈很实在、有收获。想接着聊的话，可以展开 “harness 这套主循环 + 工具 + memory 的框架具体怎么运作”，或者王雁鹏说的 “Agent 替代岗位、重组工作流” 到底会先落在哪类工作上。
