它是什么、能做什么

项目在 GitHub 上公开，作者称当时 Star 数约 2401（视频开头说 “两千四百多”）。
用 TypeScript 开发，主打免配置、开箱即用，最大特点是在本地运行，能直接读取你本地的文件。
支持 Claude Code、Codex 等编码方案，还能驱动浏览器，从日程表和即时通讯里接任务。
仓库里有 Electron 桌面端和移动端的完整代码。

使用门槛与限制

没账号也能用：在登录界面选 “跳过”，就能跑本地智能体。
但后端服务不在开源库里，不登录就用不了云端功能。
环境要求是 Node.js 22.x、pnpm 10.x（作者说暂不支持 pnpm 11）、Git LFS。

一个容易误解的点 “本地运行” 不等于 “完全离线可用”。开源仓库只给了客户端和界面层，真正干活的云端能力要靠登录后的后端服务；所以它更适合 “本地文件 + 本地模型” 的隐私场景，而不是拿来当免费的全能云助手。
