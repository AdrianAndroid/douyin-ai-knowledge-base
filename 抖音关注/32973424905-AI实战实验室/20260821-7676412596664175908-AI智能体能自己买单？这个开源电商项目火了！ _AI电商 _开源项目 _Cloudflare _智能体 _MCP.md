这是一条介绍开源电商项目 minshop 的科普短视频，作者是「AI 实战实验室」。核心观点是：这个项目让 AI 智能体可以自己逛店、挑商品，甚至自己完成付款，而且整套系统跑在 Cloudflare 的边缘网络上，体量极轻。

它到底做了什么

minshop 是一个跑在 Cloudflare Workers 上的全栈电商系统，关键帧里能看到它的仓库是 ddyy/minshop，说明文档要求 Node ≥ 22.12。它最核心的设计是给 AI Agent 提供了一套 MCP 接口：智能体可以直接通过 API 读取商品目录，再用闪电网络（Lightning）付款，全程无人干预。普通顾客则走 Stripe 结算，两条支付通道分开。

后台功能也齐全，商品管理、订单处理、媒体库都有；商品搜索不依赖外部服务，直接用本地 SQLite 实现，这也是它能做到 “极轻量” 的原因。

作者提醒的两个坑

一是首次部署如果不加防护，后台设置页面会直接公开暴露；二是缓存功能必须绑定自定义域名、并关闭默认域名才真正生效。所以作者的建议是：适合想低成本试验 “AI 自主采购” 的电商技术团队，但上线前得先补上这两处。

需要说明的是，以上都是作者在视频里的介绍和判断，具体部署细节建议以项目仓库文档为准。另外，视频里 “AI 自己买单” 指的是通过闪电网络完成机器对机器的微支付，并不是让 AI 花你的银行卡 —— 这条通道和 Stripe 是分开的。
