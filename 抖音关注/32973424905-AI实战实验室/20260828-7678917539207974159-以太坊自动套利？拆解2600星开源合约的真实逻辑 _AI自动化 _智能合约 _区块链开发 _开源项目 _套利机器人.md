项目怎么运作

技术组合：Solidity 智能合约负责链上执行，外部 Python 脚本负责自动化控制，两者配合。
核心能力：合约里有一个核心函数，能在单笔交易内完成套利；同时能自主管理代币白名单，也就是决定允许交易哪些币种。
启动流程：官方文档给出的步骤是，先在编辑器里新建 .sol 文件并粘贴合约代码，用 0.8.20 版本编译器编译，再进入 Python Automation 面板确认字段自动填好、合约已选中，然后一键启动。
运行机制：启动后，后台扫描器会实时监听以太坊主网的交易，一旦模拟估算显示这笔交易可行，就会触发钱包确认并发送交易。

作者强调的限制

作者明确说，这套方案适合懂智能合约部署和 Python 的开发者，不是零基础就能用的工具。收益受三重因素压制：市场波动、同行竞争、Gas 费。官方文档也提示，即使投入 1 个以太币本金，收益也完全不确定。
