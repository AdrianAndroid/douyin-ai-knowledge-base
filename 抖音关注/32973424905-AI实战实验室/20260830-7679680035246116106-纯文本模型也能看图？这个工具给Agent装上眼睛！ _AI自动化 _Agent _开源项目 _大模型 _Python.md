这个视频介绍的是 GitHub 上的开源项目 Anionex/agent-vision-toolkit，核心思路是：给只能处理文字的 Agent 补上 “眼睛”，让它也能处理图片和屏幕界面。作者是「AI 实战实验室」。

它解决什么问题 纯文本大模型做自动化时 “看不见” 图片，这个项目在模型外部加了一层视觉工具链，把图片转成模型能用的信息。视频称它已有 一千多 Star，支持多图理解、UI 还原和 GUI 自动化。

几个关键能力

ground 工具：定位屏幕上的元素，输出精准的像素坐标，方便 Agent 点击、操作界面。
长截图识别：自动切割长图，并合并其中重合的文本。
草图转代码：真实测试里，它把手绘草图自动还原成了可编辑的 HTML/CSS 界面，视频结尾展示了原图和重建结果的对比。

使用门槛 作者特别提醒两点：项目本身不带视觉模型，必须自己配置外部 API Key；运行几何提取等工具时，本地至少需要 Python 3.11 环境。

作者认为，这种 “用外部工具链补齐模型视觉短板” 的思路，是 Agent 自动化的一条新途径，适合需要视觉辅助、又想继续用文本模型跑自动化的开发者。
