他的三步量化方法

新手好不好找工作：用招聘网站的 “校招岗位数量” 衡量，而不是全部岗位数。他统计的结果是 C++ 和 Java 岗位最多，并建议按自己所在城市再查一遍。

他的最终建议

非科班别选 C++；Java 和 JavaScript 任何情况下都能选，岗位更多。
想离产品、用户更近，或想做数字游民、全栈，选 JavaScript（他提到 65% 的资深程序员会 JS，前端、后端、移动端都能做）。
