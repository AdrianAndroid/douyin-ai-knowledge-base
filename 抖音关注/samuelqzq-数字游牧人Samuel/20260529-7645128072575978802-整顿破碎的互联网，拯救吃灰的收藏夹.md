这条视频是博主 数字游牧人 Samuel 的实操教程：用腾讯刚发布的 Marvis 多 Agent 助手，把散落在各平台的内容统一订阅、下载到本地、整理成知识库，再拿来生成内容。作者说这是他第一次用 Marvis，认为它 “开箱即用、对小白友好”，最特别的是能在电脑上跑安卓 App 并让 AI 操作它。

核心思路：作者把 Marvis 比作 “雇了一帮牛马”，Team Leader 负责统筹，下面有 App Agent、File Agent、Search Agent、Browser Agent 等共 6 个分工小弟，各自去操作软件、读写文件、查资料、开浏览器。

完整流程（按视频顺序）

统一订阅：用开源项目 RSSHub 把 B 站、微博、博客等平台的更新转成 RSS，再用一个 RSS 阅读器集中看。作者让 Marvis 全程代装依赖、跑起项目，并生成 “数字游牧人” 的 B 站订阅链接；随后让它调研开源 RSS 阅读器并给出对比建议，再自己装好、填入链接。
导出笔记：在 Marvis 技能广场装微信读书官方 skill，读取书架和笔记。遇到要 API key，作者直接让它自己开浏览器登录网页版去取，最后把 400 多条笔记导出成 Markdown 文件。
没有官方 skill 的软件：让 Marvis 在电脑上跑安卓 App，由 App Agent 自动操作，比如在汽车之家抓销量排行；也可以用开源项目 MediaCrawler 把国内平台内容批量下载到本地。
建知识库：把 67 个文件拆成上百个独立知识点并互相链接，用本地模型建索引，之后能直接搜到某一篇笔记。
生产内容：从知识库提取游戏设计相关知识点，用 PPT 技能生成演示文稿；手机端还能远程控制家里电脑上的 Marvis。注重隐私或想省 token 可开本地模式，文件不发给云端大模型。

作者的态度：他提醒不是每个人都需要搭这么一套系统，重点在于 “用 Agent 把 AI 和各种软件、开源项目连起来组成解决方案”，这套方法也能迁移到别的问题上。另外他也吐槽 AI 时代对普通人用电脑的要求变高了，环境变量、Git、Docker 这些词越来越躲不开。
