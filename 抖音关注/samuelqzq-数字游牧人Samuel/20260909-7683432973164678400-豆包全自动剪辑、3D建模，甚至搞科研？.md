他实际演示的三件事

自动剪 vlog：先让豆包装上对应 Skill，再把几十个 G 的出差素材丢给它，指令是 “剪成一条有配乐带字幕的 vlog”。十几分钟后，剪映里生成了工程文件，画面按内容自动归类，配了旁白，景点还标了地名。作者自己的评价是 “当粗剪已经很不错了”。
自动建模：装好 Skill 后让豆包在 Blender 里造城堡，它会先列计划再一步步操作；后来又丢一张图让它建房子。作者强调自己从没接触过建模软件。
自动科研绘图：用 GitHub 上的 Skill，让豆包自己上网抓上海近几天 24 小时气温数据，再启动 Origin 建数据表、画热力图 —— 亮黄色对应中午偏热，深蓝对应夜间偏凉。作者同样表示完全不会用这个软件。

关键机制：核心不是豆包本身会剪片、会建模，而是 Skill 充当 “操作说明书”，让 Agent 能点击、输入、调用剪映、Blender、Origin 这类本地软件。作者在结尾把可用的 Skill 列在画面上，并说 “把各种 skill 发给豆包就能实现全自动操作第三方软件”。
