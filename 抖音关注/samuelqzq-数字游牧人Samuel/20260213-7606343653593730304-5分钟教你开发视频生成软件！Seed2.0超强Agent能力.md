这是「数字游牧人 Samuel」的一条实操教程：用免费版 TRAE 中国版和字节的 Seed2.0（豆包大模型 2.0），从零做出一个 “上传照片→选风格和春节场景→生成图片→生成视频” 的拜年视频生成器。作者的核心主张是：现在做 AI 应用，重点不在写代码，而在给编程 Agent 装上 “Skill”，让它连配图、配视频都能一条龙搞定。

开发流程（作者实际演示的步骤）

打开 TRAE 新建项目，选 SOLO 模式，让智能体独立处理复杂项目。
TRAE 本身不能生图，于是让 AI 调用名为 Skill-creator 的 Skill，自己写一个 “生图 Skill”：在 Skills 目录下建 seedream 文件夹，写一个调用 Seedream 生图模型的 Python 脚本，再加一个 SKILL.md 提示词文件当使用说明。API Key 在火山引擎创建。
描述需求做前端，并明确要求用 Next.js 全栈框架，否则 AI 会自己挑框架；第一版太丑，再让它按 “高级感” 重做。
补后端 API：没有后端，API Key 会直接暴露给所有人，这也是评论区作者亲自解释的点。
让 Agent 读代码找出所有需要配图的位置，批量生成 16 张马年主题图并写回代码，作者说手动做要一两个小时。
用同样方式做视频生成 Skill 和后端，跑通 “像素风 + 年夜饭” 等组合；中途报错，日志显示 Seedance 余额不足，充值后继续。
最后让 AI 参考一张图生成 3 张马图，选一张做成视频，放到首页当开场。
