这是博主「数字游牧人 Samuel」的一条实操演示：在 ** 扣子（Coze）** 里把 Claude Code、Codex、OpenClaw 等不同 AI 拉进同一个项目组，让它们像公司员工一样分工，合作产出电商长图、宣传视频和网站。

核心思路：作者认为单个 AI 各有所长，但过去要在几个 AI 之间手动搬运信息；组成团队后，一个对话窗口里 @ 不同 Agent 就能接力干活。

搭建三步

建 Agent：三种方式 —— 接入本地 Agent（电脑上跑一条命令连 Codex、Claude Code、OpenClaw）、新建云端 Agent（相当于租台电脑一键部署）、用职业模板（如 “自媒体运营达人” 自带内容创作、账号诊断、热搜榜技能）。每个 Agent 有独立的 skills、记忆和工作目录，还能设定性格、添加技能。
建项目：把程序员、美工等 Agent 拉进项目组，一个 Agent 可同时参与多个项目。
@ 分工干活：给一张产品图 → 产品经理（本地 Claude Code）写需求文档 → @美工做产品信息长图（美工其实看不到额外信息，能自己读到前面的文档）→ 美工出 9 张分镜图 → @导演生成视频 → @开发用图片和视频做网站。

两个实用细节

作者提到的小技巧：Agent 有时读不到对方生成的文件，可以上传到共享地址再让下一个 Agent 接力。
分工背后是各用各的模型：美工是 Codex 调用 GPT-Image-2 出图，导演是扣子里的 Agent 调用 Seedance 出视频。
项目里还能邀请真人，同事把自己的 Agent 也加进来，形成 “两个人 + 五个 Agent” 协作，甚至同事睡觉时也能 @ 他的 Agent 干活。
