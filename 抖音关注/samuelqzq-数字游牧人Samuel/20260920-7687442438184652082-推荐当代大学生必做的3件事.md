三件事的具体做法

做作品集或个人简历：把课程作业、比赛、个人项目整理起来，别交完就丢。没有创意时，让 Trae 搜索适合二次开发的开源项目，要求 “不像模板、有互动、能持续加内容”。博主用 Plan 模式语音描述风格、页面内容和交互方式，需求不清楚时它会列选项让你选，生成开发计划后确认再开发。最终做出一个手绘像素风、可沿走廊走进不同房间的 “个人世界”；作品少的人也可以参考乐高网站画风，做一份 “边走边看” 的文字版简历。
把课堂汇报做成可交互网页：不写代码，在插件市场安装 “调研分析” 类插件，把主题和问题交给 Trae 整理资料、生成报告，再选 “高质量 PPT 版”，并指定哪里放图表、哪里做成交互。示例是 “新能源汽车价格战” 汇报，数据变成可现场操作的图表；讲代码时还做了 Boids 鸟群算法演示，点代码右侧鸟群就出现爆散、编队、聚合。
做一个 vibe coding 小作品：博主想养桌面像素宠物，找到开源项目 PixelPets，一句话让 Trae 下载、配置环境、跑起来，再自己加待办清单和番茄钟，配合提醒和日历，变成能陪自己也能安排日程的工具。

两个实用细节：为省 Token 按任务切换模型，搭网站用强模型、改文字调样式用快而省的模型，也支持 API key 接入；大项目先在设置里开防休眠和自动审批，减少手动确认。结尾提到完成学生认证可领 2000 积分，属于博主提到的福利信息，具体规则以官方页面为准。
