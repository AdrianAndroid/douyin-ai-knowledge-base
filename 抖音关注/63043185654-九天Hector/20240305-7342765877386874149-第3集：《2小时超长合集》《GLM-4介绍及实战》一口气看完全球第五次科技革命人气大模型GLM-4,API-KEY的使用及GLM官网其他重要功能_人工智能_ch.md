一、API-KEY 是什么、怎么拿 作者解释，API-KEY 本质就是一串字符串，调用大模型前先输入它，作用相当于身份验证，同时确认账户里有钱可用。获取路径是登录后进个人中心或控制台，头像下方有 “查看 API-KEY”。和 OpenAI 需要手动创建首个 key 不同，智谱 AI 给每个初始账户默认发了一个 key，点旁边的复制小方框即可复制（页面上看不到完整字符串）。

二、安全提醒与设置环境变量 作者强调 key 相当于账户密码，别人拿去跑模型，费用记在你账上，所以要当资产保管。推荐做法是把它设为系统环境变量：控制面板 → 系统 → 环境变量 → 系统变量 → 新建，变量名自取（他用了 ZHIPU_API_KEY），变量值粘贴 key，确定后需重启电脑生效。之后代码里只写变量名，不出现明文字符串。他还提到智谱有类似熔断的机制，检测到 key 被滥用或暴露会直接停用，需要另建新 key；平台要求至少保留一个 key，想删旧的要先建新的，也建议定期更换。
