1.0 到底改了什么

LangChain 与 LangGraph 的关系反转：以前 LangGraph 是更高层的图状工作流，现在 LangGraph 退为底层编排语言，LangChain 1.0 在它之上做高层封装。作者调侃这是 “左脚踩右脚”。结论很实用：初学者只学 LangChain 就够，要深入底层再看 LangGraph。
中间件（Middleware）：这是作者认为最核心的新概念。传统 create_agent 构建的是 ReAct Agent，模型怎么调工具对开发者是黑箱。中间件在 “用户输入→模型→每次工具调用” 的每个环节埋钩子，让开发者能介入。它直接支撑三件事：无限上下文（超长时裁剪或让模型压缩历史）、模型动态切换（简单问题用 chat 模型、复杂问题切推理模型）、人在闭环（删数据等敏感操作先人工确认）。
生态打通：LangChain 1.0 可直接复用原 LangGraph 配套的部署、可视化、监控、前端对话工具。
Deep Agents：更高一层封装，改几个参数就能得到定制化 Agent 模板，目前仍在测试阶段，课程未展开。

课程主线

先讲模型接入：DeepSeek、OpenAI、阿里百炼、Ollama 本地模型，统一流程是 “装对应库→实例化→invoke”。再讲消息格式，HumanMessage、AIMessage、SystemMessage 三种角色加 content、metadata；多轮对话本质是不断拼接消息列表。然后是流式 stream、批处理 batch、batch_as_completed 和 Pydantic 结构化输出。最后用 Gradio 搭一个流式多轮聊天机器人，作为入门实践。
