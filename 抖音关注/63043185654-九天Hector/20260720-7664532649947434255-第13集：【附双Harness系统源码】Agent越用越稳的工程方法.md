作者提出的四大方法

文档即真相源：把技术栈、规范、禁区、团队偏好写成 Agent 唯一可读的依据，不靠临时补充。
机械化约束：已知风险用脚本和 Hooks 硬拦截，语义层面的风险交给独立 Agent 审查，形成双层防线。
反馈闭环：把检查放到工具调用、任务执行、代码提交、上线后每一层，让错误尽早暴露。
系统熵减：定期清理过时经验、压缩低频规则、强化高频问题，避免记忆和规则越积越乱。

两套实战系统

Skill 淬炼系统：从历史会话中自动提炼高质量 Skills。
Skill 自动优化系统：根据历史任务建数据集，自主测试并优化现有 Skills。
