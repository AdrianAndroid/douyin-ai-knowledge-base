这条视频是「大模型入门基础」系列的一期，作者九天 Hector 讲的是大模型高效微调能带来哪四方面改变，核心观点是：微调不是万能的，它擅长 “调风格、补常识、练推理和工具调用”，但记不住非常细节的事实。

四类微调作用按视频顺序如下：

对话风格微调（约 00:08）：用不同语气、风格的问答语料训练，模型能很快学会新的说话方式，适合智能客服或特定领域的问答。作者认为这类微调相对最简单。
知识灌注（约 00:28）：通过微调让模型掌握原本不具备的概念性、推理类知识，比如医学、法律、金融常识。但作者强调它的边界 —— 想让模型精准记住 “某年某月发生了什么事” 这类细节很难，这种情况更适合外挂知识库 + RAG 检索增强。这也是微调和 RAG 的本质区别：一个补 “理解方式”，一个补 “具体事实”。
推理能力提升（约 01:22）：对 Qwen3 这类推理模型，喂入大量带思考链的数据集，可以进一步强化它的思考能力。
Agent / 工具调用能力（约 01:37）：也就是过去的 function calling、现在的 MCP 能力。作者举例：某个业务场景只涉及 10–20 个工具，就围绕这些工具设计问答数据集做微调，模型识别和调用这些工具的准确率会非常高。

一个容易误解的点是：很多人以为微调能 “把公司文档塞进模型”，但按作者的划分，细节事实恰恰是微调最不擅长的部分，硬灌容易记错或记混，检索式方案更稳。
