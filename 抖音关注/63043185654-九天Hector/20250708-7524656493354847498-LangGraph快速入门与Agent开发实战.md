这是一节 LangGraph 零基础公开课，讲师是九天 Hector。核心主张是：LangGraph 是 LangChain 生态里目前最通用的企业级 Agent 开发框架，它把 LangChain 的 “链式工作流” 升级为 “图结构工作流”，并用 “状态” 贯穿整个执行过程。

它和 LangChain 的关系 两者底层同源，LangGraph 直接复用 LangChain 的 API 接大模型、接工具，所以装了 langchain-deepseek 这类库就能直接用。区别在哲学：LangChain 的 LCEL 是链式编排，LangGraph 用节点（点）+ 边（线）搭图，且是有向、有环的图 —— 数据可以从下游再传回上游，这是实现循环、重试、多轮 Agent 的基础。

课程主线（按讲解顺序）

图的基本语法：StateGraph 建 builder → add_node 加节点（可以是函数、模型或工具）→ add_edge 连边 → START/END 标识首尾 → compile() 编译 → invoke() 运行。演示例子是 x=10 先加 1 再减 2，输出 9。
状态类型：最简用 dict；更严谨用 Pydantic 的 BaseModel 定义字段和类型，避免字典被随意改写。
复杂结构：add_conditional_edges 做 if/else 分支（判奇偶），条件判断函数只作为 “边” 的判别器，不占节点；循环结构则让边指回自己，直到满足条件才进 END。
接大模型：把模型包成一个节点，状态用带 add_messages 的 message 列表，HumanMessage/AIMessage/SystemMessage 区分角色。
记忆管理：手动拼历史消息太原始，用 MemorySaver + thread_id 两行代码搞定多轮记忆，不同 id 之间互相隔离；默认存内存，进程结束即清空。
流式输出：把 invoke 换成 astream，逐 chunk 打印。
配套工具：LangSmith 做运行追踪和 debug（有免费额度，需联网），LangGraph Studio 可视化图结构并在线对话测试，启动靠 langgraph dev，要求 Python 3.11+。

评论区的两个有效补充 作者回复里明确区分了：LangChain/LangGraph 是代码构建，Dify 是低代码拖拉拽，企业级场景通常选前者。另有观众认为用 if/for/while 加结构体也能实现 Agent，这属于个人看法，不是视频结论。

讲师自己也承认，光是底层图语法就已经是学习 LangGraph 的第一道门槛，比 Agent SDK、ADK 上手更陡。
