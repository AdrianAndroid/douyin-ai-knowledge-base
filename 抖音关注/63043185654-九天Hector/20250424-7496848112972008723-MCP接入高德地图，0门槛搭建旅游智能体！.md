阿里云百炼 + MCP 搭建旅游智能体，这是博主「九天 Hector」的实操演示：不用写代码，在百炼平台上把高德地图的 MCP 工具挂到模型上，就得到一个能规划行程的智能体。

作者的核心观点 百炼最初是模型调用平台，提供千问、DeepSeek 等模型的 API；现在升级成智能体搭建平台，自带联网、RAG 检索等工具。接入 MCP 后，可选工具大幅增加，作者称平台用户从 9 万涨到 27 万（第一天数据，属作者说法，未独立核实）。但他也明确提醒：真正的 agent 开发远不止 “模型调工具”，付费课程里的项目动辄几万甚至十几万行代码；百炼做的是把 “大模型接工具” 这个基础环节变简单。

演示步骤

进入百炼主页 → 点 MCP → 选高德地图的出行规划 MCP → 立即开通。开通只是授权，不扣费。
上方「应用」→ 左侧「MCP 管理」，确认已开通的工具。
新建应用（即新建智能体）：选模型 Qwen Max，按需关联知识库、开启视觉、添加 MCP 服务，在弹窗里勾选高德。
写提示词，例如 “你是一名经验丰富的导游，请耐心认真地为用户规划出游行程”。
右侧直接对话测试：问 “周末想去玉渊潭，上午出发下午回家，中午在外面吃顿饭，帮我规划行程”。模型先调用高德 MCP，再反问出发地、口味、预算，补齐信息后多次调用工具给出方案。

关键机制：MCP 相当于一套统一的 “工具接口标准”，把高德这类外部服务包装成模型能直接调用的能力，省去自己对接 API、写调用逻辑的工作。作者强调，以前即便高德有通用 API，实现同样功能开发量也很大。另外，百炼支持把组装好的模型 + 工具以 API 形式调用，方便后续在代码环境里继续开发。
