接着是完整步骤：

新建项目文件夹，写 requirements.txt 装依赖，.env 里放 DeepSeek、OpenWeather 等 API Key（LangSmith 的 Key 可选）。
写 agent.py：定义外部工具函数 → 组成 tools 列表 → 创建模型和 prompt → 封装成 ReAct Agent。
写 langgraph.json，指明 Agent 入口、环境变量来源和主目录。
命令行执行 langgraph dev 启动后端，打开 Studio 链接能看到 model 与 tools 两条线相连的循环结构，还能查看接口文档、直接对话测试。
克隆 Agent Chat UI，装 Node.js 后用 pnpm 装依赖、启动前端，前后端联通后就能在网页里提问，比如问 “北京天气” 会返回查询结果。
