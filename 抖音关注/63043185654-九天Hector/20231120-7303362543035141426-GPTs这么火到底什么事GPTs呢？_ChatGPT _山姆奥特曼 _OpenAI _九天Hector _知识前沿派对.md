这是博主九天 Hector讲 “什么是 GPTs” 的科普视频，核心结论是：GPTs就是个人专属的功能定制版 ChatGPT，把过去要写代码才能做的 AI 应用，变成在网页上聊天就能搭出来的东西。

视频讲了什么

作者先对比了两条开发路线：

传统做法：拆解文档标题和问题、匹配文档与问题、格式转换、长文档切短、短文本 Embedding、问答，再用微调、Few-shot、COT（思维链）控制输出格式。步骤多、门槛高。
用 GPTs/Assistant API：上传文档、设置回答格式、创建完毕，三步搞定。

接着他区分了两种形态：GPTs 是完全脱离代码、在网页端靠自然语言对话完成开发的 AI Agent；如果加少量代码，功能还能快速增强。而 Assistant API 是更底层、更自动化的纯代码方式，内部已集成文本读取、代码解释器等能力。

GPTs 为什么好用

作者认为关键在三点：一是角色身份设置，设定成 “数据分析师” 后，这个身份不会随对话轮次被遗忘，能长期影响回答风格；二是行为准则，可以输入一段长文字规定模型怎么做事；三是外部文件，把项目数据、数据字典等长文本作为问答背景喂进去。这三点合起来，就是 “定制版” 的实际含义。

一个容易混淆的点

GPTs 和 Assistant API 不是两代产品，而是同一套能力的两种入口：前者面向不会写代码的人，后者面向开发者，底层都靠模型读取文件、按指令执行。所以 “零代码” 指的是搭建方式，不代表能力缩水。
