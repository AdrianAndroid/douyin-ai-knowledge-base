这是博主九天 Hector的一期 MCP 实操教程，核心是用不到 7 分钟，从零开发并发布一个天气查询 MCP 工具，再接入 Cherry Studio 等客户端调用。作者把流程拆成开发、测试、发布三段，全程用真实命令行演示。

开发：把普通函数包装成 MCP 工具 先用 pip install uv 装 UV，再依次 uv init 建项目、uv venv 建虚拟环境（Windows 用 .venv 激活，Linux 用 source .venv/bin/activate）、uv add 装依赖。然后在 main.py 里写查询天气的代码，关键是用官方 FastMCP 库：初始化一个带名字的服务器实例，再用装饰器把天气函数注册进去，模型运行时就能自动识别并调用。脚本末尾设置启动时输入 API Key，并选择 stdio 通信模式 —— 这是 MCP 最常用的方式。

测试：用官方 Inspector 验证 命令行跑 npx 启动 MCP Inspector，工具端口 6277、Inspector 端口 6274，浏览器打开 127.0.0.1:6274，点 Connect 连接，进 Tools → List Tools，能看到 query_weather 就是刚才注册的函数。输入 “北京” 点 Run 运行，返回天气结果就说明功能正常。

发布：打包上传到 PyPI 改 pyproject.toml：确认项目名在 PyPI 上不重名、填版本号和描述、Python 版本设为 ≥3.10、声明启动命令（如 mcp-server-weather 对应 main 函数）。装打包上传工具、注册 PyPI 账号拿 API Key，然后 build 打包、upload 上传。之后在 Cherry Studio 的 MCP 服务器页添加服务器，选 stdio 类型，填 uvx 命令和服务器名、API Key 参数，保存即自动下载启动，对话里问天气就能看到工具被调用。
