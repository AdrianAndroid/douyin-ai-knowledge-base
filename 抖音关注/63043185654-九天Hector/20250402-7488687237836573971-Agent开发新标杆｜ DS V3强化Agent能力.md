并行调用是什么：一个任务同时需要调用多个外部工具时，模型一次性发起多个调用，而不是串行一个个来。作者提到这种模式最早在 GPT-4o 中集成，此前 Agent 能力最强的两个模型是 GPT-4o 和 Claude 3.5，现在 DeepSeek V3 也跟上了。
