这是博主「九天 Hector」对 OpenAI 2025 年 3 月 12 日凌晨直播发布会的技术解读，核心结论是：OpenAI 把 API 从 “调模型” 改造成 “造 Agent”，开发者用几行代码就能搭出类似 Manus 的智能体。

发布会发布了什么

不到 20 分钟的直播，由产品负责人 Kexin 主持，共四项新 API 工具加一个开源项目：Response API、Web search、File search、Computer use，以及开源的 Agents SDK（视频里口播成 “Connection SDK / 文史 SDK”，是识别误差）。

作者认为最关键的变化：Response API

它取代了沿用两年的 Chat Completions API，是 OpenAI 两年来最大的底层更新。作者判断原因在于：OpenAI 不想让 API 只是模型调用接口，而要变成 Agent 开发接口。发布会演示采用 “左边网页、右边代码编辑器” 的前后端一体形式，改代码即时看到效果。代价是截至 2025 年 2 月全球超 200 万开发者的既有代码可能要重写。

三个工具的实际分量

Web search：相当于 DeepResearch 的 API 版，作者称 3 行代码就能做 “搜资料 + 写研报”，对标 Manus 的搜索与长文能力。
File search：Assistant API 文档检索的升级版，最高支持 100G 文档检索，作者评价这是他用过最强的 RAG 系统。
Computer use：作者眼中最劲爆的一项。概念最早由 Anthropic 在 2024 年 10 月以实验形式提出，OpenAI 这次给出工业级方案 —— 让模型 “看屏幕、懂页面逻辑、代替人操作电脑”。他指出 Manus 的技术本质也是 computer use，只是跑在云端沙盒电脑上，因此这项开放被称作 “压垮 Manus 的最后一根稻草”。

三者可在 Response API 调度下自由组合，比如做旅行计划：Web search 查信息、File search 读出行习惯、Computer use 订机票，API 还会监督各环节、自动 debug，并配任务管理后台看进度。

开源与判断

开源 SDK 不同于去年实验性质的 Swarm，作者称它是企业级 Multi-Agent 开发工具，也是 OpenAI 至今最有诚意的开源。他个人判断 2025 年是 Agent 爆发元年，这次发布会相当于吹响号角。
