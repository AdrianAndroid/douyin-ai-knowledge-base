这是博主「九天 Hector」对 DeepSeek-OCR 的深度解读与本地部署教程，全长约 12 分半，分三部分：核心功能、横向对比、快速上手。

它是什么 DeepSeek-OCR 是 DeepSeek 新开源的模型，总参数量约 3B，实测运行占 7G 左右显存。作者强调它虽叫 OCR，但本质是多模态大模型（即 “OCR 2.0”）：靠自研视觉编码器 DeepEncoder 把图像映射到文本空间，再借大模型语义能力理解图像，所以不只能认字，还能读懂 CAD 图纸、流程图这类传统 OCR 认不出的内容。

核心能力

多模态 PDF 一键转 Markdown，自动区分标题、正文、图片、表格、公式
表格、公式高精度识别，图片语义理解与视觉元素分割
通过改提示词切换任务，适合做多模态 RAG 系统

技术亮点与对比 作者认为最大创新是情境光学压缩：用更少视觉 token 压缩图像信息，再靠大模型推理补回逻辑关系，因此 3B 尺寸能超过 InternVL 3 78B 的效果。速度上官方称单卡 A100 40G 可达 2500 tokens/s，作者实测单卡 4090 约 450 tokens/s。对比 PaddleOCR 胜在语义理解，对比 Qwen3-VL 等通用 VLM 胜在视觉编码器专门微调过，对比 olmOCR、InternVL、MinerU 等 OCR 2.0 模型胜在更小、更快。

上手要点 目前无在线 API，只能本地部署。流程：下载权重 → 建 conda 虚拟环境 → 装 PyTorch、vLLM（需指定版本预编译包）、flash-attention → 改 config 里的模型路径、输入输出目录和 prompt → 跑 image 或 pdf 脚本。作者提醒：vLLM 版本限制不支持 50 系显卡，中文提示词效果不稳定，建议用英文。

评论区补充了几点实用信息：作者确认 8G 显存可满足基本需求、Mac 和 50 系暂不适配、GitHub 上已有第三方 API 项目；也有用户反馈输出格式不符预期、image 文件夹为空等问题。视频里的课件、权重和测试文件需扫码进作者的技术社区领取，属于引流环节。
