这是一条实操教程，作者演示了从零注册 Claude API 账号、领取免费额度到拿到 API Key 的完整流程。视频里作者口播说的是 “cloud”，实际指的就是 Anthropic 的 Claude。

注册与登录

打开 Claude API 控制台（console）页面，在 “Build with the Claude API” 处输入邮箱，点击确认。
Claude 账号不用 “账号 + 密码” 登录，而是用邮箱加邮件验证码。作者收到验证码后填入，这一步不需要手机号验证。
首次登录会要求填写公司或组织名称。作者说可以随便填，因为 Claude 目前所有账户都挂在 “组织” 下，不像 OpenAI 分个人账户和公司账户。

领取 5 美元免费额度

新账户默认没钱，但每个初始账户会送 5 美元额度，页面顶部有 claim 入口。
点 claim 后需要手机号验证。作者用 SMS 接码平台买英国（+44）虚拟号，一次买 5 个逐个试，因为有些号会被拒。
作者提到，在 Safari 上被拒的概率比 Windows 电脑上的 Chrome 高。换号后验证码约一两分钟到达，填入后验证通过，页面关闭即表示领取成功。
在右上角个人菜单的 “Plans and billings” 里能看到 5 美元余额。点 upgrade 可以充值，但要用虚拟信用卡。

后续 拿到额度后，在控制台创建 API Key，就能在本地调用模型。作者也提醒，在线大模型都按调用量计费，5 美元适合前期实验和简单测试。

需要注意，视频里用接码平台和虚拟信用卡注册属于绕开平台地区限制的做法，账号存在被风控封禁的风险，这里只做内容还原，不建议照做。
