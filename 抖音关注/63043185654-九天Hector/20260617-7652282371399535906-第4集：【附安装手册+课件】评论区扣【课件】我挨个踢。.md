课程主线

三种运行模式：Terminal（命令行）、IDE 插件、Web。作者认为国内开发者用命令行最合适 —— 轻量、好配置；VSCode 插件需要开代理增强（TUN 模式）才能连上 Anthropic，门槛高；Web 端还在开发中，主要用来连 GitLab。
安装与登录：Windows 用 SET 设代理端口、Mac/Linux 用 export，再执行官方安装脚本，装完用 claude --version 验证。登录分订阅账号（Pro/Max，额度每 5 小时刷新，更划算）和 API Key（按次扣费）两种。
本地存储原理：记忆、Skill、MCP、历史对话全部存在本机主目录的 .claude 文件夹里，不是云端；settings.json 里的 autoUpdate 可设 latest 或 stable，出问题用 claude doctor 自检。
文件夹绑定：所有会话和项目绑定，claude resume 必须在原文件夹里才能恢复；可以多开，但同一个文件夹不能开两个，否则会话列表会错乱。
换国产模型：改 settings.json 里的 Anthropic 兼容端点即可，作者排序为 Kimi K2.5、千问 3 系列最好，其次 DeepSeek、GLM、MiniMax；Code Plan 里他首推阿里云百炼，其次 Kimi。
六大核心系统：内置工具（read/edit/write/bash/web-fetch 等）、斜杠命令（共 59 个，含 clear、compact、rewind、init、context、cost）、扩展能力（MCP/Skill/Plugin）、多级记忆（CLAUDE.md 为最高权限 “宪法”，超 200 行就拆 rules）、回滚与 checkpoint、多 Agent 协作（内置 Explore/Plan/General Purpose 三个子 Agent，另有 Agent Teams）。
实操演示：建 claude-lab 文件夹，让 Claude Code 生成一个深色背景的学习实验页面；写 CLAUDE.md 规定 “注释用中文、加前缀、琥珀橙配色”，重启后新任务自动遵守；故意改成黑白配色后演示 /rewind 回滚；手写一个 summarize Skill 让它自动生成项目摘要。
进阶部分：用 frontend-design Skill 和 Pencil MCP 美化前端，再让规划、编程、审查三个 Agent 串成工作流，开发前后端分离的聊天机器人。
