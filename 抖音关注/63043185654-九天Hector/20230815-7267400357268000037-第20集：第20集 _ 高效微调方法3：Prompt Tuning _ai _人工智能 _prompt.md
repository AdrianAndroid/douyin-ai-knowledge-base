核心内容

定位：属于参数高效微调（PEFT）家族。不修改大模型本身的权重，只在输入端加入一小段可训练的 “软提示” 向量，冻结原模型，只训练这几十到几百个参数。
与 Prefix Tuning 的区别：Prefix Tuning 是在每一层注意力的 Key/Value 前拼接可训练前缀；Prompt Tuning 更简单，只在输入嵌入层加一段可学习的 prompt embedding，模型其余部分全部冻结。
引用的论文：画面中出现的《The Power of Scale for Parameter-Efficient Prompt Tuning》（2021），核心结论是模型规模越大，Prompt Tuning 的效果越接近全参数微调；在超大模型上，少量 prompt token 就能达到不错效果。
优势：训练和存储成本极低，一个基座模型可以挂多套 prompt 应对不同任务，切换任务只需换 prompt，不用换权重。
