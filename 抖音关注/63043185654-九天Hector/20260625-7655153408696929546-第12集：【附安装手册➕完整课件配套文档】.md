这是一场关于 Hermes Agent（视频里被戏称为 “爱马仕智能体”）的技术直播课，作者是九天 Hector。核心主旨是：Harness Engineering（驾驭工程） 是让 AI 智能体从 “能跑通” 走向 “长期稳定、越用越聪明” 的关键，而 Hermes Agent 就是这套思路的落地产品。

它到底讲了什么

为什么需要 “驾驭”：作者认为现在模型本身已经够强，问题出在智能体上 —— 输出有随机性、多步调用容易走偏、上下文有限会 “遗忘”、没有人类审美对齐就会质量退化。所以 “智能体 = 模型 + 好的约束”。
Hermes Agent 的定位：一个开源的通用智能体，对标 OpenClaw / Claude Code，但按 Harness Engineering 体系搭建，作者称其运行更稳、迭代更快。它最核心的两个特性是记忆自主进化和Skill 自主生成与优化。
四层记忆系统：第一层是自动写入的 memory.md/user.md（有 token 上限，超了自动压缩）；第二层用 SQLite 存全部历史对话做全文检索；第三层是可插拔的外部 provider；第四层是拼接提示词时的安全扫描（后门、不可见 Unicode 字符、凭证泄漏等）。
Skill 自主进化：演示中让它做一次项目安全审计，跑了近 6 分钟、调用大量工具后，它会主动询问是否把这次经验固化成 skill；确认后自动生成，第二次同类任务耗时压到 300 秒以内，后续还会自己找规律继续优化。背后是叫 GEPA 的进化引擎，用遗传算法 + 多目标优化来改提示词。
两个配套项目：skill distill（从对话中提炼或按需求全自动生成 skill，遵循 Anthropic 官方 skill creator 流程）和 skill 进化系统（用测试集让 skill 越迭代越准），端口分别是 3270 和 3280。
