第一部分：把 DeepSeek 接进来

安装 LangChain，0.3 以上版本都能用，用 pip install 装完再查一下版本确认。
去官网注册 DeepSeek 的 API Key，在项目文件夹里建 .env 文件写进去，同时装 dotenv 库，用 os.getenv 读取。
先用 OpenAI 风格 API 跑一次简单调用，验证网络和 Key 是否正常。
关键两步：Key 必须写进本地环境变量，因为 LangChain 会自动去读，不需要在代码里显式传；另外要装 langchain-deepseek 库，它不会出现在导入语句里，但后台会用到。
用 init_chat_model 创建模型对象，只需填模型名和提供方，比如 deepseek-chat（V3）或 deepseek-reasoner（R1），然后 model.invoke() 就能对话。

作者特别强调 LangChain 和 OpenAI SDK、CrewAI 等框架不同，自己定义了一套模型调用规则，所以必须走 init_chat_model 这条路。返回的 result 是 AIMessage 对象，正文在 content，token 数、对话 id、推理模型的思考链都在 additional 里；人类消息则叫 HumanMessage，多轮对话就是把不同 message 拼成列表。

第二部分：链（Chain） LangChain 名字里的 chain 就是核心。作者用竖杠 | 把模型和 StrOutputParser 串起来，前者负责生成，后者把 AIMessage 过滤成纯字符串，方便直接打印或保存。他打了个比方：这套 “把模型塞进工作流扮演不同角色” 的思路，和 n8n 很像，但 LangChain 起步早、跑在纯代码环境里，灵活度高得多；后来的 Agent 功能也都是在这层链之上做的更高封装。

第三部分：进阶内容 课件还覆盖了 Function Calling—— 作者说这是大模型变成智能体的关键，因为模型本身没法直接碰外部工具，得靠一个函数当 “中介” 去调用，画面里演示了用 create_tool_calling_agent 配合自定义天气工具搭 Agent。
