这是博主九天 Hector的一期技术公开课，讲的是字节旗下零代码 Agent 开发工具 ** 扣子（Coze）** 突然开源后，开源版能做什么、和在线版差在哪，以及怎么在自己电脑上把它跑起来。

开源版 Coze 砍掉了语音交互和开发者权限管理，但 Agent 开发的核心功能基本保留：网页端零代码开发测试、画布上拖拉拽编排工作流、单节点菜单式配置、代码节点、内置插件系统和几套模板。它自带完整后端，开发好的智能体可以一键部署，再在公众号、飞书文档、CherryStudio 里调用，或用 LangChain/LangGraph 当作外部工具接入。协议是 Apache 2.0，允许改源码、搭闭源 SaaS、做商业化二次开发，也能完全离线部署，数据不出本地。

作者认为它不只是低代码玩具：后端 Golang、前端 React+TypeScript、微服务架构，可独立部署扩展，定位是 "上限也很高的专业 Agent 开发框架"，并称功能比 Dify 更丰富灵活。他还讲了背景 ——Coze 最初对标 ChatGPT 的 GPTs，靠低门槛起量，后来随着大模型进入深水区，才补上工作流编排、提示词评估优化等复杂能力。

部署部分（以 Windows 为例）

装 Docker 并保持运行；硬件最低 2 核 CPU、4G 内存，支持 Mac/Windows/Linux。
git clone 拉取 coze-studio 源码（或直接用网盘压缩包）。
在模型配置模板目录里复制 DeepSeek 模板，填入 base_url、api_key、模型名，再复制到上一层目录；同时在 docker 目录建 .env，写入相同配置。
修一个格式小 bug：把 setup-es.sh 的换行符从 CRLF 改成 LF。
主目录执行 docker compose 拉镜像（约 2–3 分钟），遇 2379 端口占用就重启 Docker，然后启动。
浏览器打开 localhost:8888，新建智能体对话，验证 DeepSeek 是否接通；新手可从 "探索 — 模板" 里复制 "导购陪练" 智能体试玩。

需要说明的是，"超越 Dify"" 更适合企业级 "是作者的个人判断，不是已核实结论。评论区就有分歧：不少人做商业级开发更推荐 n8n，也有人反馈自己部署后发现文档里大量标注" 开源版暂不支持 "、没有可用插件，还缺少用户付费订阅计费功能；另有讨论认为扣子本质是 Workflow 而非能自我迭代的 Agent。这些和视频里" 几乎拥有全部核心功能 " 的说法存在落差，实际选型建议先按自己的场景验证插件和计费这两块。
