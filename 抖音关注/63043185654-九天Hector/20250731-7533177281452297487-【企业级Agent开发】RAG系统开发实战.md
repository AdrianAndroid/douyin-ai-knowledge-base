这是「九天 Hector」的一节 RAG 系统开发公开课，核心观点是：RAG 门槛很低，但上限极高。视频用约 72 分钟讲清从极简 demo 到企业级 Agentic RAG 的完整搭建路径，并配套课件、代码和数据集。

作者的核心判断 初学者常以为 RAG 就是 “切文档、做匹配、拼上下文”，但真正落地时会遇到多模态 PDF 检索、跨文档隐藏语义提取等特殊情况，复杂系统甚至要开发几十个功能模块。所以作者说它 “门槛很低、上限极高”，并用四个实战案例来补工程能力。

四个案例的递进逻辑

纯手写：不用框架，从零实现各模块，理解完整流程。
LangChain 极简版：用 PyPDF 读文本 → 递归字符切分（每片不超 1000 字符）→ FAISS 向量库存储 → 封装检索工具 → create_tool_calling_agent + AgentExecutor 跑通前后端一体的单轮问答。embedding 用 ModelScope 的 text-embedding-v1，对话模型用 DeepSeek。
加护栏的版本：以公司员工手册为语料，先判断问题是否与文档相关，相关才检索，不相关直接回 “超出问答范围”。护栏有两种做法：靠提示词约束，或先检索看相似度再决定；两者也可混用。
LangGraph Agentic RAG：能自动判断是否需要检索，并根据检索结果改写原始问题以提升召回，还支持 CLI 部署、LangSmith 监控和前端对话页。

几个值得记住的工程细节

文档尽量预处理成 Markdown，标题层级（#、##、###）结构化后，切分和读取都更准。
FAISS 和 Chroma 在 80% 以上场景性能差别不大，可互换。
PDF 解析从简到繁：PyPDF 只提文本，MinerU 能做深度格式与多模态解析，但部署复杂。
额外赠送 LangChain-ChatChat 二开版，可接 DeepSeek、在 Windows 稳定运行。
