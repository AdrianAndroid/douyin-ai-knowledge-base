这条视频是一场关于 Hermes Agent（爱马仕智能体）的公开课，主讲人把它定位成 “越用越懂你” 的通用智能体，并围绕 Harness Engineering（驾驭工程）讲原理、做部署演示。

作者的核心观点

作者认为，市面上大多数 AI Agent 出厂即巅峰，用第一天和第一百天能力一样；Hermes 打破了这个规则 —— 每跑完一次任务就回写操作流程，同一件事做到第 14 次，完成速度提升 60% 以上，准确率还在涨。它由 Nous Research 开源，作者称其 “在不少场景可替代 Claude Code”，但也在视频里明确承认：多 Agent 协作、生态丰富度上还不如 OpenClaw，且只能命令行交互，上手门槛更高。

拆解的四大模块

四层记忆：memory.md（持久记忆，约 800 token 上限）、user.md（用户画像，约 500 token）、SQLite 数据库（全量历史对话，可全文检索）、外部 provider（可插拔的长期记忆插件），外加一层记忆安全扫描，防恶意注入、不可见 Unicode 字符和凭证泄露。
Skills 自主迭代：任务复杂、多次工具调用或报错后，它会主动询问是否把这次流程沉淀成 skill。演示中一次 Python 项目安全审计跑了约 6 分钟，生成 skill 后第二次压到 300 秒内，还顺手做了修复。
GEPA 机制：借鉴遗传算法与多目标优化的提示词进化框架，不只改 skill，还能反过来优化系统提示词，最终合并需人工确认。
47 个内置工具：终端、文件、浏览器、多模态、搜索等，作者称提示词经过精调，所以比 Claude Code 跑得更稳。

实操部分：Mac/Linux 下用安装脚本一键部署，hermes doctor 自检，config set 配模型（演示用 DeepSeek），chat -q 一次性跑任务、chat 进交互模式；再通过 gateway 接入飞书，用 cron create 做定时巡检，最后演示记忆自动写入与 skill 从零生成。

评论区反馈集中在另一面：多会话丢对话、多轮易出错、幻觉和 token 消耗夸张，也有人提到 Claude Code 开启自动记忆后靠 Claude.md 说明需求即可。这些属于用户个人体验，不是作者的结论。
