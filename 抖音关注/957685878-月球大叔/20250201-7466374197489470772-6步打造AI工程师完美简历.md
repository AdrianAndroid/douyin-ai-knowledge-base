一个核心 + 六个模块

Highlight（摘要）：只写两句话。第一句说过去的工作 / 实习如何对上岗位，比如 “半年 AI 训练平台实习，用 k8s 支持训练任务”；第二句说产出亮点，比如系统支撑上百万用户、参与知名开源项目。作用相当于论文 abstract，勾住 HR 和 Hiring Manager 继续读。
教育经历：应届生放第二段，写清专业，绩点好可加；毕业三年以上放最后，因为此时学校已不关键。
工作 / 实习经历（灵魂章节）：先写公司和职位，再按固定模板写项目 —— 项目名用 “为了 X 业务的 X 平台” 格式，然后四步走：说清场景（训练 / 推理、k8s 平台 / 数据平台 / 底层编译器，即 “核心流派”）、说清结果（降了多少延迟、提了多少吞吐）、说清技术和自己做了什么（如把 vLLM 用到项目里再做定制优化）、最后讲 impact 和业务规模（省了多少钱、部署到多少设备）。他给的范例是 “1024 块 GPU 的 k8s 平台上把 token generation 吞吐提升 1.5 倍，帮公司省下 100 万美金，业务服务百万以上用户”。
开源项目：AI Infra 基本靠开源推动，强烈建议真参与一个；贡献大就按工作经历的格式写，做得一般也可以写，体现态度。
技能点：按 AI / Cloud / Data 分类，对照 JD 重排，主要为了过机器筛选。
论文或专利：挑几篇能支撑 highlight 或对上 JD 的即可，工业界看业务产出，不必罗列太多。

几个附加提醒：每个项目用固定格式写，是为了降低对方阅读成本、快速形成印象；所有内容都要围绕 highlight，别跑题；投递时按 JD 微调，别一份简历投上百家；写不出这样的简历，就把它当学习计划，专攻一点慢慢补。结尾他鼓励 “不要焦虑，慢慢来就是最快的”。
