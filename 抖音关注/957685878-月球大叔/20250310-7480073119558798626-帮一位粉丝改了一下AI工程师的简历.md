这段视频是博主在直播里现场改一份粉丝的 AI 工程师简历，核心观点是：工业界招聘 “一个萝卜一个坑”，简历必须只对准一个岗位，写深不写全。

主要问题与改法

Summary 定位太散：原简历同时写了 software engineer、LLM、AI engineer、data scientist 四个方向。博主用 “川菜馆招厨师，你递东北菜简历” 打比方，说 HR 一次要看上百份简历，看到这种只会困惑 “你到底在找什么工作”。建议只留一个方向，比如 AI infra 或 ML；真会多个方向，就准备三份简历，各写一句总结。
Project 写法：给出四段式模板 ——business problem（解决什么问题）→ method（你做了什么）→ result（具体数字，如精度提升、内存降低）→ impact（被多少人 / 多少团队使用）。每个项目控制在四到六句话，一行一个要点，不要写成大段落。
量化要落地：原简历只写 “提升效率”，博主追问指标是什么，示范改成 “原来读十个 PPT 要一小时，现在五分钟，效率提升约 12 倍”，并说内部找人问一问就能拿到大致数据。
岗位名称：建议把 AI engineer 改成更直白的 machine learning engineer，工业界更认这个叫法。
内容太单薄：实习经历和项目重复，来回就那一个项目。博主建议花三到六个月参与开源社区，在简历里加 open source 板块并附 PR 链接。他还估计，这份简历在美国投实习 “四百投不超过五个面试”。

博主也提到，impact 部分适度包装可以，但别太夸张。整体属于经验分享，不是官方标准。
