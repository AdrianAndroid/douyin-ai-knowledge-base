这条视频是财经博主「直言财经」的口播评论，核心问题是：DeepSeek 都开源了，马斯克为什么还要花大钱做闭源的 Grok 3？他的答案是：这不只是技术选择，而是开源与闭源两条路线在争夺未来科技话语权。

视频讲了什么

博主先摆出 Grok 3 的 “堆料” 数据：20 万块英伟达 H100、约一个中型城市一年的用电量、2 亿 GPU 小时训练，但结果只在数学、科学推理等少数场景比 DeepSeek 强不到 2%，发布会还得把坐标轴起点调高才看得出差别。他还举了个调侃性的例子：问 “9.12 和 9.9 谁大”，Grok 3 也答错。同一天 DeepSeek 发论文讲注意力分散机制如何降能耗，博主用 “周文王吃馒头咸菜写《周易》” 作比，说省钱也能出好东西。

两条路线的分歧

开源（DeepSeek 为代表）：个人免费、企业 API 低价收费，快速接入出行、医疗、金融、政务等长尾场景，靠 “薄利多销” 扩大付费基数；用户多→数据多→技术更强，形成良性循环，最终是 “用脚投票” 的赢家通吃。
闭源（OpenAI、Grok 3 为代表）：Grok 3 闭源且付费，仅限 X 平台月费 30 美元的高端会员，并计划绑定社交数据、自动驾驶、机器人做生态闭环变现。博主认为这最终滋生 “垄断租金”，先进生产力握在少数人手里。

博主还点出马斯克的矛盾：他曾因 OpenAI 转向闭源而愤然离开，这次自己却做了闭源。他的解释是马斯克如今身负 “让美国再次伟大” 的角色，若美国巨头都用 DeepSeek 框架，等于拿自己的用户和数据养大别人的模型，所以 “马公老城谋国，不得不多想一步”。
