视频由「AI 启示录」发布，作者声明为 AIGC 内容。核心事件是：2025 年 4 月 10 日深夜，斯坦伯格在 X 上晒出 Anthropic 安全团队的邮件，称其账号被判定 “存在违反使用政策的行为”，全部 Claude 访问权限被撤销，没有说明具体条款、没有事先警告，只给了一个申诉表单链接。两个多小时后账号恢复，Anthropic 工程师在评论区解释是滥用检测分类器过于敏感导致的误判。但作者认为，把前后半年的事连起来看，这不像单纯的 “风控乌龙”。

作者梳理的三条线

改价与断供：4 月 3 日 Claude Code 负责人公告，次日中午起 Claude 订阅不再覆盖 OpenClaw 等第三方工具，用户需改用按量付费包或 API 密钥，从公告到生效只留一天。官方理由是订阅体系不适合第三方工具的使用模式，需要把算力留给自家产品和 API 用户。作者算了一笔账：一个 OpenClaw 实例 24 小时运行，按 API 定价一天消耗约 1000—5000 美元，而 Max 订阅每月仅 200 美元，全球 13.5 万个活跃实例的算力成本远超订阅收入，所以改价本身有商业逻辑。
功能复刻的时间线：1 月 Claude Cowork 以研究预览版上线，做本地文件读写整理；2 月 24 日升级为企业级产品，上线 20 多个原生插件；2 月 25 日收购初创公司 Versat；3 月 17 日推出 Dispatch，手机发任务、Mac 端自动执行；3 月 19 日 Claude Code 上线 Channels，支持通过 Telegram、Discord 下发任务；3 月 24 日 Cowork 上线 macOS 桌面控制；4 月 3 日扩展到 Windows。作者认为这半年正好把 OpenClaw 的基础能力、集成生态、跨设备调度、本地执行逐块复刻了一遍。
改名风波与法律通知：OpenClaw 最初叫 ClaudeBot，因发音接近被要求改名。斯坦伯格申请两天宽限，结果点下重命名按钮 5 秒内旧社交账号就被脚本抢注，随后被用来挂恶意链接和诈骗代币，他一度想删掉整个项目。三天里项目从 ClaudeBot 改成 Moltbot，再改成 OpenClaw，他还花 1 万美元买了企业认证号。之后 Anthropic 又发来第二封邮件，称律师已介入。与此同时，OpenAI CEO 在 2 月官宣斯坦伯格加入，负责下一代个人智能体研发，并承诺 OpenClaw 交由独立开源基金会托管。

作者自己的态度很克制：他明确说 “没有人能替这家公司下蓄意打压的定性，也不能把时间先后等同于因果”，但认为这些事按这个顺序发生，已经让开源社区产生难以消除的疑虑。他最后落到三个问题：固定包月订阅模式在智能体时代是否已被击穿、大模型厂商要做 “水电煤” 还是全链路闭环、开发者的生命线到底握在谁手里。
