这是「拿幸・AI 启示录」发布的一条 AIGC 科普解读视频，核心讲的是 Agnes AI 把文本、图像、视频、语音全模态 API 免费开放，作者认为这背后是一场争夺开发者工作流的生态战，而非单纯的 “薅羊毛”。

作者讲了什么

事件：Agnes AI 将文本模型 Agnes 2.0、图像模型 Agnes image 2.1 Flash、视频模型 Agnes video 2.0 一起免费开放，公开说法是面向全球开发者和创作者长期开放，不是试用版。视频称开放后周调用量冲到 3.12 万亿 Token，其中文本约 1.9 万亿，图像和视频合计约 1.2 万亿。
为什么 “免费” 戳中痛点：作者指出 Agent 时代一次用户提问背后可能是几十轮模型调用，小团队常常 “产品还没上线，账单先上线”。图像、视频 API 过去是奢侈品，批量试主图、封面、分镜成本很高，很多人不是没想法，是不敢试错。
三项升级：1M 超长上下文（让 AI 从单文件补丁工变成项目级协作者，处理长文档、长期对话）；4K 生图（最高 4096×4096，支持 1:1、3:4、4:3、6:9、9:16、21:9 等比例）；TTS 语音，把写稿、生图、做视频、配音串成一条流水线。
作者的判断：免费只是第一拳，真正目的是让开发者从写 demo 起就用它，最终变成底层基础设施；AI 竞争正从 “比模型跑分” 转向 “比工作流更便宜、更顺滑”。

需要留意的部分

作者自己也提醒了边界：1M 上下文 “长不等于读得准”，要看长文本检索和多跳推理；免费能否持续、高并发稳不稳、会不会突然改规则，都是风险。视频里那张 ClawEval 排行榜截图显示 Agnes-2.0-Flash 为 60.9%，低于 Claude Opus 4.6 的 70.8%、GLM 5.1 的 62.7%，属于中游位置，和 “顶尖” 的说法有落差。

另外，评论区反馈和宣传差距明显：多数人吐槽限流严重、响应慢（30 秒以上常见）、日 / 周 / 月配额容易耗尽，常遇 429/503 报错；有人认为文本和视觉理解勉强可用，但生图、视频效果差，视频只有几秒、人物畸形。也有网友按 3.12 万亿 Token 估算电费成本约 936 万到 2808 万元，质疑 “免费” 的可持续性。这些是用户体验层面的说法，不代表官方口径。
