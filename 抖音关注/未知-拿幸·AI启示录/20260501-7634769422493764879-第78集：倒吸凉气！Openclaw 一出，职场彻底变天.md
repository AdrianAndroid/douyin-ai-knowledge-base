视频讲了哪几件事

人物背景：彼得 14 岁开始编程，白手起家做了 10 年公司后卖掉，随后陷入三年倦怠。2025 年初接触 AI 编程代理后，他发现写代码不再是瓶颈，几个月内一个人做了 44 个项目。
关键转折（马拉喀什）：他给自己做了个挂在 WhatsApp 上的助手，只要求 “像人一样说话”。某天他发了一条语音，而程序里根本没写处理语音的代码，AI 却在 9 秒内自己检查文件头、转换格式、翻出电脑里的 OpenAI API 密钥、调用接口转文字，再用当地语言回复。作者把这种 “没被写死也会自己想办法” 的能力，视为代理与聊天机器人的分水岭。
失控的一夜：他把这个高权限代理扔进公开 Discord 频道让陌生人调戏，进程被搞崩后，靠底层写的 “韧性恢复机制” 自行重启，跟网友聊了一整夜，留下 800 多条交互记录。所幸没有发生数据泄露，项目随后在 GitHub 病毒式爆发。
商业冲突：爆红后，提供底层模型的大厂以商标侵权发律师函，要求改名、放弃龙虾吉祥物，最后直接切断 API 访问。彼得一度想删库，是看到普通用户的用法才留下。
两个案例：维也纳 60 岁退休老人格哈德不会写代码，用语音让代理接管家里酿酒设备跑完 90 分钟流程，之后代理还主动提议建站卖酒、写前端、接支付；深圳则出现 “养龙虾” 的说法，以及公司要求员工每天必须用 AI 自动化一项工作、否则开除的 KPI 表。
