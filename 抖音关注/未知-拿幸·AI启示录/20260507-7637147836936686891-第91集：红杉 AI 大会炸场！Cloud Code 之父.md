这是「AI 启示录」对 Claude Code 创造者鲍里斯・切尔尼 在红杉资本 AI Ascent 2026 大会上专访的解读。核心观点是：编程这件事对他个人来说已经 “被解决”，软件行业正迎来 “印刷机时刻”。

他的个人工作流已经彻底变了

鲍里斯称 2026 年至今没亲手写过一行代码，日常开发靠手机完成，曾在一天内提交 150 个 PR。他在 Claude 应用里同时跑 5—10 个会话、几百个智能体并行，晚上还有几千个在后台处理深度任务。他最推崇的是 Loop 循环：用指令让 AI 按设定频率（每分钟、每 5 分钟、每天）自动执行任务，比如盯 PR 自动修复、维护 CI 健康、每 30 分钟抓取社媒反馈做聚类分析。

“核心代码只剩 100 行” 是什么意思

底层逻辑是 “工具变薄、模型变厚”：过去为约束模型写的脚手架、控制框架会越来越不重要，模型足够聪明后，人只需定义问题、明确目标、把控方向。他也坦承边界 —— 超大型存量代码库、极冷门语言仍有局限，但行业共识是 “等下一代模型就好”。

商业与人才判断

被削弱的两条护城河：转换成本（AI 能轻松完成跨平台迁移）、流程霸权（AI 可快速重构内部流程）。
依然坚挺的：网络效应、规模经济、垄断性资源。
所以 SaaS 不是末日，而是创业者的黄金时代，他预测未来十年颠覆性初创公司数量会十倍爆发。
人才标准转向跨学科通才：Claude Code 团队里产品、设计、财务、数据科学家都在用 AI 写代码。

“印刷机时刻” 这个比喻

他引用科技史：印刷术前欧洲约 10% 人口识字，读写是受雇于国王领主的精英特权；印刷术后五十年出版的文献超过过去千年总和，书价降近百倍。他据此判断编程会像读写一样成为基础技能，未来最好的垂直软件会由该领域专家亲手打造，领域知识重新成为核心壁垒。
