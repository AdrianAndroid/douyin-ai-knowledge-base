视频主线

引子：5 月 5 日，GPT-5.5 给自己办了一场私密庆祝派对，受邀客人由 Codex 从全网推文回复里筛选，活动方案也由模型自己敲定。作者认为，让 Codex 挑客人，是 OpenAI 对自家产品的一次信任投票。
Claude 仍领先的方面：SWE-bench Pro 测试中 Claude Opus 4.7 得 64.3%，GPT-5.5 为 58.6%；Tom's Guide 七项实测 Claude 全胜；500 多名 Reddit 开发者参与的 12 轮代码盲测中 Claude 赢 8 轮；2026 年 2 月年化收入突破 25 亿美元。
Codex 反超的方面：同一份调研中 65.3% 的开发者倾向 Codex（按点赞加权达 79.9%）；开发者用量从 2% 一路涨到 2026 年 1 月的 40%，4 月首次越过 50%；4 月 8 日官宣周活跃用户突破 300 万；同一重构任务 Codex 消耗 150 万 token，Claude 消耗 620 万，相差约 4 倍。
信任崩塌的起点：3 月 23 日，有 Claude Pro 用户发帖称 “3 分钟用掉 5 小时会话 60% 的额度”，随后类似抱怨集中爆发。开发者反编译 Claude Code 的 228MB 二进制文件并抓包，发现两个问题：自定义的 bond 分支每次请求都会替换内部计费标记字符串，破坏了缓存前缀完整性；resume/continue 续跑会让整段对话缓存失效。而未缓存 token 的成本是缓存 token 的 10 到 20 倍，于是用户以为只发了一条指令，后端却把整段历史按未缓存重新计费。
Anthropic 的应对失误：工程师先在个人 X 账号非正式承认限流影响约 7% 用户，直到 3 月 31 日才有官方回应，4 月 1 日仍无正式公告，问题根源反而是社区开发者先找到的。
OpenAI 抓住窗口期：4 月 8 日官宣周活破 300 万，并承诺用户每增 100 万就重置一次额度。4 月 22 日 Anthropic 做套餐测试，把 Claude Code 从 20 美元 Pro 套餐中移除，只保留 100/200 美元 Max 套餐，几小时内因强烈反对回滚，但作者认为信任伤害已不可逆。
