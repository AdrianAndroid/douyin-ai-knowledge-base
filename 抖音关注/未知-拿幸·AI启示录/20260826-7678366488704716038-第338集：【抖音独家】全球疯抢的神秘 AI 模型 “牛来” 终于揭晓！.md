这条视频讲的是 Ox Alpha 匿名模型的身份揭晓：8 月 26 日，智谱向彭博确认，它就是自家 GLM 系列的新一代版本，并计划当天晚些时候公开权重；代号 “牛来” 也确实和电影《牛来》有关。

事件主线

8 月 20 日，OpenRouter 上出现一个没有发布会、没有论文、没有 Logo、连开发者名都没有的模型，只标着 Stealth Model，配置却很高：104.8 万 token 上下文、最高超 13 万 token 输出，支持文本、图片、视频输入和工具调用，专注代码、复杂推理和长周期 Agent 任务，而且免费，据称提供方每天准备最高 100 万亿 token 推理容量。
它迅速接入 OpenCode、Hermes 等真实工作流，上线数日登顶 OpenRouter 使用榜；截至智谱确认身份时，使用量已达 DeepSeek 的两倍以上。Stripe CEO Patrick Collison 公开评价 “very impressive”。
出圈靠的是代码能力：早期开发者用 10 道真实软件工程任务测试，它通过 8 道。但视频特意澄清，10 道样本太小；后续跑完全部 113 道，完成 66 道，通过率 58.4%，不是 80%，且属第三方测试而非官方成绩。更值得注意的是，约 80% 的任务完成了至少 90% 的目标测试，说明多数失败卡在工具调用、回归测试和 Agent 执行可靠性上，而非完全不会。

怎么被 “扒” 出来的

开发者先比对 tokenizer 对多语言代码和特殊字体的分词习惯，发现与 GLM 体系高度吻合；再故意发送错误参数，服务器返回的异常信息里露出了智谱 API 基础设施相关的 Java 类路径。视频也提到，智谱并非首次这么做：今年 2 月 OpenRouter 上的匿名模型 Pony Alpha 后来被证实是 GLM-5，之后 Hunter Alpha、Elephant Alpha 也陆续确认为中国团队作品。

作者的核心观点

作者认为，这种 “蒙面发布” 与传统发布会逻辑相反：不先宣称世界第一和跑分，而是隐去公司、国籍甚至模型名，直接投进全球最真实的代码仓库和 Agent 流，让市场用开发者检验、让工程师找 Bug，最后揭晓。对智谱来说，几十万开发者几天内抛来的真实代码、长上下文任务甚至恶意攻击，等于一场全球真实压力测试 —— 如今最稀缺的不是文本或代码，而是模型在复杂任务中 “究竟如何失败” 的反馈，免费开放 100 万亿 token 表面烧钱，实则是在购买这种反馈。

需要留意的边界

正式型号尚未公布，网传 “GLM-5.3 Flash” 等只是猜测，非官方结论；截至 8 月 26 日晚它仍免费，但各渠道数据政策不同，OpenRouter 页面称提供方可能保留输入输出但声明不用于训练，OpenCode Zen 另有说明，公司源代码、客户数据和商业机密上传前务必先查所用渠道的政策。评论区里也有用户反馈访问慢、免费已停止、性能不如其他模型，这些属于网友体验，和视频陈述的事实要分开看。
