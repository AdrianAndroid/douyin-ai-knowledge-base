这是博主「卡尔的 AI 沃茨」对 OpenAI 首届开发者大会（DevDay） 的连夜速览总结，核心是 GPT-4 Turbo 的发布和 GPT 定制化生态的开放。视频画面是大会现场，奥特曼在台上演讲，博主用口播加字幕逐条拆解重点。

模型与能力升级

GPT-4 Turbo 的上下文长度提升到 128K，知识截止时间更新到 2023 年 4 月；新增 JSON mode，能返回格式一致的输出，并具备数据检索能力。
支持图像输入的 GPT-4 Turbo with Vision 同步推出。
语音方面，发布新的 TTS 模型和语音识别模型 Whisper V3。
微调方面，GPT-3.5 可微调，长度扩展到 16K；活跃用户还能申请 GPT-4 微调。
推出 Custom Models，支持自定义训练和领域预训练，用于孵化垂直模型。

价格与 API

GPT-4 Turbo 定价为每 1000K 输入 token 1 美分、每 1000K 输出 token 3 美分，比 GPT-4 便宜约 2.75 倍；GPT-3.5 16K 比原来的 4K 版本便宜 3 倍。
API 速率限制提高，安全性增强。

重头戏：GPTs 与 Assistants API

用户可以用自然语言 “动嘴” 做出个性化 GPT，发布给别人使用或分享到社区，还能参与收入分成。
Assistants API 内置检索、代码解释器和沙盒环境，解决对话历史冗长的问题；现场演示中直接搭出了一个个人助手。
现场每位出席者获赠 500 美元 OpenAI 积分。

博主认为 GPTs 搭配 Assistants API 会打开更多可能，各类 agent 也将迎来大更新，最后引用 “we will be able to do more, to create more, and to have more” 收尾，落点是 “用 AI 解锁百倍生产力”。
