他的核心观点

开头他先摆出反差：一边是 DeepSeek 这类工具让人眼红 “搞钱”，一边是 Juniper Research 的数据 —— 线上支付诈骗金额到 2028 年将涨到 910 亿美元。他的判断是：人类自己每年都被骗走这么多，让智能体直接接管支付更危险。所以问题不是 “AI 能不能花钱”，而是 “怎么让它花得可控”。

他给的解法：x402 协议 + Zen7 的支付代理

谷歌支持的 x402 协议，是在尝试统一 AI 之间的支付标准；博主说 “看不懂不要紧，会用就行”。
Zen7 Labs 的开源项目已支持 x402 和非托管的 EIP-2612 形态。他用了个好懂的比喻：相当于给 AI 一张 “企业信用卡”，不用把整个小金库交给它，只下达规则 —— 比如这个月预算 60 块、只能买 API 数据、只能在凌晨 1 点到 5 点执行。
流程上分几层：Payer Agent 先核对这笔支付是否符合预设额度和时间范围，通过后交给 Host Agent，再由它调用 Settlement Agent 完成结算，Payee Agent 收款确认安全，任务才放行。

为什么这件事重要

他举了个很生活化的场景：智能体写行业报告时突然需要花 2 块钱买张图，如果每笔都要弹窗问你 “老板能转我 2 块吗”，那 “睡觉、坐飞机、开会时它把事全做完” 的想象就不成立。所以只有先有安全可控的小金库，智能体才算真正自主—— 学会花钱不是为了剁手，是为了解放双手。

需要说明的是，视频里的市场数据（910 亿美元、2025 年近 80 亿美元、年增 45%）是博主引用的机构预测，属于他的论据；x402 和 Zen7 项目的实际成熟度，视频没有展开验证。另外 “做实盘” 在片中并未真正演示，别把它当成量化交易的实操教程。
