这是博主卡尔的 AI 沃茨的一期实操教程：用腾讯云开发平台的 MCP 服务，两步搭出一个能自己动手干活的通用 Agent，标题调侃为 “今天偷家 Manus”。

MCP 是什么 作者把 MCP 比作 “AI 界的万能插头”，全称 Model Context Protocol。核心是让大模型用同一种 “语言” 对接外部工具，基于该协议开发的工具统一叫 mcp server。配置好后，模型会收到一份 “使用说明书”，自己判断什么时候调用哪个工具，从 “只会聊天” 变成能搜索、浏览、操作网页。

两步上手

进腾讯云开发平台，跳到 AI+ 的 MCP 栏目，挑需要的服务开通，等右侧绿灯亮起即完成。
在同一页面选 Agent 栏，模型切到 hunyuan-turbos 或 hunyuan-t1，添加 mcp server，就能开始对话体验。

想再进一步，可转到可视化开发，把 bot-id 复制进去发布成网页端，连有历史记录的对话界面都现成。

补充一点背景 MCP 由 Anthropic 在 2024 年底开源提出，之后 OpenAI 及国内多家厂商陆续宣布支持，这也是作者判断 “对话 + 操作” 会成为趋势的依据。需要说明的是，视频里 “十秒开通”“奶奶都能用” 属于博主的夸张表达，实际体验还取决于所选 MCP 服务的稳定性和模型对工具说明的理解程度。
