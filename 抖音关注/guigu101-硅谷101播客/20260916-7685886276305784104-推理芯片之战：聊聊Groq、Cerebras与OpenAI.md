这期《硅谷 101》由主播泓君主持，嘉宾是两位正在做 AI 推理芯片创业的从业者 Mark（硬件与系统架构）和徐子扬（软件与编译器）。核心结论是：推理芯片的竞争焦点已从 “算力” 转向 “带宽”，而带宽问题的本质是 “局部性”—— 数据放在离计算单元多近的地方。

局部性是贯穿全片的主线。Mark 的导师、英伟达首席科学家 Bill Dally 有句话：“计算机架构就像房地产，关键是位置、位置、位置。” 推理时每生成一个 token，都要把整个模型权重从存储读进计算单元，所以带宽成本直接决定 token 成本。

为什么训练和推理要不同的芯片

训练阶段没有直接商业回报，大家愿意赌最强集群；推理则能算清账：用户为每百万 token 付多少钱，对应硬件加电费的成本。
技术上，训练有海量数据提供并行度；推理的 decode 阶段是严格自回归的，必须一个 token 接一个 token 生成，算力用不满，卡在访存上。
GPU 的应对办法是批处理：攒一万个用户的请求一起算，代价是单个用户要等别人一起算完，延迟变高。

存储介质的三档取舍

DRAM：便宜但慢；HBM：把 DRAM 搬到芯片旁、通道多，快但贵且产能紧张；SRAM：直接做进计算芯片，最快，但一个比特要 6 个晶体管，容量比 HBM 低约两个数量级。
作者判断：Groq、Cerebras 以及 d-Matrix、MatX 等创业公司，还有谷歌 TPU、亚马逊 Trainium，都在往 SRAM 方向收敛，因为带宽的绝对值和性价比都高得多。

Groq 与 Cerebras 的分岔

两家都看到 “带宽要更便宜更高”，都选了 SRAM，但 SRAM 容量小，只能把系统做大到上千颗芯片，瓶颈随即变成芯片间通信。
Groq的思路是把调度全部前置到编译器，静态排好每个时钟周期做什么计算和通信，追求确定性；Cerebras 则用整片晶圆做一颗超大芯片，用物理距离换通信效率。
代价：Cerebras 受良率拖累，整片晶圆有瑕疵就报废，成本高；Groq 的静态调度遇上 MoE 这类运行时才决定激活哪些专家的动态结构，会出现芯片空转，但 SRAM 本身有 2—3 个数量级的性价比优势，浪费一个数量级仍划算。

OpenAI 的 Jalapeno 走了另一条路 节目最后补录了 OpenAI 与博通在录制当天（6 月 24 日）发布的首颗自研推理芯片。它没有走 SRAM，而是把 HBM4 带宽堆到单封装每秒 15.4TB，做一颗通用推理芯片，prefill、decode、attention、FFN 全包，还提出 “暗硅” 概念，按需关掉部分单元省电。原因是美国数据中心最紧的约束是电力供给而非资本，所以它优先优化每瓦 token 数。作者认为这不推翻 SRAM 判断，只是不同市场约束下收敛到不同点位。

其他值得记的点

绕过 CUDA 在推理时代 “百分之百会发生”：推理只有一个大应用（Transformer），算子写全就能跑，且 AI 辅助编程大幅降低了软件栈门槛。
判断一颗推理芯片好不好，最终看系统级的每 token 成本和单用户每秒 token 数；速度的意义不在让人读得更快，而在同样时间内让模型多想十倍。
国内创业的相对优势：成熟制程可用、供应链完善、开源模型生态开放。
