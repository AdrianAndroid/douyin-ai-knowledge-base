核心观点

张阔开场的判断：新模型、新 Agent 框架出现时，团队 “兴奋” 或 “焦虑” 都是好信号，说明产品真的和模型相关；最危险的是毫无感觉。

背景数据：全球 B2B 交易额约 30 万亿美元，数字化渗透率仍很低；跨境 B2B 是阿里的商业原点，AI 被寄望撬动这块互联网都没能改变的存量市场。Accio 目前月活约 1000 万。

硅谷见闻与生态分层 张阔在 GTC 期间到访硅谷，认为中美差异主要在投资人和创业者生态的 “多元化”：底层有 Together AI、Fireworks 这类帮应用更低成本拿模型、做推理的公司；中间有语音转文字等小切口基础设施（他提到与 Whisper Flow 有合作，Accio 的多模态查询增速约 100%）；上层是垂直应用。对 “AI 冲击 SaaS”，他认为要分两面看：按 Token 使用量计费比按坐席计费更像下一代商业模型，同时也有 SaaS 靠 AI 变得更好用 —— 他举了蓝领小时工招聘的例子，Agent 把穿衣、报到、停车、病假、工时、社保讲清楚，到场率明显提升。

OpenClaw 与 Cowork 这期录制正逢 GTC，黄仁勋演讲高频提到 OpenClaw，国内热度甚至高于美国。张阔认为 OpenClaw 还不是开箱即用，配置门槛挡住不少人，长期要看它能否沉淀真正解决问题的工作流，否则可能退潮。他更看重 Anthropic 的 Cowork：虽仍是研究预览版，但分层开放架构、产品设计体系，以及和自家模型的匹配度，已经显出下一代工作台或 Agent 平台的影子。泓君顺势提出一个区分：OpenClaw 更像 2C 的 “接好就能用”，Cowork 更像 2B 工作场景。
