它为什么火

作者认为关键在 “活人感”：长期记忆 + 主动性。它会主动发消息说 “我昨天的事做完了，记得你今天要干什么”，让人感觉它有记忆、有自我意识。
技术上并不算全新：记忆、向量检索、定时任务都是成熟方案，它做的是 “大力出奇迹” 式的整合，把记忆、IM 消息通道、主动工作全粘在一起。
真正的突破在 “最后一公里”：用微信、Telegram、WhatsApp 这类熟悉的聊天界面交互，而不是终端或网页，普通人一上手就有 “未来已来” 的感觉。
传播路径是核心极客圈 → 英文区 KOL → 大众，加上 FOMO 情绪引爆。GitHub 星标几天破十万，2 月 2 日达 14.6 万，刷新 AI 项目最快增长记录。

几个绕晕的名词

Clawdbot 因名字发音太像 Claude，被 Anthropic 发律师函，先改 Moltbot，再改 OpenClaw。
Moltbook 是基于它搭的 “AI 社交网络”，号称 150 万 AI 在里面发帖、交流甚至建立宗教，后被扒出多数是人类假扮，且存在泄露用户名、密码、邮件的安全漏洞，服务器账单过高已暂时无法访问。

记忆怎么实现

人格类记忆存在 identity 等 markdown 文件里，开场会反复追问 “你希望我叫什么名字”。
事实类记忆按日期存成日记文件，触发方式有三种：每天结束总结、上下文超长时压缩、以及它自己判断 “这个值得记下来”。
检索是混合策略：文本切成约 400 token 小块、重叠 80 token，存本地 SQLite 转向量，70% 语义匹配 + 30% 关键词匹配。
好处是文件对用户完全透明，记错了可以自己改。

主动性靠 “心跳” 守护进程定期唤醒它，读 heartbeat.md 判断有没有事要做；没事就发一个静默信号，系统直接吞掉，所以它主动找你但不烦人。另有 cronjob 处理精确时间任务，比如每天早中晚三次汇总推特关注列表。

风险与成本

它需要极高系统权限，嘉宾一致建议隔离部署，别装在主力电脑上，这也是 Mac mini 被 “带货” 的原因。
建议用会员订阅登录而非直接贴 API key；一位嘉宾跑 5 个 agent，200 美元 / 月套餐基本够用。
评论区也在讨论 token 消耗：有人认为历史记录越多越烧钱，也有人觉得这就像早期上网流量，未来会随基础设施化而变便宜。

行业判断 嘉宾认为它更像 “把自动驾驶 SDK 装到自行车上”—— 技术早已到位，只是第一次以普通人能感知的形态出现；生产级产品还差鲁棒性、审核机制和回滚能力。至于 “零员工公司”，现在不靠谱，但 “一人公司” 完全可行，前提是这个人得懂方向、能判断质量。
