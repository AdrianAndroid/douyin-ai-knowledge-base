这是一期《硅谷 101》播客，主持人泓君与 PingCAP CTO 黄东旭、张宏江（前微软亚洲研究院创始人之一、前金山 CEO）对谈，主题是：AI 行业正从 “Token Maxing”（无脑烧最强模型）转向 “Token Efficient”（经济地用 Token），背后是 Agent 工作范式的一次改革。

核心论点

市场关注点从 “模型能力” 转向 “Agent 工程问题”，从科研转向工程。
硅谷开始冷静：Uber 四个月烧穿全年 AI 预算、Meta 计划限制员工 Token 消耗；同时 DeepSeek、GLM、Kimi 等开源模型逼近第一梯队，被接入工作流。
张宏江判断 “没有泡沫”：AI 基建占 GDP 比例仍低于当年铁路网、公路网，且 Token 价格过去几年每年降约十倍。

黄东旭的一线经验（最有价值的部分）

去年 11 月起用最强模型从零构建分布式数据库 DBNine，日账单曾达四五千美金（在 Claude Code Pro Max 订阅额度用尽后额外付费），但一人三个月做出千万美金级销售额的产品，认为 ROI 极高。
他澄清 “Token Maxing 是结果，不是目标”：有设计地狂用 vs 为刷排行榜而无效调用，是两回事。
演进路径：自建 Agent 框架 → OpenClaw（个人助理向，编程上帮助有限）→ Hermes（靠 “总结成功经验成 skill” 绕开记忆难题）→ Sloc/Rough（多 Agent 聊天室式互相挑刺，一天曾消耗约 10 亿 Token、账单三四百美金）。
转折点：GPT-5.5 级模型一次解决 “蜂群讨论半天搞不定” 的问题；DeepSeek Coder V4 让本地开源模型变得实用，一台 Mac Studio 跑出约 30 token / 秒，电费约一天 1 美元，账单从日烧数千降到月两三百美金。

几个关键概念

Agentic Loop：Agent 内部循环反复调用大模型、调用外部工具，工具输出又变成上下文，长任务可跑几百步，这是 Token 消耗比 Chatbot 时代高百倍以上的工程原因。
杰文斯悖论（张宏江引用）：单价降、总量涨，市场反而更大。
Agent Native 的判断法：把 Agent 元素抽掉后，这件事若仍成立，就不是 Agent Native。

投资视角：两人看好 Agent 基础设施（memory、search、sandbox、可观测性、Agent Cloud）与垂直行业数据壁垒，认为纯 ToC 应用仍易被模型升级碾压；Minus 这类 “To Professional” 本质仍是 ToB。
