这是《硅谷 101》主持人 Yiwen 对阿里国际站总裁张阔的第二次访谈，主题是：模型榜单分数越来越高，为什么商家在实际经营中没感受到同等提升，以及 Agent（智能体）在电商里到底能接手多少活。

核心观点

张阔给了一个公式：Agent = Model × Harness，即模型能力之外，还需要一整套 “驾驭” 它的工程与业务框架。他还说 “必须是一个用得起的 AI 才是一个有价值的 AI”，并认为在预算、供应链等条件相同的前提下，用 Agent 经营一定比人做日常操作和判断更赚钱，这就是商业领域的 AGI。
团队从真实业务里整理了107 个任务，测试 AI 能否在无人干预下把活干完，以此衡量真实可用度。

为什么 Coding 跑得快、电商跑得慢

编程任务 100% 数字化，代码在 GitHub 等代码库里能被大量学习，而且对错可即时验证（能不能编译、结果对不对）。
商业场景数据更多元、没有通用流程，好坏标准因企业而异，验证周期可能是按天、周、月甚至年计，反馈闭环很长。所以 Coding 渗透率被认为接近 99%，而商业类 Agent “刚刚开始”。

Accio Work 的三个阶段

早期相当于Alibaba.com的 “AI mode”，买家可用自然语言或多模态描述需求。目前整体搜索涨 20%，多模态搜索涨 130%。
采购（Sourcing）向前后延展：从一句 query 扩展到市场调研、产品设计文档（design pack）、与供应商沟通、完成交易，张阔称之为 “agentic trade”。
今年 4 月推出的 Accio Work 走向更泛化：一站式管理多平台电商后台、供应链和员工日常经营表现。

案例：商家 Edward 他爱种植物却总把花养死，想做一款能 “告诉人自己状态” 的消费级电子产品。Accio Work 帮他做设计文档、匹配广州深圳的电子厂商、处理订船期与海关 HS code、管理物流，再到 Amazon、eBay、Shopify、TikTok 上架销售、按各平台规则做内容和定价、管理买家反馈。原本维护一张 20 列 Excel、跟十几个供应商来回沟通、以月计才能拿到样品的流程，被压缩到24 小时内出结果。供应商反馈说没见过这么专业的设计文档。人仍需做最终选择判断，属于人机协作。

中美差异与 SaaS 之争 美国 SaaS 高度垂直（CRM、广告、律师、医疗各有成熟体系），中国更多是平台内集成大量垂直功能，AI 切入的惯性不同，但最终交付目标一致。对 “Agent 杀死 SaaS” 的担忧，张阔认为 SaaS 贴近工作流、掌握企业经营上下文，若能主动用 AI 升级反而是利好；通用 AI 进企业很难自动搞懂数据含义和老板真正的优化目标。

评论区整体是正向学习氛围，不少人表示在学 AI 大模型、感慨技术发展快，也有人提醒别过度迷恋 AI；另有吐槽视频偏长、画面转圈久。
