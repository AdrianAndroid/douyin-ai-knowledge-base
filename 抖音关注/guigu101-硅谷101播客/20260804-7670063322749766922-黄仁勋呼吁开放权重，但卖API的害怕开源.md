核心观点：利益结构天然对立 嘉宾认为，开源与闭源在商业逻辑上本就对立：

卖铲子的一方（NVIDIA）：芯片和基础设施厂商乐见人人都能自由搭建模型，因为这样能卖出更多算力，它并不在乎 “谁挖到金子”。这也是黄仁勋被指责的立场出发点。
卖 API 的一方（OpenAI、Anthropic）：护城河就是模型本身，开源模型每开放一次，都会直接冲击其 API 定价与收入。

闭源内部的两条路线 作者把闭源公司分成两类：

纯 API 型：OpenAI、Anthropic，过去主要靠卖 API 赚钱，缺少其他分发渠道来对冲开源压力。
有分发与基础设施型：Meta 有 Instagram、WhatsApp 等 App 矩阵（片中举例 WhatsApp 推出 299 / 月收费版），阿里主要赚云服务，开源反而能带动云业务。

所以结论是：这不只是 “开源好还是闭源好” 的立场之争，而是结构层面的变化—— 卖算力的、卖 API 的、卖云和流量的，各自的最优解不同，利益越来越难对齐。
