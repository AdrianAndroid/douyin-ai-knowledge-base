这段视频来自「硅谷 101 播客」的访谈，标题是《AI Agent 创业哲学：技术路径决定生死存亡？》。受访者是一位斯坦福强化学习博士，他围绕 “AI Agent 创业怎么跟投资人讲、靠什么活下来” 给出了自己的判断。

核心观点一：不要试图 “卖想法”，要在共识上加一个逻辑飞跃

作者认为，跟投资人聊特别技术的项目，别一上来就讲 “我的做法跟所有人都不一样”—— 因为超前的想法往往没有共识，投资人听不懂，也不会买账。他的建议是：先利用市场已有的共识（比如 “强化学习 Agent 有未来”），再在共识之上加一个逻辑飞跃，说清楚两件事：你要解决的问题为什么有意义，以及你凭什么有 “不公平的优势”。单纯强调 “我的训练方式和别人不同” 没有意义。

核心观点二：技术路径决定能不能活，创始人和团队决定长成什么样

被问到 Genspark、Manus、ChatGPT、Fellou 这些公司谁能脱颖而出时，他给了两层回答：

分化是必然的：这些公司最后会像早期的 MySQL、OpenAI、Anthropic 一样，走向不同的专注领域，因为创始人不同，决策自然不同。
技术方向是生死线：智能体系统成本很高，很多 AI 公司的痛点是 “融了钱、增长越快、死得越快”，因为增长是入不敷出的，下一轮给投资人看毛利是负 50%，对方第一反应就是 “你什么时候能转正”。而技术提升是把毛利转正的关键，只有毛利能转正，投资人才认 “增长值得投”。

补充背景：为什么 “毛利为负” 在 Agent 行业格外致命

Agent 产品每跑一次任务都要调用大模型、消耗算力，边际成本随使用量线性上涨，不像传统软件那样边际成本趋近于零。所以 “用户越多亏越多” 在这类产品里是真实存在的结构性问题，这也解释了作者为什么把技术路径（降本、提效）看得比产品形态更靠前。

访谈后半段，主持人补充了自己的看法：技术路径选错，成本会高到短时间只能靠融资维持；很多公司估值快到 10 亿美元，被收购可能性不大，但估值偏高的小团队被收购概率挺大，接下来一到两年会是大鱼吃小鱼的过程。
