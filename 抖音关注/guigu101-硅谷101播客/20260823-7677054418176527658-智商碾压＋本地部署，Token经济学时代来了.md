这是「硅谷 101」播客的一段对谈精剪，主题是Token 经济学：嘉宾复盘自己用 AI Agent 的方式在几个月内发生的两次认知转变 —— 从 “多烧 Token、堆 Agent” 转向 “省 Token、靠强模型”，以及开源模型本地部署带来的成本结构变化。

第一阶段：从单 Agent 到 Agent 群组 嘉宾描述自己的演进路径：从自己搭 Agent 框架，到 OpenClaw、Hermes、Slock 这类工具；从单个 Agent 到 Agent 群组互相检查；从 “让它读封邮件一会儿就完” 到让它持续不停干活、干完一个马上接下一个，还要在过程中不断给自己挑错。他坦言这曾是 “今年三四月份的认知”，三个月后就迭代了。

转折一：强模型的 “智商碾压” 过去堆多个 Agent 的前提，是不相信任何单个 Agent 一次成功（One-Shot），任务一复杂或调用链一长就容易顾此失彼，所以要 “三个臭皮匠” 互相兜底。但 Fable 5 这类模型强到：群组讨论半天做不出的复杂 bug 或大功能，它没有前文上下文，一次就精准解决。作者的说法是 “烧了 10 亿 Token，不如它一次搞定”。不过他强调这是 yes and no：单点专家级难题上强模型确实能顶一个团队，但并非所有场景都如此。

转折二：开源模型变得 “实用” DeepSeek V4 让他第一次信任开源模型做复杂软件开发，GLM-5.2 又推进一步。他的用法是 “顶级模型 + 便宜聪明的开源模型” 协同，类比公司管理：不可能全公司都是资深专家，也需要大量能写代码的工程师配合，这才是更经济的方式。

本地部署的实际账 他在一台 Mac Studio 上跑 DeepSeek V4 Flash，速度约 30 Token/s，已接近在线 Chatbot 的体验。成本只剩电费和机器折旧，约一天 1 美元、满载一个月二三十美元。这解锁了两类以前 “不敢放开干” 的事：一是大量重复性日常，比如整理自己的文章记忆和数字足迹（他称之为 “自己的蒸馏”）；二是把 CVPR、NeurIPS 几百篇论文整批丢给工作流持续跑、筛出有意思的再汇报 —— 用付费 API 一批可能几百美元。

最后他点出关键其实不是钱：“并不是我掏不起这几百刀，而是会想着这个东西不受我控制”，本地跑带来的是掌控感。

评论区则在比较 Fable 5 与 Opus 5 的代码能力，高赞观点认为 Fable 5 一次通过率更高、代码能力断层领先，Opus 5 即便配上子 Agent 和顾问仍问题不少 —— 这属于网友经验，不是视频里的结论。
