这段视频是硅谷 101播客在外滩大会 “智能体时代进化论” 分论坛的切片，主持人泓君和三位创业者聊的核心问题是：智能体（Agent）的推理成本到底有多贵，以及怎么把它降下来。

成本有多贵

一次复杂的 deep research 任务通常要消耗 100 万 token 以上，单次成本：用国内模型约 3–4 美元，海外模型 8–10 美元，用更贵的方案能到十几美元。
嘉宾提到，现在 AI 公司 80%–90% 的钱花在推理上，训练成本反而在下降；对 Agent 公司来说，推理成本已经超过云成本。
对比很直观：ChatGPT 月费 20 美元，但 C 端付费率不到 5%，剩下 95% 免费用户只要用三次 deep research，平台就是亏的。嘉宾直言 “目前没看到一家 C 端公司能把成本打平”。

为什么便宜模型顶不上 复杂任务必须用顶级模型（如 Gemini Pro 级别），小模型或 Flash 级别直接端到端交付 coding 任务，质量过不了关。所以成本很难靠 “换便宜模型” 一刀切解决。

三条降本路径

模型多样化：总结、上下文压缩这类任务用便宜模型，复杂任务用强模型，按性价比混合调度。
上下文抽象：一个人的经历可能有几千万甚至上亿 token，不可能全塞进上下文，而是抽象成精简的人格画像（如大五人格分类）再使用。
自研微调：垂类 Agent 自己 fine-tune、自己 serving，成本比调 API 指数级下降，这是 C 端公司最确定的路。

另外有嘉宾推测，GPT-5 引入 Router 的核心原因就是成本 —— 用户习惯 “有好模型就用好模型干简单活”，Router 能把需求硬分到小模型上。还有嘉宾提到，为每个人训练专属模型（SecondMe）每月训练成本要几百美元，目前只在开源系统里，尚未上线。
