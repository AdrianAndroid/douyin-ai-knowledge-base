三点加速原因

写代码能力跃升：Claude 3.5 在代码生成上有质变，带动 Windsurf、Cursor 这类编程 Agent。
RLFT 强化学习微调：数据有限也能提升特定任务表现，让 Agent 在环境中自主探索路径。
MCP 协议：2024 年 11 月底由 Anthropic 提出，把传统信息服务改造成 AI 可调用的接口，底层基础设施开始搭建。

关键概念：环境 陶芳波解释，上一代 Agent 只是给大模型 “加工具”，模型训练时从未与环境互动，所以机械、难落地。新一代做法是先用推理模型打底，再把它放进电脑操作、编程、检索等环境里做强化学习，像 AlphaGo 自我对弈一样学会 “错了怎么调”。Operator 就是把点击、输入、开标签页等基本动作纳入思考过程，形成 “思考 — 执行 — 反馈 — 再思考” 的闭环，而不是靠人写死 workflow。

两位嘉宾的分歧

侯泰宇偏乐观：开发成本大幅下降，遇到场景就能造 Agent，他自己做过两百多个。

补充一点背景：MCP 常被误读成 “多智能体协作协议”，节目中明确纠正 —— 它是 Agent 访问外部信息源和服务的协议，是 AI 与服务之间，不是 AI 与 AI 之间。
