这是「硅谷 101 陈茜」对英伟达 2026 年 GTC 大会的深度拆解。核心结论是：黄仁勋不再讲单颗芯片，而是把叙事升级成 “卖 token 的 AI 工厂”，并喊出 Blackwell 与 Vera Rubin 到 2027 年底 1 万亿美元订单的目标。

一、为什么换叙事 两个背景：一是多模态和编程让推理需求暴涨，二是 OpenClaw 爆火带动全球 agent 生态，黄仁勋因此称 “推理拐点已至”。视频里 GMI Cloud 创始人 Alex Yeh 的说法是：北美需求主要来自代码生成和多模态视频、图片生成，而 OpenClaw 带来的 token 需求主要来自中国；他认为全球算力消耗连 1%—5% 都还没到。于是英伟达从 “卖卡给云厂商” 转向 “卖 token 给每家公司”，今年 GTC 的关键词是生态，不是芯片。

二、一万亿怎么算 去年 GTC 说 Blackwell 加 Vera Rubin 到 2026 年底是 5000 亿美元，今年直接翻倍到 2027 年底 1 万亿，且不含新 CPU 和基于 Groq 的 LPU。黄仁勋在闭门会解释：只算 GPU 是为了让外界直观看到增长，混入其他产品线会把两件事搅在一起。嘉宾认为这个数字是 “实实在在的订单”，相当于给 2027 年营收利润划了个底，对应 EPS 约 13—14 美元；且推理和训练需求都还在涨，CapEx 会继续上行。

三、五层蛋糕的逻辑 从下到上是能源、芯片、基建（云厂商、数据中心、供电冷却网络）、模型、应用。作者的解读是：哪一层没有绝对垄断者，利润就会被摊薄，最终回流到有垄断地位的芯片层。所以英伟达在基建层扶持 CoreWeave 这类新云对抗 AWS、谷歌云，在模型层大搞开源、办开源模型论坛，在应用层提前布局自动驾驶和机器人 —— 目的是定义规则，让市场爆发时大家还得回来买它的卡。若开源模型能做到顶尖闭源 90% 的性能、只要 10% 的价格，token 价格被打下来，卖推理的模型层被商品化，钱又回到英伟达。

四、收编 Groq 去年 12 月英伟达花 200 亿美元现金拿下 Groq 非独家技术授权，是其史上最大交易，据说黄仁勋三周就拍板，三个月后 GTC 上产品就出来了。原因是 GPU 擅长 prefill 和 attention 这类高吞吐并行计算，但 token 只能逐个串行生成、对延迟极敏感，高吞吐和低延迟天然矛盾。方案是 Rubin GPU 负责 prefill 和 attention，Groq 负责 decode 和 token 生成，一颗 Rubin 配八颗 Groq 3 LPU 组成一个推理单元，一个机架塞 256 颗 LPU。代价是 Groq 单颗只有 500MB SRAM，而 Rubin 是 288GB HBM4，差五百多倍，存不下万亿参数模型。这笔交易目前还面临反垄断潜在调查。

评论区基本是玩梗，最高赞用 “贩卖 token 和 API” 调侃大厂军备竞赛最后都落到卖算力赚钱，属于配合语境的戏谑，不是严肃结论。

想接着看的话，可以聊聊 Groq 那条 “SRAM 太小” 的短板，英伟达具体是怎么用软件把推理拆成两半绕过去的。
