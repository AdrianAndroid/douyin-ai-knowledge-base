几个主要判断

Karpathy 加入 Anthropic：田渊栋认为这释放的信号是 “自我改进、自动化研究” 成了主流方向。他提到 Karpathy 此前在推特上直播自己做自动化研究的过程，把图像和报告都开源了，很多人跟着发现这条路线可以优化；Karpathy 本人也明确说去 Anthropic 是做预训练和自动化研究。
编程工具格局：他实际用下来 “没觉得谁比谁厉害”。Codex 5.5 挺好用，Claude Code 有时会幻觉，但 Codex 并不比 Claude Code 差太多，只要 OpenAI 想追，能力和产品力都能追上，差别只在执行速度。开源侧他提到 DeepSeek V4 也不错，只是需要先 “预热” 约 1 万个 token 才变聪明。
胜负手不是新范式：代码本身已经很赚钱，接下来关键是谁能让用户愿意用，也就是产品竞争。他特别指出，两家一旦进入上市和资本叙事，逻辑就变了 —— 从 “做出惊艳的新东西” 转向收入、成本、资产负债表，赛道和以前不一样。
Meta 与 Muse Spark：他先声明自己持有 Meta 股票、说法未必客观。评价是 Muse Spark 不错，多模态和理解能力较好，但可能仍比 Gemini 3 差一点。他不认同 “Meta 放弃通用前沿模型” 的说法：内部仍是先训通用模型、再针对场景微调，否则没必要花大钱。
团队而非灵光一现：他同意姚顺宇的观点，工业级大模型靠的是各岗位把流水线跑通，差异点在 “做多细、多努力”，小细节有人注意到就多一点提升。

评论区里，有人讨论 DeepSeek 的表现和 “破卡” 适配问题，也有人感慨 AI 把几十年的发展压缩到了几年 —— 这属于网友观点，不是田渊栋的原话。
