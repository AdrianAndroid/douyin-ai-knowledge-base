核心主线：云的三次形态变化

互联网云时代：2006 年亚马逊 EC2 把算力变成像电一样按需付费的服务，形成 IaaS/PaaS/SaaS 三层。服务对象是网站、企业软件，人用应用、应用消耗算力，核心是让软件更低成本地开发部署。
大模型云（GPU 云）：2022 年底 ChatGPT 上线后，服务对象从应用变成模型。硬件基座从 CPU 服务器转向 GPU，科技巨头开启史无前例的资本开支扩张；平台层出现百度千帆、阿里百炼、谷歌 Vertex AI、AWS Bedrock 等，把训练、推理、微调封装成云服务。这一阶段优化目标是 “速度优先”—— 模型跑得更快、更便宜、更稳定。
Agent 云：2025 年下半年起，Agent 产品和底层协议密集出现，企业开始让 Agent 进入真实业务。作者引用数据称，90% 的企业表示 Agent 在实际工作中会掉链子。原因在于 Chatbot 只要快速给答案，Agent 要高质量完成任务：需要多轮推理、数量级更长的上下文、大规模分布式推理和 KVCache 存储支撑。

关键概念：Agent Harness

作者把 Harness 解释为 Agent 的 “运行底座”，位于模型之上、应用之下，负责调用 MCP、使用工具、管理长期记忆、运行工作流，并在安全隔离环境中执行任务。它存在明显的木桶效应—— 最短的那块板决定整个系统的能力，所以推理、存储、工具、记忆、沙箱、安全必须系统化协同优化。云的三层也随之改写：IaaS 对应 AI Infra，PaaS 延伸为 Agent Infra，SaaS 变为智能体应用。

产业链与市场变化

Agent 落地带动 GPU 高速互联、KVCache 超高带宽存储、超低延迟网络、向量数据库并发读写，HBM、光模块、先进封装都成了稀缺品；CPU 因负责任务调度、工具调用、跨系统协作而重新重要起来。云的核心生产资料从单一 GPU 扩展为 “GPU+CPU+HBM + 光互联”。海外 Neocloud（CoreWeave、Nebius）快速崛起，Nebius 自 2024 年 10 月复牌以来股价涨超 10 倍，今年 6 月 22 日纳入纳斯达克 100；中国则没有形成独立新云赛道，而是由百度智能云、火山云、阿里云等超大云厂商直接向 AI Native Cloud 演进。

2026 年的集体动作与 DAA 指标

微软在 Build 2026 提出 Agent 将取代 “App + 操作系统” 旧范式，推出 Agent 全栈架构；谷歌在 Cloud Next 2026 让服务五年的 Vertex AI 退役，换成 Gemini Enterprise Agent Platform，并发布 Agentic Data Cloud 和第八代 TPU。百度在 Create AI 开发者大会宣布百度智能云升级为 “面向大规模智能体应用的新全栈 AI 云”，并提出DAA（日活智能体数）。作者解释：Token/$、Token/Watt、Token/Second 这些指标衡量的是性能、效率和成本，属于 “投入侧”；DAA 关注的是有多少 Agent 真正进入企业流程、完成任务、交付价值，即 “产出侧”，也意味着单位 Token 的智能水平比 Token 数量更重要。

落地路径与验证

百度智能云的思路是按 “芯、云、模、体” 四层重构：AI 基础设施（百舸平台、昆仑芯集群、吉瓦级数据中心）、云平台（千帆词元工厂、Agent 沙箱与隔离 Runtime、长上下文记忆）、模型（从跑分转向融入业务）、研发范式（AI 自主开发、直接调用云产品接口），四层协同消除短板。验证标准是进入最难场景：已覆盖 80% 央国企、系统重要性银行和 100% 主流车企，中国具身智能云市场份额达 35%。视频中具身智能企业嘉宾提到，机器人 Agent 要求强物理交互不能有幻觉、追求 Pass@1 一次成功率，推理需 1.5 秒内开始动作，依赖百度的训练加速、千卡以上集群稳定性和运维恢复能力。
