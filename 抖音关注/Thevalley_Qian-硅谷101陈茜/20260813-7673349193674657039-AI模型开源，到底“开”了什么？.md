这条视频来自 硅谷 101 陈茜，主旨是回答标题里的问题：AI 模型 “开源” 到底开了什么。作者先以 DeepSeek V4 Pro、Kimi K3 等中国开源模型冲击美国闭源阵营为引子，再回到技术流程，拆解 “开源” 的真实含义。

核心知识：开源不等于公开代码

作者把大模型从训练到发布拆成七步：训练数据、模型架构与参数规模、训练基础设施、预训练 / 微调 / 强化学习、模型权重、部署（API 或本地）、技术报告。据此把开放程度分三档：

闭源：全部不开放，只能通过 API 或产品使用，如 Anthropic、OpenAI、谷歌的大部分模型。
完全开源（Open Source）：训练数据、训练代码、中间存档、技术报告全公开，代表是 Ai2 的 OLMo 系列。
开放权重（Open Weight）：只放出训练后的最终结果，可下载、微调、改进 ——现在说的 “开源模型” 大多属于这一类。

作者特别解释：权重本身只是一个巨大的数字文件（如 Kimi K3 是 2.8 万亿个浮点数），必须配合厂商公开的推理代码才能读取、计算、输出回答。而训练数据配方、完整训练流程仍是各家核心机密。

两个关键补充

一是许可证决定能不能商用。DeepSeek 从自定协议转向 MIT，千问转向 Apache 2.0，门槛大幅降低；Kimi K3 改用自研协议，对月活超 1 亿或月收入超 2000 万美元的产品要求展示标识，做模型托管生意且年入超 2000 万美元需另签商业协议；Meta 的 Llama 社区协议限制最多。作者提到这类条款是为了防止云厂商 “搭便车”（free ride）。

二是开放权重不等于不赚钱。作者归纳三条路径：带动云算力消费（如阿里）、私有化部署与行业定制、后训练与模型开发平台；另有模型托管厂商按授权付费，月之暗面年化经常性收入据公开信息已达 3 亿美元。
