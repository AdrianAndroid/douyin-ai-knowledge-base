这是「硅谷 101」陈茜的一期科技解读，核心讲的是 OpenClaw 这款 AI Agent 产品如何从极客圈的小众工具，被百度等大厂接入后走向大众，以及这背后的机会与门槛。

OpenClaw 是什么、为什么火

作者把它称作 “AI 圈的顶流”“这只小龙虾”。它的特点是 “有手”：能直接操作你的电脑，帮你清空收件箱、管理日历、编辑代码，甚至盯盘看股市，相当于一个 24 小时在线的 AI 助理。作者认为它爆火的原因很简单 —— 用户已经不满足于 “会聊天” 的 AI，而是想要 “能干活” 的 AI。

普通人的两道坎

一是安全：直接装在主力电脑上，AI 就有权限访问文件、浏览器 cookie、密码、API key，一旦被恶意代码攻击就可能泄露数据。这也是作者解释 “Mac mini 卖疯了” 的原因 —— 大家想用一台隔离设备来跑它。二是部署门槛：要懂 Linux、租 VPS、配环境、申请各家大模型的 API Key，对技术小白并不友好。

百度的解法

作者提到百度是国内最早接入的大厂之一：在百度 App 里搜 “OpenClaw” 就能看到一键部署入口，百度智能云在后台把环境、模型、API 都配好，用户在 App 里私信发指令，就得到一个云端助理。作者还提到，百度官宣接入两天后（视频中说的是 2 月 16 日），OpenClaw 创始人宣布加入 OpenAI，用来佐证头部玩家对技术风向反应极快。

大厂接入的附加价值

不只是降低部署门槛，还能把自家生态接进去：百度搜索的实时信息流、百度百科知识库、百度地图出行规划，以及百度优选的电商 Skill。作者举的例子是，你说 “帮我选一款性价比最高的降噪耳机”，助理就能跨平台比价、看口碑、筛评测，给出建议甚至直接下单，从 “找货” 到 “决策” 到 “购买” 全流程自动化。

作者的判断

OpenClaw 只是新一轮 Agent 产品迭代的导火索；要真正成为大众产品，还得解决使用门槛、稳定性、信任机制三件事。平台化接入是一条可能路径，让原本在硅谷技术社群流行的产品第一次进入大规模用户场景，但这不代表技术已经成熟，只是让更多人第一次接触到 Agent 形态。
