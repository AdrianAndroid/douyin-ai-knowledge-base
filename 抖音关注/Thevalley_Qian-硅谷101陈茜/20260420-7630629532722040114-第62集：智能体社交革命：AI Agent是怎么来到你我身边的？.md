支撑 Agent 的三层技术

模型层：不再依赖单一 “大脑”，改用 model router 调度多个模型。Teamily 内部编排了 200 多个模型，用十二维任务分类（效果、成本、速度、安全、隐私、合规、用户偏好等）做路由决策。难点在于任务往往模糊、多阶段，判断错反而更慢更贵。
记忆层：从早期 RAG（向量检索塞进 prompt）演进到 memory os，做结构化存储（画像、片段、预测），并解决 “什么值得长期记”“偏好会变”“上下文窗口有限” 的矛盾。业界思路包括 progressive disclosure 分层释放、Heimdallr 分层记忆、EverMemOS 生命周期架构，以及 Teamily 的 social brain—— 把记忆整理成社交图谱，帮你归类几千个好友。
协议层：MCP 解决 “能不能连”（工具、API、数据库），skill 解决 “会不会用”；A2A 解决 Agent 之间协作；ACP 解决 Agent 如何面对人类，让同一 Agent 出现在 IDE、对话框等各种界面。何朝阳称这三块拼成 “最后一块拼图”。

Agent 能力的三重变化：时间上从即用即走变成 7×24 持续在线（如 OpenClaw 的 while loop 定时检查任务）；行为上从等指令变成主动行动，甚至发帖招聘人类做线下任务；能力上通过 skill 与 experience 沉淀实现自进化，配合 harness engineering（系统提示词、工具、沙盒、评估反馈）形成闭环，用得越多进化越快。

产品路径分三类：Meta、腾讯、Slack 这类在原有社交 / 协作体系上叠加 AI 的 “延长创新”；Moltbook 这类让 Agent 主导社交的激进实验；以及 Teamily 走的 “人机共生”—— 把 Agent 做成联系人拉进群聊，能跨群记住你的过敏史并在订餐时自动避开。何朝阳判断竞争焦点会从 “谁的模型强” 转向 “谁的 Agent 更懂行业”，商业模式从卖 token 转向卖行业 Know-how。
