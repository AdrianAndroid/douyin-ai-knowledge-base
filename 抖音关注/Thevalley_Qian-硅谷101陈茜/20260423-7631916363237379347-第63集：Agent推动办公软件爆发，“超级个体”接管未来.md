主要论点

视频先回应 “AI 普及后软件工具会被淘汰” 的唱衰声音，引用黄仁勋的看法：工具使用量会迎来前所未有的增长，软件公司股价也会随之起飞；现在还没发生，是因为智能体还不够擅长使用工具。
过去用 AI 是逐个工具切换，只起到 “加一点速度” 的作用；OpenClaw 之后的新趋势是一人驱动多个 Agent 协同—— 只给一个目标，任务自动拆解、分配、执行。
用 OSWorld 近 400 个真实任务的评测做佐证：2024 年初最好的模型成功率约 12%，到 Claude Sonnet 4.6 已升至 72.1%，接近人类水平，意味着 Agent 能在真实办公环境里像人一样干活。
组织形式随之变化：人负责决策、创造、战略，AI 负责执行、复盘、调研、调度、整理，飞书这类平台成为人机协同的 “中控台”。

案例与产品逻辑 全联商业地产大会上，飞书分享了一线员工 Jason 的做法：在工作流里部署 5 个专属 AI 助理（会议复盘、客户材料参谋、调研助手、找素材、做 PPT），从会议总结到最终演示全流程覆盖；他还把过去一年约 50 万字的文档交给飞书 AI，训练出数字分身，预审文档、批阅周报时七八成意见与他本人一致，团队不增人、效率却明显提升。

支撑这套模式的是飞书三层能力：协同层把知识问答、会议、消息、文档 AI 化，自动生成纪要、提炼待办；业务层让有技术能力的团队深度定制，零代码的普通人也能搭自己的小工具；开发层开放接入 OpenClaw、Hermes 等外部模型和原生 Agent 产品 aily，并提供官方插件与 CLI 工具。
