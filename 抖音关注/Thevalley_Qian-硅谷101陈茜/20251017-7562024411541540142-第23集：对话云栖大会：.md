这是一期由 硅谷 101 出品的连线访谈，主持人是陈茜。她在硅谷远程接入 2025 年云栖大会（9 月底在杭州举办）现场，对话阿里云智能集团公共云事业部解决方案架构部副总经理、AI 加速器总经理 楼恒，以及 Pokee AI 创始人兼 CEO、Meta 前 AI 应用强化学习负责人 Bill Zhu（朱哲清）。核心话题是：AI 爆款产品从哪来、大模型下一步怎么走、Agent 在企业市场有多大空间。

一、Agent 的底层逻辑是 “工具调用” Bill 认为今年是 “AI Agent 元年”，而 Agent 的核心就是调用工具。他举了 “Strawberry 里有几个 r” 的例子：再大的模型也可能算错，但写个 Python 脚本一查就对。数据上，Grok 4 在 HLE 基准上带工具调用能到四十几分，不带工具只有 20% 多。这意味着 32B 的小模型加上工具，就能超过几十 B 的大模型，也解释了为什么 Zapier、Manus、Genspark 这类产品都往工具调用上靠。

二、展会观察：企业端 “深水区” 更赚钱 楼恒看到的是医药研发、医药报告分析、病例分析等企业应用，以及蚂蚁 AQ 这类面向 C 端的健康问诊与主动健康建议。Bill 则更看好硬件落地：AI 眼镜是公认最好的 Agent 载体，因为用户没法手动点屏幕；车企的 AI 应用进展也比他预期快，小鹏就在做车机与手机联动、用语音和 Agent 操作车辆。

三、未来 6—12 个月三个方向

多模态生成：AI 视频可能越过 “人眼难辨真假” 的临界点，鉴别难度会大幅上升（他提到 “消失的兔子” 视频曾被当成真事传播）。
工具调用扩容：目前最强模型也就撑住十几个 MCP、两三百个工具，能否出现横跨互联网的 Agent 值得期待。
具身智能：把机器人控制器的每个动作都视作 Agent 的一次工具调用，配合世界模型和强化学习训练。

楼恒补充了长记忆带来的个性化个人助理（“一百亿人可能有一千亿个 Agent”）、端侧小模型与快速推理，以及企业端从单任务 Agent 走向多 Agent 协同的 “蜂群” 状态 —— 包括 MCP、A2A、AP2 等协议标准化，Agent 甚至能 “带钱包” 做微支付，比如自动完成供应商背景调查。

四、通用 Agent 与企业 Agent 的三层格局 Bill 把 Agent 分成三层：只提供模型和工具接口的底层（代表是 Anthropic 的 Claude）；集成数千工具、可自主调用的中间层（Genspark、Manus，以及只做工具的 Arcade.dev、Composio）；深耕垂类的第三层（Clay、Decagon、HeyGen）。垂类 Agent 技术门槛最低，护城河在数据、人脉和销售资源，但企业级 Agent 目前最赚钱—— 工具少、微调一下准确率就很高，小模型即可胜任，比如 Clay 只做 “找人 — 查 LinkedIn— 发邮件” 这条外向销售链路。
