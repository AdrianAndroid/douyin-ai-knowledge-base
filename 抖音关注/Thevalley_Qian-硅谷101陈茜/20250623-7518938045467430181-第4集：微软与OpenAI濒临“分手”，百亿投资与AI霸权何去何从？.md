这是一期由「硅谷 101」陈茜主讲的财经解读，核心讲的是 OpenAI 与微软的股权谈判陷入僵局，作者判断双方 “分手” 有相当概率发生。视频引用的消息源主要是 The Information 和《华尔街日报》的爆料，属于当时谈判阶段的报道，不是最终结果。

矛盾的根源 2019 年微软首笔 10 亿美元投资时，OpenAI 极度缺钱，谈判地位被动，签下的协议对微软极为有利。如今 OpenAI 已经强大，作者认为它必然要回头解决这个 “历史遗留问题”。更根本的分歧在于：微软是传统软件公司，看重直接投资回报；OpenAI 则持续向微软要算力和资源，回报却遥遥无期。

微软手里的三张牌 累计投资约 130 亿美元后，微软拿到的是：营利部门 49% 的利润分成（并非直接持股）；2030 年前 20% 的收入分成；以及 Azure 对 OpenAI 模型 API 的独家销售权。

Altman 想改的三条 取消 49% 利润分成，换成新营利架构下 33% 的股份；2030 年后收入分成从 20% 降到约 10%；收回 API 独家销售权。作者评价这些条件 “非常苛刻”，正常 VC 投的企业不敢这样反过来逼投资方重谈条款。

Altman 的底气与双方的 “核弹” 底气来自合同里的一条：一旦 OpenAI 实现 AGI，微软将被切断访问权。而微软恰恰希望 2030 年后继续持有模型授权，所以球在纳德拉这边 —— 是否退一步换长期访问权。OpenAI 的 “核弹级选项” 是指控微软存在反竞争行为、请联邦监管机构审查合同；微软的选项则是直接离桌，把现有合约执行到 2030 年，按当前收入估算届时能分到约 350 亿美元。

时间压力在 OpenAI 一侧 据上一轮融资条款，若今年年底前无法完成非营利转营利，OpenAI 将失去包括软银在内的上百亿美元资金。作者还提到，这类大基金要的是稳定回报，更像成长型股权或 PE，而不是传统 VC，所以转型成功与否直接决定它能不能拿到钱。

作者最后感慨，两年半前 ChatGPT 发布时两家合作被称妙哉，Altman 被赶出公司时纳德拉第一时间力挺，如今蜜月期结束得如此之快；她认为微软过度依赖 OpenAI、没尽早自研领先模型，可能是纳德拉走得最错的一步。
