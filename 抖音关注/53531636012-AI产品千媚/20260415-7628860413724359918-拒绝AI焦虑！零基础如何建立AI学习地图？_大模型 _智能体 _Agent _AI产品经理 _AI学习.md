建立知识骨架宏观认知

学习新领域知识的首要任务是建立一个宏观的知识骨架。知识的沉淀过程，本质上是从骨架长出分支，再长出枝叶，最终进化为网状知识图谱的过程。在这个阶段，要避免两个常见误区：一是一上来就扎进细节，容易跑偏并浪费时间；二是一开始就规划过于宏大的知识库，因构建门槛太高而容易被劝退。

以 Agent 领域为例，其核心骨架是 “模型 + 工具 + 编排 + 运行环境”。在这个基础框架下，工具可以延伸出 MCP 和 Skill 等分支，编排则可以扩展出 Workflow、单 Agent 的各种推理模式以及多 Agent 协作等内容。有了这样的地图，再去细化学习每个模块，即使每天只学一个小知识点，思路也会保持清晰，让零散的信息各归其位。

遵循实用主义学习顺序

面对冗长的课程和繁多的知识点，明确学习的顺序和节奏至关重要。核心心法是从实用主义和解决实际问题的角度出发，避免脱离应用场景的盲目学习。

以推荐系统为例，其核心目标是解决推荐精准度的问题，因此适合采用从前到后的学习顺序：先学习召回，再学习排序，最后学习重排。如果一开始就直接扎入某个算法或神经网络，很容易越学越累且缺乏成就感。在 Agent 的学习路径上，作者建议遵循从简单到复杂的层级：

第一层级：增强型大模型，通过增加 Memory 和 Reg 等方式，让大模型具备解决实际问题的能力。
第二层级：Workflow，通过人工方式抽象业务流程，使大模型能够处理流程化任务。
第三层级：Agent，让 Agent 自主规划解决问题的路径，学习如何进行编排。
第四层级：Agent Harness，学习如何为 Agent 搭建执行环境，使其能够自主解决复杂问题。

拒绝二手信息选择一手

很多时候学习不够深入，是因为被大量为了流量或由 AI 自动生成的二手信息所包围，这些噪音严重影响了知识的质量。真正的干货往往藏在一手信息中，作者推荐了三个最实用的一手信息来源：

头部公司的技术博客：例如 Anthropic 等公司的博客，不仅包含最新的技术，更重要的是包含经过实践验证的经验，实用性极高。

打造适配阶段个人知识库

在拥有了知识脉络和高质量的原始内容后，搭建个人知识库成为促进知识关联和二次整理的关键。但在工具的选择上，应当根据自己所处的知识阶段来决定，切忌为了工具而工具，本末倒置。

在知识积累的前期（0-1 阶段），由于脑子里内容较少，建议采用通过文件夹树形结构管理知识的工具（如 YouMind），简单清晰的结构更利于入门学习；此时如果直接使用 Obsidian 等复杂工具，往往会觉得费时费力、门槛极高。随着知识的不断扩展，尤其是开始加入代码架构分析等复杂内容后，树形结构将无法满足需求，此时双向链接和图谱关系等高级功能才会成为刚需，重新启用 Obsidian 等工具便能发挥其真正价值。
