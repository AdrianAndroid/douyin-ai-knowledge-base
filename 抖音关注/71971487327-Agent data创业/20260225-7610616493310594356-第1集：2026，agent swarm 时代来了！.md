AI协作的演进
・AI协作经历了从单一Agent到Agent Swarm的四阶段演进

1. 单一Agent：一个模型一次处理一个任务，能力强但有上下文长度限制，复杂任务易崩溃

2. 串行Agent：流水线式处理，上一步完成后再启动下一步，但会卡在最慢环节，且任何一步出错都会导致全链路崩溃

3. Agent Teams：有Leader的团队模式，预定义角色并分工协作，Leader负责任务分配与结果整合

4. Agent Swarm：无需预定义角色，仅给目标即可自动生成专业Agent并行探索，最后由Synthesizer聚类归纳结果

Token成本陷阱与控制
・多Agent系统需通过三大原则控制Token成本

1. 成本陷阱：无约束的多Agent系统成本会指数级增长，部分任务Token消耗超200万，是单Agent的15倍

2. 控制原则：限制Agent数量、控制工具调用范围、设计精准的合成策略

3. 节省方法：采用模型分级路由（简单任务用小模型、复杂任务用大模型）+Context压缩和摘要，可节省30%-50%Token
