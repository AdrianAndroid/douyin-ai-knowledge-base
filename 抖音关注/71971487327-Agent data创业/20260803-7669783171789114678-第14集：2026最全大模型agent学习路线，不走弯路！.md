这是 AgentAlpha 创客星球 发布的一期 Agent 求职学习路线讲解。作者的核心观点很明确：求职不是读博，不用把 RAG、多智能体、强化学习等十个模块全学一遍，而是先打牢基本盘，再挑一个方向做深。他把路线拆成 “必学、加分、专项” 三层，并给出每层的验收标准。

第一层：基础盘（没有它，简历都过不了）

RAG 全链路：作者称这是最核心、没有之一的部分，90% 的面试第一问都从这里开始。要搞懂固定长度、语义、递归等分块方式各自适用什么场景，稀疏检索、稠密检索、混合检索三者的区别，以及答案怎么溯源、怎么让模型不编造来源。验收标准是：能从零搭一个带引用的知识库问答，并用 RAGAS 跑一次评测，说清召回率和忠实度。
工具调用与 function calling：重点在 schema 怎么写、参数怎么约束、工具结果怎么喂回模型继续推理、调用失败怎么办。
单 Agent 核心循环：吃透 ReAct 的 “思考 — 行动 — 观察” 循环，再理解 self reflection（自我反思）怎么检查并修正输出。
Memory 记忆系统：短期记忆、事件记忆、语义记忆要能说清，更关键的是哪些信息值得存进长期记忆、怎么和当前上下文融合、对话太长怎么压缩。
工程化部署：作者说这是 “分水岭”。项目不能只在本地 Notebook 跑，要封装成 API、支持流式输出、用 Docker 一键部署，有数据库、日志和错误处理，否则面试一问 “并发上来了怎么办” 就答不上来。

第二层：加分项（拉开差距） 多 Agent 协作（角色分工与编排思想，状态机、条件跳转、失败回滚比用哪个框架更重要）、MCP 模型上下文协议（作者比喻为 “电脑的 USB”，统一接入外部工具和数据的标准接口）、DeepSearch（和传统 RAG 的区别是 “边想边搜”，推理过程中动态决定搜不搜、搜什么、搜几次，还有文档内推理）。

第三层：专项方向（选一个做深）

Code Agent：仓库级代码理解，函数调用图、依赖图，代表框架 SWE-agent、RepoMaster，适合喜欢写代码的人。
推理优化：KV Cache、PagedAttention、连续批处理、量化，工具如 vLLM、SGLang，适合偏后端、对性能敏感的人。
Agentic RL：把搜索和工具调用当作强化学习的动作来训练，代表工作 Search-R1、GRPO。作者特别提醒门槛高，零基础别一上来就冲。
