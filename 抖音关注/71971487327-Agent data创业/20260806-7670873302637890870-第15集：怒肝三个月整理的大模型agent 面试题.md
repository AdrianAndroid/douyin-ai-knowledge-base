六大模块的问题清单

RAG 类（作者称 “重中之重”）：完整流程及各步作用、文档分块策略及选型理由、稀疏检索与稠密检索的区别、混合检索怎么做、Rerank 为什么能提升效果、用过哪些 Rerank 模型和评测框架、RAG 幻觉怎么解决、向量数据库用过哪些。
Agent 架构类：作者强调 “先问范式再讲分工”。包括 Agentic RAG 与传统 RAG 的区别、什么时候值得上更复杂的方案、ReAct 范式、单 Agent 与多 Agent 的区别及何时用多 Agent、多 Agent 常见角色与分工、LangGraph 和 AutoGen 的区别；最后问控制 —— 怎么避免失控、有限状态机是什么及在编排里怎么用、自我反思怎么做、有什么价值。
工具调用类：Function Calling 的原理、调用失败怎么处理、怎么保证参数准确、返回结果太长怎么办。
Memory 类：记忆分几种、长期记忆怎么存、怎么检索、对话历史太长怎么压缩。
工程落地类：项目怎么部署、有没有用 Docker、流式输出怎么实现、并发上来了怎么优化、怎么监控 Agent 运行状态、vLLM 了解过吗、连续批处理的原理。
开放性问题：项目最大难点及解决方式、重做会怎么优化、Agent 集群落地最大瓶颈、最近关注的技术（如 Graph Engineering）。

作者给的两条核心建议

一是项目经历要能在 3 分钟内讲清背景、方案设计、亮点难点、自己的判断和量化结果，最好有上线经历，背熟到不卡壳。二是求职最短路径不是收藏文章，而是打牢基本盘 + 做一个完整项目 + 选一个专项深扎。作者认为面试官只看三件事：代码能力、是否真做过项目、对技术有没有自己的思考。
