这是「晚点聊 LateTalk」的一期播客对谈，主持人是曼琪，嘉宾是 MIT 博士生 杨松琳—— 她是 DeltaNet 的核心贡献者之一，也是线性注意力开源小组 FLA 的发起者。全片约 87 分钟，主旨是：线性注意力不只是省算力的提效手段，在数据受限的场景下还有被低估的潜力。

核心知识脉络

注意力机制是什么：本质是 "序列混合"—— 把不同位置的信息混合起来，预测下一个词。原始 Softmax Attention 是两两 token 直接交互，复杂度是平方级；线性注意力则是把 Softmax 去掉、写成 RNN 递推形式，把成本压到线性。
DeltaNet 的来龙去脉：2021 年 ICML 论文《Linear Transformers Are Secretly Fast Weight Programmers》提出，用 Delta Rule 替代 Hebbian 更新，增强 "上下文检索" 能力。但当时没火，原因有二：一是缺少短卷积、输出归一化、输出门控这些现代网络模块；二是官方实现是循环写法，速度很慢。
杨松琳的关键贡献：她 2023 年 9 月开始琢磨怎么并行化 DeltaNet 的递归，2024 年 3 月想通 —— 把累积项对应到数值代数里的 Householder 矩阵累积，用经典 WY 算法把 "累积" 变成 "累加"，正好和线性注意力的分块算法兼容，于是 DeltaNet 可以大规模训练了。之后她在 OpenAI 实习做出 Gated DeltaNet，相当于 DeltaNet + Mamba2 的结合，加入衰减（遗忘门）。
业界落地：阿里 Qwen3-Next 混用 Gated DeltaNet 与 Gated Attention；Kimi 的 KDA 是 Gated DeltaNet 的改进版，把粗粒度衰减改成每个维度独立的细粒度衰减。作者认为 Qwen 和 Kimi 是目前公开在推线性注意力的两家主要厂商。

两个值得记住的判断

为什么都做混合架构：线性注意力每层 hidden state 大小固定，整体容量是常数，长文本下会 "记不住"；Full Attention 的 KV cache 随 token 线性增长，容量够但推理是 memory bound、越来越慢。混合是拿 75% 的层换成 RNN 类结构，KV cache 直接砍掉约四分之三，从而支持更大 batch。
MiniMax 为什么退回 Full Attention：M2 主推 Agent 能力，而多跳推理（A→B→C→D）这类长程任务，线性 / 混合架构把中间表示压缩到模糊 state 上，准确率会掉；MMLU 这类短程任务则看不出差别。作者补充，MiniMax 之前用的 Lightning Attention 是很弱的线性模块，加的是与输入无关的粗粒度衰减，直接 scale 到几百 B 可能内部验证不够扎实。

关于 "无限算力还需要线性注意力吗"，她的回答是：还要看数据。Full Attention 没有归纳偏置，数据充足时学得更好，但数据受限时反而是劣势；高质量数据已被绑住，后训练、RL 场景数据更少，混合架构的优势可能在这里体现。另外 DeltaNet 在计算复杂度理论上属于 NC1，强于 Transformer 的 TC0，做状态追踪类任务（如代码变量维护、Agent 操作状态）可能更省思维链。
