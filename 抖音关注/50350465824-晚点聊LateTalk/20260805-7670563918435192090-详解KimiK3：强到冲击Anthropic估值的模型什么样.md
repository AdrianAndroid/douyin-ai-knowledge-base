这是一期《晚点聊》的技术播客，主持人曼奇请来 RadixArk 创始成员、SGLang 核心开发者赵晨阳和华盛顿大学博士生曾致远，从推理工程和算法两条线拆解 Kimi K3。核心结论是：K3 是首个达到 3T 级（2.8T 总参数、104B 激活）的开放权重模型，被两位嘉宾称为 “里程碑级别成果”，但它开放的只是权重，不是造下一代模型的流水线。

架构：没有 “老老实实的 Transformer” 赵晨阳用 “特修斯之船” 打比方：K3 的注意力是线性注意力 KDA 加全局注意力 MLA 的混合，残差改成深度方向上的 attention，FFN 是压缩空间里的稀疏专家，位置编码几乎被删掉。船板、甲板、龙骨都换了，船名还叫 Transformer。由此引出的启发是：全注意力与线性注意力不是二选一，混合架构才是可行方向。K3 用约 3:1 的比例（三层 KDA 配一层全局注意力），把此前 Kimi Linear 在 48B 小模型上验证的方案放大了约 60 倍。

几个关键技术点

KDA 的效率：百万 token 上下文下解码速度约为全注意力架构的 6.3 倍（该数字出自 Kimi Linear 论文，非 K3 报告严谨值）。代价是固定大小的循环状态存在容量瓶颈，早期细节会被覆盖，靠周期性全局注意力缓解。
Quantile Balancing：MoE 路由均衡的新做法。相比 DeepSeek V3 用固定步长调 bias，K3 直接按路由分数分布的分位数算出该调多少，被认为是大规模训练稳定的关键之一。
Per-Head Muon 优化器：对每个注意力头单独做正交化，避免大尺度头主导更新。
Attention Residuals：把 attention 旋转 90 度，让深层可以主动 “检索” 浅层表示，解决残差流信息被稀释的问题。
后训练：先训九个领域专家模型，再用多教师在线蒸馏（MOPD）合并成一个，目的是让各团队解耦、各自迭代。

开源争论与 “护城河” 节目也讨论了 K3 在美国引发的震动：有观点认为强开放权重模型会冲击 OpenAI、Anthropic 的估值，因为企业可以把模型部署在自己环境里、不必把数据交给第三方。赵晨阳的判断是：权重是一次训练的产物，环境才是能反复产出下一代权重的流水线；K3 开放了权重和部分基础设施，但路由环境、自我演化知识图谱等没有开放，迭代速度的差距未必缩小。

使用体感：两位嘉宾都提到前端 / 长程 agent 任务表现突出（Kimi 曾在 frontend code arena 登顶），但速度偏慢、价格也不再走极致性价比路线；晨阳认为这是新架构 serving 栈尚未优化到位，属可优化范围。
