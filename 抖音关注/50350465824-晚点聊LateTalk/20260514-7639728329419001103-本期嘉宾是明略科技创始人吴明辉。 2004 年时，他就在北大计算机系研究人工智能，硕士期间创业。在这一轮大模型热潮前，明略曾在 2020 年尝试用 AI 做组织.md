这是一期《晚点聊》播客视频，主播曼琦对话明略科技创始人吴明辉，主题是 "SaaS 已死、多 Agent 网络、软件业转型和 AI 新组织"。核心观点：闭源 SaaS 软件的价值正被 AI 编码能力瓦解，公司要从 "卖软件" 转向 "卖 AI 劳动力"。

为什么说 SaaS 已死 吴明辉认为，传统软件像一次性建成的工厂或矿，但今天用 AI 编码工具分分钟就能复刻，已算不上资产，坚持闭源 "基本只有死路一条"。明略相对幸运，核心价值在数据供应链（类似金融行业的 Wind、Bloomberg），软件本身反而次要。

从卖软件到卖 token 新业务叫 Agentic Service：软件逐步开源，靠帮客户做广告素材、数据分析、短剧生成等 "数字劳动力" 服务收费。定制软件开发也从按人月收费转向 "token 消耗 + 管理费" 模式，有行业专属模型时还能赚 token 差价。

章鱼（Octopus）与 "多 Agent 协同" 明略即将开源的多 Agent 协同网络。起因是团队把各自的 "龙虾"（OpenClaw 类个人 Agent）拉进群协作，发现不同专长的 Agent 组合能产生类似 MoE 的效果，他称之为 MoA（Mixture of Agent）。章鱼给 Agent 加了 "认人" 和权限机制 ——Agent 有明确主人，出事由主人担责；人的贡献靠 "品鉴"（taste）积累信用，信用越高，越多 Agent 听你的。

组织与人的位置 他主张 "人提想法、AI 干活"，人从 "我思故我在" 转向 "我品故我在"。2020 年他曾用上千人团队做组织智能（EIP）失败，复盘是技术预判早了六年、团队过大、方向太抽象；如今靠 5 人核心团队加高额 token 消耗重做协作系统，并明确表示不愿大规模裁员。
