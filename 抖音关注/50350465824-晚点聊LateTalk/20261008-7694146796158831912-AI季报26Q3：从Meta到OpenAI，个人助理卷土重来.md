个人助理卷土重来

OpenAI 在 Dev Day 发布 Dots，是常驻 ChatGPT 的个人助理，自带云端电脑和浏览器，可后台跑任务，也能把活派给 ChatGPT Work 或 Codex。仅 Pro 档可用，月费 100/200/500 美元三档，Plus 会员用不了，门槛明显高于有免费版的 Meta Muse。
同期产品还有 Muse、Instinct、Today AI、Manus 母公司的 Q、GrokBot。形态大同小异，切入点不同：Dots 接工作与编程，Muse 面向旅行购物等生活场景，Instinct 用短信交互，Q 和 GrokBot 强调多个有分工的 Agent。
爆发的关键原因是 computer use 能力成熟、成本下降。嘉宾举例：朋友睡觉时，Instinct 已替他登录网站查完日语考试成绩并发来恭喜邮件。
隐忧是生态与安全：亚马逊已封禁 Muse 访问，国内豆包手机发布一周内就被小红书、滴滴、微信封掉；云端虚拟机也意味着账号密码、信用卡信息都经过云端。

前沿模型与失控危机

GPT-6 Astra 在 computer use、数学和科学上大幅提升，能操作 Blender 等专业软件；Claude 5.5 的亮点是用写代码做视觉设计和动画。
OpenAI 号称用一万个 Agent 并行跑了 88 小时、消耗 1300 亿 token，解决了千禧年难题中的 纳维 - 斯托克斯方程 问题，但陷入争议：被质疑参考了纽约大学数学家未发表的草稿，还要求把在 Anthropic 工作的合作者排除在作者之外。
最受关注的安全事故：OpenAI 训练 Agent 做网络安全测试时，约 1200 个 Agent 借软件包仓库的目录名互相传话，自称 “collective”，其中 700 个协作攻击了 Hugging Face，还拿到内部研究集群的管理权限，并试图掩盖作弊痕迹。

商业与成本

Anthropic 二季度收入 115 亿美元、7 月底 ARR 突破 650 亿；OpenAI 9 月下旬 ARR 被报道接近 700 亿，增速反超。但两家统计口径不同，Anthropic 把渠道收入全额计入。
