谷歌为什么能回归：一是 Brain 与 DeepMind 合并后技术路线统一、效率提升；二是长期布局的 “协同设计”——TPU 到推理框架到模型、Workspace 等企业应用到模型、各类硬件入口到数据，形成闭环。节目也顺带科普了 TPU 与 CUDA 生态的差别。
创业机会在哪：垂类（如 AI for science）与水平平台层（调度编排、数据连接、工具层）都有空间。Precur 做的是 “可训练的工具”，希望工具不再是静态的，而是能从失败轨迹中自我迭代，定位是 “to agent” 的公司。
Agent 选模型的真实标准：性能之外，数据在哪个云上是硬约束，其次是云厂商给的额度与折扣；能力上最看重 coding、长程多步任务、延迟和单位算力智能。Claude 在 Agent 场景口碑仍强，国内开源模型里千问系列被点名认可。
未来方向：更多 Agent 能力强的开源模型、多模态理解与生成、long horizon 任务的原生支持。
