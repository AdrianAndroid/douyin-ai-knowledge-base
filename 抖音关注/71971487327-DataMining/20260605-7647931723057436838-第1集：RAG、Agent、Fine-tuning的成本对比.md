这是「AgentAlpha 创客星球」的一条成本量化科普视频，核心观点是：RAG、Agent、Fine-tuning 不是互相升级的关系，而是三种不同场景的方案，成本量级差别很大，不要一上来就三个全叠。

作者的核心判断 Agent 不是 RAG 的升级版，而是完全不同的使用场景。同等任务下，Agent 的 Token 消耗是单次调用的 6—10 倍，API 调用次数约 5 倍，这直接决定了成本量级。

三种方案的成本与适用场景

方案	开发周期	运行成本	适合任务
RAG	用 LlamaIndex 或 Dify 搭标准 pipeline，1—2 周上线	gpt-4o-mini 接向量检索，1000 次查询约 2 元；Chroma/Qdrant 自托管软件免费，单节点每月几十到两三百元；Pinecone 托管标准计划每月起步 50 美元	知识检索型：客服 FAQ、内部文档问答、产品说明查询
Agent	4—8 周起步，要处理多步推理状态保存、工具调用失败重试、ReAct 循环上下文管理	RAG 跑一次约 1 元的任务，5 步 ReAct Agent 跑完约 6—10 元，任务越复杂、工具输出越长倍数越高	多步执行型：监控数据触发告警再生成报告、抓竞品价格再更新定价策略
Fine-tuning	数据准备是最大隐性成本，5000 条高质量指令对起步，通常要 1—2 周以上整理	GPT-4o 微调每百万训练 token 25 美元；Qwen、DeepSeek 官方没有公开统一训练价，需按 GPU 资源估算	行为固化型：统一输出格式、训练特定口吻、压缩推理时 prompt 长度

选型原则：问 “查什么” 用 RAG；问 “做什么连续动作” 用 Agent；问 “模型总是以某种方式答错” 用 Fine-tuning。三个叠加，成本也叠加。

需要说明的是，以上价格和周期都是作者给出的经验估算，不是官方报价，实际会随模型版本、调用量和服务器配置浮动；Qwen、DeepSeek 的微调成本作者也只给了 “按 GPU 估算” 的口径，没有具体数字。

先纠正一个常见误解：Agent 属于另一类场景，Token 消耗是单次调用的 6—10 倍、API 调用约 5 倍，成本量级由此拉开。

开发用 LlamaIndex 或 Dify 搭标准 pipeline；运行侧讲 gpt-4o-mini 加向量检索的查询成本，以及自托管与 Pinecone 托管的费用差别。

难点在多步推理的状态保存、工具调用失败重试和 ReAct 循环的上下文管理；同一任务从 1 元涨到 6—10 元。

5000 条高质量指令对起步、1—2 周以上整理人力；训练侧给出 GPT-4o 每百万 token 25 美元，国内模型需按 GPU 估算。

按 “查什么用 RAG、做什么连续动作用 Agent、模型总以某种方式答错用 Fine-tuning” 对号入座，并提醒不要三个方案全叠。
