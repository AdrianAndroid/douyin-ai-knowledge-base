这是「技术爬爬虾」介绍开源信息聚合工具 Follow 的教程视频，核心观点是：用一个免费工具把文章、视频、播客、图片和公众号统一订阅到一个收件箱里，摆脱算法推荐和来回切换 App。

它是什么、为什么火 Follow 基于 RSS（简易信息聚合）技术，在 GitHub 上同时登顶日榜、周榜、月榜，作者称它是自己心中的年度最佳软件。视频提到它已开启公测，大部分功能无需激活码。作者认为 RSS 这种无广告、按需拉取的方式本质上是 “反算法” 的，正因不利于大厂收割用户，如今很少有网站还提供 RSS 订阅，所以称它为 “失落神技”。

技术原理 Follow 的作者此前开发过 RSSHub，用爬虫扫描网站、把信息组装成 RSS 消息，宗旨是 “让天下所有网站都接入 RSS”。所以 RSSHub 是底层基础，Follow 是上层应用：它保存用户订阅的 RSS 地址，按固定频率自动检查更新，再把内容转成易读格式。

上手流程

浏览器打开 follow.is，点 Get Started，选 GitHub 登录（视频里提到主页专栏有 GitHub 加速的免费课程）。
点加号搜索信息源，选中后点 follow、选类型（文章 / 视频 / 音频 / 图片）、再点订阅，订阅会出现在左侧导航栏，带未读数、刷新、仅显示未读、全部标为已读。
若网站本身支持 RSS，复制其 RSS 链接，在加号里选 RSS 粘贴、预览后订阅。
视频博主、播客、图片同理，分别选视频、音频、图片类型；播客可直接在右下角网页播放器播放。
公众号需先用 vvRSS 项目把公众号转成 RSS 链接（作者部署在自己的家庭服务器上），再粘贴进 Follow。

评论区在聊什么 大家普遍把它和 RSS 联系起来，感慨 “20 年前的东西” 又回来了，也提到 Google Reader 停服后内容聚合形态的变化；有人认为是 RSS 挡了广告财路才被冷落，也有人认为关键还是内容源和大厂是否支持。另有提问集中在是否支持安卓、是否收费、能否订阅抖音博主。
