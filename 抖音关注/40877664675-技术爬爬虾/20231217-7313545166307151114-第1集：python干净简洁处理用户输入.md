这是「技术爬爬虾」的一条 Python 编程技巧视频，讲的是用 match 语句替代一长串 if/elif，干净地处理用户输入。

代码主线

先定义两个函数：do_this() 打印 "do this"，do_that() 打印 "do that"。
用 match input("what you want to do:") 接收用户输入，再按输入内容分派：
case "this": → 调用 do_this()
case "that": → 调用 do_that()
case _: → 兜底，打印 "invalid input"
终端演示里输入 this，输出 do this；最后输入一个无效值，走到 case _ 分支，输出 invalid input。

关键点解释

match ... case 是 Python 3.10 才引入的结构化模式匹配语法，这里的用法接近其他语言的 switch。case _ 中的下划线是通配符，表示 “其他所有情况”，相当于 else，用来兜住非法输入，避免程序没有响应。相比层层嵌套的 if/elif，这种写法分支一目了然，增删选项也更省事。

需要注意，match 是精确匹配，用户输入的大小写、前后空格都会影响结果，实际项目里通常还要配合 strip()、lower() 做规范化。
