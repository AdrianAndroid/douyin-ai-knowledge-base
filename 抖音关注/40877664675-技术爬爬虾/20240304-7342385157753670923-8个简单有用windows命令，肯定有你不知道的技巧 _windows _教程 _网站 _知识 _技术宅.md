彻底擦除磁盘空间
清空回收站后，文件并未真正从硬盘擦除，而是标记为空闲状态，使用技术手段仍可恢复。若想彻底擦除文件防止被恢复，可以在命令提示符（管理员身份运行）中输入 cipher /w:盘符: 命令。其原理是通过写入一个巨大的临时文件来覆盖磁盘空间，使已删除的文件彻底无法恢复。

加密解密重要文件
利用 cipher 命令还可以对重要文件或文件夹进行加密保护。输入 cipher /e 文件路径 即可完成加密，成功后文件右上角会显示一把锁，且密钥与当前 Windows 账号绑定，没有密钥则无法查看内容。若要解密，只需将命令中的 /e 替换为 /d。此外，添加 /s 参数还可以对整个文件夹及其内部所有内容进行批量加解密。

查看局域网IP信息
在网络管理中，ipconfig 是一个非常基础且实用的命令。执行该命令后，显示的 IPv4 地址即为电脑的内网 IP 地址，而默认网关则通常是路由器的 IP 地址，直接在浏览器访问该网关 IP 便可进入路由器的设置页面。

查询当前公网IP信息
若想查看当前网络的公网 IP 及所在城市等信息，可以利用命令行的网络请求工具 curl。在 CMD 中输入 curl ipinfo.io 命令，系统会向指定网站发起请求，并在界面返回当前的公网 IP 地址及相关的地理位置信息。

排查网络链路故障
当遇到网络连接问题时，可以使用 tracert 命令进行路由追踪。例如输入 tracert www.baidu.com，该命令会输出本地到目标服务器所经过的所有网络链路信息。通过分析每一跳的延迟与 IP 地址，可以有效排查出具体是在哪个网络节点出现了故障。

查看已连WiFi密码
对于曾经连接过的 WiFi 网络，系统会保存其配置信息。在 CMD 中输入 netsh wlan show profiles 可以列出电脑上所有连接过的 WiFi 名称。若要查看某个特定 WiFi 的明文密码，只需接着输入 netsh wlan show profiles name="WiFi名称" key=clear，在 “关键内容” 一栏即可找到对应的密码。

启用IE浏览器脚本
虽然新版 Windows 系统已停止对 IE 浏览器的支持，但部分特定的老旧网站仍需使用它来访问。可以通过创建一个简易的 VBS 脚本来重新启用 IE：新建一个文本文档，将特定的脚本命令粘贴进去，最后将文件的后缀名改为 .vbs。双击运行该脚本文件即可成功打开 IE 浏览器。

绕过系统强制联网
在安装 Windows 11 时，系统通常会强制要求联网并登录 Microsoft 账户，且在无网络环境下 “下一步” 按钮会处于灰显状态。为了绕过这个限制，可以在安装界面按下 Shift + F10 调出 CMD，输入 oobe /bypassnro 命令并回车。电脑重启后，安装页面就会多出一个 “我没有 Internet 连接” 的选项，点击即可继续进行离线安装。

扫描修复系统文件
当系统出现异常（例如资源管理器崩溃或关键系统文件缺失）时，可以在 CMD 中运行 sfc /scannow 命令。该指令会自动扫描 Windows 中的所有关键文件，并尝试修复缺失或损坏的部分。修复完成后，打开任务管理器并新建任务输入 explorer 即可重启资源管理器，使修复生效。
