本视频展示了如何在 Windows 系统的 Linux 子系统（WSL）中，通过 Docker 运行 macOS 虚拟机的 “套娃” 部署过程，适用于跨平台软件开发与兼容性测试。

00:00
开启系统虚拟化功能
首先确保 CPU 虚拟化已在任务管理器中开启，接着在 Windows 功能设置中勾选 “适用于 Linux 的 Windows 子系统” 和 “虚拟机平台”，完成后重启电脑。

01:15
安装WSL并配置系统
以管理员身份运行命令提示符，使用 wsl 命令安装默认的 Ubuntu 发行版。安装完成后，在 Windows 用户目录下新建.wslconfig 配置文件，添加相关配置以允许虚拟机嵌套。

02:24
安装Docker Desktop
下载并安装 Windows 版的 Docker Desktop，进入设置界面确保勾选了 “Use WSL 2 based engine” 以及 Ubuntu 的 WSL 集成选项，保存并重启服务。

03:34
安装KVM与依赖工具
在 WSL 终端中，先更新 apt 索引，随后安装 KVM 虚拟化工具及相关依赖。验证 KVM 安装成功后，再安装 x11vnc 远程桌面控制软件。

04:10
拉取镜像并运行容器
复制并修改对应的 Docker 运行命令，将镜像地址替换为阿里云私服地址以确保顺利拉取。在终端执行修改后的命令，等待镜像下载并启动虚拟机。

05:17
格式化虚拟磁盘并安装
在弹出的 QEMU 窗口中打开磁盘工具，选择最大的虚拟磁盘进行擦除格式化并命名。随后选择重新安装 macOS，一路确认并选择刚创建的磁盘进行系统安装。

06:08
配置系统并创建账号
等待安装完成后，系统会进入最后的配置阶段。一路点击继续并跳过不必要的步骤，无需登录苹果账号，最后创建自定义的用户名和密码即可进入系统。

06:32
保存系统状态与重启
直接关闭虚拟机窗口即可停止运行，此时 Docker 容器及其中的更改会被保留。下次需要使用时，可通过 “docker start -ai [容器 ID]” 命令直接重启该虚拟机。
