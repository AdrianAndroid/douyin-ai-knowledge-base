这条视频讲的是 Python 循环里的 break 和 continue 到底有什么区别，用一段遍历编程语言列表的代码现场演示。

演示用的代码 列表 languages = ["C++", "JavaScript", "Java", "Ruby", "Rust"]，用 for language in languages: 逐个打印，最后再打印一句 Done。

两个关键字的差别

break：在循环里判断到 language == "Java" 时直接终止整个循环，所以输出只有 C++、JavaScript，后面的 Ruby、Rust 都不再执行，但循环外的 Done 照常打印。
continue：同样在 Java 处触发，但它只跳过这一次，不执行本次剩下的 print，然后继续下一轮，所以输出是 C++、JavaScript、Ruby、Rust、Done，唯独少了 Java。

一句话记：break 是 “整个循环不干了”，continue 是 “这一轮不干了，下一轮继续”。两者都只影响当前这一层循环，嵌套循环里想跳出外层得靠标志位或 for...else 之类的写法。
