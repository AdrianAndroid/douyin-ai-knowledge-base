这是「技术爬爬虾」的一条 Python 入门演示：用 pyautogui 这个库，几行代码就能让程序自动移动鼠标、自动打字。标题说的 “一行代码” 是夸张说法，实际要先装包、再写调用语句。

操作流程

打开终端，先更新工具：pip3 install --upgrade setuptools，再装库：pip3 install pyautogui。
代码里 import pyautogui as pag 导入。
控制鼠标：pag.moveTo(x, y) 传入屏幕坐标，运行后光标自动滑到该位置。
控制键盘：pag.write("hello world", interval=0.5)，第二个参数控制每个字符的输入间隔，视频里设成 0.5 秒，运行后文字就一个个 “敲” 出来。

评论区两个高频疑问

下载包版本不一样：有人从官网装，发现和视频里的不同。其实 pyautogui 版本会持续更新，视频录制时的版本未必是当前最新版，功能接口基本一致，不必执着找 “同款包”。
坐标从哪来：moveTo 用的是屏幕绝对坐标，左上角为 (0,0)，单位是像素。想知道某个位置的坐标，可以用 pag.position() 实时打印当前鼠标位置，或 pag.displayMousePosition() 开一个跟随显示坐标的小窗口，把鼠标移到目标点读数即可。

要注意的是，这类脚本会真实接管你的鼠标键盘，运行前最好留好中断方式（比如把鼠标快速甩到屏幕左上角触发 pyautogui 的防故障机制），别让它在你没准备时乱点。
