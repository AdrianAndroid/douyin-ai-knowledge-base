视频里的两种写法

常规思路（00:09 起）：新建空列表 new，遍历旧列表 old，用 if item not in new 判断，不在才 append 进去。运行后打印结果，重复元素被去掉，顺序不变。
一行写法（00:23 起）：new_list = list(dict.fromkeys(old))。先把列表转成字典，再转回列表，结果同样是去重且保序。

为什么这样能保序

关键在于 Python 3.7 起字典保证插入顺序。dict.fromkeys(old) 会按 old 中元素首次出现的顺序建键，重复的键被自动合并，所以转回列表后顺序自然保留。视频里作者说 “去重并且排序好的”，这里的 “排序” 其实是 “保持原有顺序”，不是按大小重新排。

一个小提醒

dict.fromkeys() 要求元素可哈希，列表、字典这类不可哈希的元素会报错；常规循环写法则没有这个限制。另外，一行写法虽然简洁，但可读性上不如循环直观，团队代码里要看场景取舍。
