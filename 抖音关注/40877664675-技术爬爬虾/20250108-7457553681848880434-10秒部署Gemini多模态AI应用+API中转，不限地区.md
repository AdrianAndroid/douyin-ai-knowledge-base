本视频介绍了如何利用开源项目在 10 秒内免费部署一个基于 Google Gemini 的多模态 AI 应用，实现不受网络限制的开箱即用体验。

介绍开源项目
作者整合了之前的项目并进行改进，推出了全新的开源项目 “Gemini Playground”。该项目采用无服务器部署，能够将 Gemini API 中转到国内，支持 AI 编程、音视频对话、翻译和聊天等多种功能。

00:52
Fork项目到GitHub
首先需要访问项目的 GitHub 地址，将项目复制一份到自己的账号下。点击 “Create fork” 按钮完成这一步操作，为后续的部署做准备。

01:01
登录Deno并创建项目
接着登录 Deno 的官网，使用 GitHub 账号进行授权登录。在创建新项目时，选择之前 fork 的 GitHub 仓库，为项目命名（该名称将作为生成的域名），并在 entry point 中选择 src 目录下的 deno/index 文件，最后点击部署。

01:37
获取Gemini API密钥
部署成功后，访问自动分配的域名。此时需要准备一个 Google Gemini 的 API 密钥，前往 Google AI Studio，在有网络环境的情况下点击 “Get API key” 创建新密钥并复制。

01:58
粘贴密钥连接AI
将复制好的 API 密钥粘贴到自建网站的指定位置，点击 “Connect” 即可建立连接。在设置中，用户还可以开启麦克风进行语音对话，并选择音色、回复方式以及视频帧率等参数。

02:24
体验多模态AI功能
连接成功后，可以向 AI 展示图片或视频进行多模态交互测试。例如展示印有大疆标志的包让 AI 猜测内部物品，或者通过展示骰子点数让 AI 计算 24 点，充分体验其强大的视觉理解与逻辑推理能力。
