这条视频讲的是 Python 里 **kwargs 到底是什么，核心结论一句话：kwargs 这个名字本身没有任何特殊含义，真正起作用的是前面的双星号。

视频讲了三个要点

名字可以随便改。kwargs 是 keyword arguments（关键字参数）的简写，只是大家约定俗成的写法。作者在画面里演示了把它换成 k、kw 也照样能跑，所以别被这个 “奇怪的单词” 唬住。

双星号才是关键。它的作用是 “接收所有关键字参数，并收集成一个字典”。画面里调用 func(a=1, b=2, c=3) 后打印，结果是 {'a': 1, 'b': 2, 'c': 3}，三个键值对被整体装进了 kwargs。

只收 “剩下的”。当函数写成 def func(a, **kwargs) 时，a 已经有自己的接收对象，kwargs 只收集 b、c 这类没被前面参数接走的 “游离参数”。另外，**kwargs 必须放在整个参数列表的最后面，否则会报语法错误。
