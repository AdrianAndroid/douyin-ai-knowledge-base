这是「技术爬爬虾」的一期实操教程：不用在自己电脑上装环境，直接在阿里云百炼云端，用平台预置的 MCP Server 拼出一个能查地图、能操作 GitHub、能连数据库的 AI 智能体，最后还能一键发布成公众号客服。

先搞懂 MCP 是什么 作者打了个比方：MCP 就是大模型的标准化工具箱，是 AI 和外部工具之间的中间层，替人去访问和操作外部工具。每个 MCP Server 专精一类活 —— 有的管数据库、有的读写文件、有的操作 Git 仓库。传统做法要把这些程序跑在自己电脑上，装 Node.js 或 Python 环境、配客户端，每台机器都得重来一遍，复用性差。

视频里的完整流程

进百炼平台 MCP 页，平台已预制 15 款 MCP Server。先开通高德地图版，测了「地名转经纬度」，输入北京颐和园、圆明园，成功返回区划和坐标。
新建智能体应用，模型选通义千问 Max，把高德 MCP 勾进技能里。问「青岛太平角公园到崂山山口怎么坐公交」，AI 自己挑工具、自己排顺序，给出两条换乘方案。第一次调用因参数无效失败，AI 自己回头查了起终点坐标再重试，成功 —— 作者说这正是 MCP 的优势：动态规划、自我修复。
补一段提示词，让 AI 先查坐标再做路径规划或周边搜，之后问「小鱼山附近有什么美食」就顺畅多了。再测一个复杂需求：从北京西二旗出发，上午下午各去一处赏花地、中午吃烤鸭、全程公交，AI 一口气调了 7 个工具，排出玉渊潭 — 王府井 — 北京植物园的行程和用时。
开通 GitHub MCP，需要个人访问令牌，作者演示了给仓库创建和编辑权限、生成 token 的过程。之后让 AI 按 star 数列出自己热门仓库，并新建了一个叫 mcp test 的仓库。
组合使用：同时挂高德和 GitHub，让它查青岛未来几天天气并写成 txt 存进仓库，AI 先查天气再调写文件工具，链接点开确实有内容。
自定义 MCP：把官方仓库的 Postgres MCP 注册进平台，用云函数计算部署、按需付费，配置里填数据库账号密码和地址。接上后问「我有哪些表」，查出学生、老师、课程、选课关系四张表；问「大于 15 岁的学生」，AI 自动生成 SQL 并返回姓名年龄。作者建议把表结构写进提示词，复杂查询会更准。
发布：右上角发布按钮，以微信公众号为例，创建 API Key、填公众号开发者 ID、扫码授权，智能体就成了能扫码使用的公众号客服。
