这是「技术爬爬虾」发布的一期教程，核心是教大家用开源项目 DeepLX 免费接入「沉浸式翻译」插件，从而获得原本需要开会员才能用的 DeepL 翻译效果。

视频讲了什么

作者先介绍沉浸式翻译的优点：一键把全英文网页变成中英对照。但免费版只有谷歌和微软两个翻译源，谷歌在国内无法直连，微软效果一般，OpenAI 和 DeepL 都要会员。于是他给出替代方案：借助 DeepLX 这个开源软件，白嫖 DeepL 的翻译服务。

操作步骤（以 Edge 浏览器为例）

打开 Edge，点右上角扩展 → 获取扩展，搜索「沉浸式翻译」并添加；
打开插件设置，左下角进入「开发者选项」，开启 Beta 测试特性；
回到基本设置，翻译服务里就能选到 DeepLX(Beta)；
点进去填写一个 API URL，用的是 zhile 大佬提供的公益免费 DeepLX 服务（他也是当年 Pandora 项目的作者）；
用 Hacker News 实测：点右侧悬浮窗，出现绿色小图标即开始翻译，速度很快且没有数量限制。

评论区值得注意的地方

不少用户认可它中英对照、翻 PDF、学外语的体验，但反馈集中在「好用但设置麻烦」：有人说找不到输入 API 的入口，有人翻译结果直接变成一串网址，也有人表示新版已要求 API Key 或会员。有评论给出的路径是：先进入「翻译服务」，再在「需设置」或「添加自定义翻译服务」里填 API，而不是在基础设置里找。也就是说，视频里的方法在部分版本上可能已经失效，具体要看插件当前版本。
