这是一个讲 Python 字符串不可变 的编程避坑视频，作者是「技术爬爬虾」，核心一句话：replace、strip 这类方法不会改动原字符串，必须把返回值重新赋值。

视频演示的过程

定义一个字符串 x，内容是「空格、空格、a、b、c」，也就是前面带两个空格。
先写 x.replace("a", "1")，再写 x.strip() 去掉前面的空格，然后 print(x)。
运行结果里 x 一点没变，还是原来的样子。
作者解释原因：字符串是不可变对象，replace 和 strip 都是「返回一个新字符串」，而不是原地修改。
正确写法是把结果接回来：x = x.replace("a", "1")，x = x.strip()，再运行就得到想要的效果。

容易踩坑的地方

只调用不赋值，等于白写一行，程序不报错，所以特别隐蔽。
同理适用于 upper()、lower()、title()、join() 等所有返回新字符串的方法。
如果链式调用，可以写成 x = x.replace("a", "1").strip()，一步到位。
