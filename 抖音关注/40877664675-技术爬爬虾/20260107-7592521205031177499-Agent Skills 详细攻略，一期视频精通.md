核心概念：带目录的说明书

作者把 Agent Skills 一句话概括为 “带目录的说明书”，本质是渐进式披露提示词的机制。它把提示词拆成三层：

元数据：只有 name 和 description，必定加载进上下文，相当于书的目录
指令层：写在 SKILL.md 正文里，AI 决定调用后才加载，相当于正文
资源层：文件夹里的辅助文件，按需读取，相当于附录

好处是平时只占一点 token，比一次性塞入大段 Prompt 或 MCP 工具描述更省上下文、更简单。
