这是「技术爬爬虾」的一条教程视频，讲的是 DeepSeek 官网被攻击、API 平台打不开时，怎么用两种方式拿到 DeepSeek R1 的 “满血版” API。

背景：视频开头展示 DeepSeek 官网的故障公告，作者说 API 开放平台已连续一周打不开。

方案一：OpenRouter 免费 API

在 OpenRouter（AI 模型 API 聚合站，国内可直连）注册登录，搜索 DeepSeek R1 free，能看到微软 Azure 和另一家平台提供免费 R1。
创建 API key，复制模型 ID，填进客户端 Cherry Studio（从 GitHub 找到的开源大模型客户端），即可对话。
作者用一道 “24 点” 题验证真假：第一次报 “调用次数超限”，重试后第一题正常答出，第二题等了 3 分多钟也答对，由此判断是满血 R1。
缺点很明确：免费所以不稳定、速度慢，还看不到思考过程。

方案二：硅基流动（全国产方案）

手机号注册硅基流动，首页就有 R1 和 V3，可先在网页端免费在线体验，官网挂了也能用，只是比官网慢一点。
新建 API 密钥，回到 Cherry Studio 选 “硅基流动” 粘贴密钥、添加模型，同样用 24 点题测试，答案正确。

两个实用补充：DeepSeek API 完全兼容 OpenAI 格式，客户端没有 OpenRouter 选项时，把提供方选成 OpenAI、填对模型名也能用；作者还建议观众把邀请码发到评论区互相填。

评论区讨论最多的也是这几件事：官网和平台不稳定（系统繁忙、500 错误）、R1 与 V3 谁更强、本地部署的硬件门槛，以及 API key 和邀请码的互换。
