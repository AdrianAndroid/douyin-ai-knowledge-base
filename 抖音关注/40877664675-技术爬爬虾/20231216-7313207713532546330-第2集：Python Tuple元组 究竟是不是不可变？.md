演示过程

先定义 my_tuple = ([1, 2], [3, 4])，也就是一个装着两个列表的元组。
接着执行 my_tuple[1].append(5)，往元组里第二个列表追加元素。
运行后输出 ([1, 2], [3, 4, 5])，程序正常结束，没有报错。

结论怎么理解

元组的 “不可变” 指的是元组这一层：它保存的是各个元素的引用，不能替换、增删这些位置上的对象，所以 my_tuple[1] = ... 会报错。但元组里装的列表本身是可变的，修改列表内部内容并不改变元组的结构，因此完全合法。一句话：元组不可变，不等于它里面的东西都不可变；只有元组内全是不可变对象（数字、字符串、元组）时，才真正 “整体冻结”。

顺带一提，这种 “浅层不可变” 也意味着元组不能当字典键，除非里面所有元素都可哈希。
