作者的三条建议

认准 GitHub：官网能造假，但项目主页的 2 万星标难造假。从 GitHub 的 release 页下载才是真安装包 —— 真包是 zip 格式，冒牌站给的是 MSI，这一点就能断定它是假的。
看是否全流程开源：WindTerm 最新发版是两周前，源代码却停在 2022 年 8 月，时间对不上，说明安装包不是这套代码构建的；作者页也写明它是 “部分开源项目”。作者对比了自己在用的 Tabby：源码与发版时间一致，打包编译托管在 GitHub Actions，没有动手脚的空间，因此认为 Tabby 安全性明显更高。
