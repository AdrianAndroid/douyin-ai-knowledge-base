本视频详细讲解了 Windows Subsystem for Linux 2（WSL 2）的工作原理，并提供了从安装配置到高级功能应用的完整实操教程。

00:00
了解WSL 2原理
WSL 2 基于 Hyper-V 虚拟化平台运行真正的 Linux 内核，相比上一代的翻译层架构，它提供了更好的系统兼容性，支持运行 Docker 并自带显卡直通功能。

01:39
开启WSL 2前置条件
在安装前需确认 CPU 虚拟化已在任务管理器中开启，并在 Windows 功能设置里启用 “适用于 Linux 的 Windows 子系统” 和 “虚拟机平台”。

02:20
安装默认Linux发行版
以管理员身份打开命令提示符，执行 wsl --install 命令即可开始下载并安装默认的 Ubuntu 系统，期间根据提示设置用户名和密码即可完成初始化。

03:07
安装其他Linux发行版
通过 wsl --list --online 命令可查看所有支持的发行版，使用 wsl --install -d <Distribution Name>命令即可安装如 Kali Linux 等其他系统。

03:38
管理已安装子系统
使用 wsl --list -v 可查看已安装的子系统列表及其运行状态，通过 wsl --setdefault 可切换默认系统，直接在终端下拉菜单或使用 wsl -d 命令即可快速启动。

05:00
卸载与备份子系统
执行 wsl --unregister <Subsystem Name>可卸载指定子系统；利用 wsl --export 可将系统导出为压缩包进行备份，wsl --import 则支持将备份重新导入到指定磁盘目录。

06:29
配置子系统文件共享
Windows 的磁盘会自动挂载到 Linux 子系统中，同时在 Windows 资源管理器的左下角会出现企鹅图标，方便直接浏览和修改子系统内的文件。

07:17
跨系统调用命令与程序
WSL 支持在 Linux 子系统中直接调用 Notepad.exe 或 Explorer.exe 等 Windows 程序，同时也能在 PowerShell 中将 Windows 命令的输出通过管道符传递给 Linux 的 grep 等命令进行筛选。

08:57
运行Linux GUI应用
借助 WSLg 技术，Linux 下带有 UI 的应用程序可以直接以原生窗口的形式在 Windows 中打开，视频演示了在 Ubuntu 子系统中安装并启动 GIMP 图像处理软件的过程。

09:34
体验显卡直通功能
得益于底层的虚拟化技术，WSL 2 支持将物理显卡直通给 Linux 子系统，自动识别并配置好驱动，为运行 Linux 版本的 AI 大模型提供了便利。

10:57
配置子系统高级选项
视频介绍了利用 /etc/wslconfig 启用 systemd 服务，以及通过修改 Windows 用户目录下的.wslconfig 文件将网络模式切换为 “镜像网络” 的高级配置技巧。

13:44
安装Docker与配置加速
最后，视频演示了在 Windows 上下载安装 Docker Desktop，并在设置中添加国内镜像源地址以加速容器拉取的完整流程。
