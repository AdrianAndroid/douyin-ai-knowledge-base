演示的原始函数 屏幕上是一个 compare(x, y) 函数：x < y 返回 "greater"，x == y 返回 "equal"，x > y 返回 "smaller"，共六行代码。

三个缺点

只能写在一行：lambda 的语法是 lambda x, y: 返回值，冒号后只能跟一个表达式，没法像普通函数那样分行写 if 语句，六行逻辑要硬压成一行。
可读性差：作者用 Python 的 if...else 三元表达式嵌套，写成 lambda x, y: "greater" if x < y else ("equal" if x == y else "smaller")。逻辑全挤在一行，很难一眼看懂在做什么。
难以调试：普通函数可以在某一行打断点、单步调试；lambda 是匿名的一次性表达式，没法在内部设断点，排查问题很困难。

作者的观点很明确：lambda 适合简单的一行小逻辑，遇到多分支判断这类复杂逻辑，还是用普通函数更合适。视频最后是常规的点赞引导。
