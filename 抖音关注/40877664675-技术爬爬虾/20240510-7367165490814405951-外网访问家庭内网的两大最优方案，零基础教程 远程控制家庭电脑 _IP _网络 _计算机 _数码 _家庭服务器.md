作者用 “快递送上门” 的生活化类比讲清核心逻辑：把 IP 地址比作门牌号，公网 IP 是互联网上直接可达的 “独栋门牌号”，内网 IP 则是大内网里 “小区内的几号楼几单元”。同时解释了 IPv4 地址耗尽后，NAT 机制如何通过 “多层 NAT 套娃” 让多设备共用公网 IP，以及 IPv6 拥有 128 位地址、理论上能给全球每粒沙子分配一个独立地址的特性。

演示了验证光猫是否拥有独立公网 IP 的方法：登录光猫后台查看运营商分配的 IP，和百度搜索 “IP 地址” 得到的结果比对，两者一致即为公网 IP。如果没有公网 IP，可以拨打运营商电话，以 “家里部署企业级监控需要公网 IP” 为由申请，不同地区运营商的开通难度和政策差异较大。
