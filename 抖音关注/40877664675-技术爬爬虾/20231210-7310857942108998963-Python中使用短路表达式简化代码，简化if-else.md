随后他把这 5 行压缩成 1 行：

python
name = user_input or "佚名"


为什么能这样写

Python 的 or 是短路求值：从左往右判断，遇到第一个「真值」就返回它，否则返回最后一个值。空字符串 "" 在 Python 里算假值，所以输入为空时 user_input or "佚名" 直接返回 "佚名"；有输入时返回输入本身。这正好等价于「有值用值，没值用默认值」的 if-else。

使用时要注意的边界

只适用于「判断真假值」的场景，比如空字符串、None、0、空列表都会被当成假值。如果 0 是合法输入，用 or 就会误判成默认值。
如果默认值本身也可能是假值，或者需要区分「未输入」和「输入了 0」，还是老老实实写 if 或用 x if x is not None else y。
这种写法在 Python 圈里常被叫作「or 默认值」惯用法，可读性上有人喜欢有人嫌隐晦，团队代码风格不统一时慎用。
