这是「技术爬爬虾」的一期实操教程：用一台普通 Windows 电脑开启 SMB 共享，把电脑里的 4K 电影直接投到手机、电视上播放，不用买几千块的 NAS。作者的核心观点是：只是偶尔看看电影，没必要上专业 NAS 设备，也不用学复杂配置。

电脑端：开启共享

在 “启用或关闭 Windows 功能” 里勾选 SMB 直通，Win10/Win11 默认走 SMB 3.0 协议；作者不建议开 SMB 1.0，因为性能差太多，不值得为兼容性牺牲速度。
右键要共享的文件夹（他以 “迅雷下载” 为例）→ 属性 → 共享，新建一个专用账户（他设的用户名和密码都是 smb），勾选 “密码永不过期”“用户不能更改密码”，并取消 “下次登录时更改密码”。
回到共享页面添加这个新用户，只给读取权限即可。Win11 创建账户时选 “我没有此账户的登录信息”。

手机端

安卓装 MX Player 或 OPlayer（他在 OPPO 应用商店能直接搜到），苹果用 nPlayer。
以 OPlayer 演示：左侧菜单 → 本地网络，通常能自动发现电脑；点进共享文件夹，输入 smb/smb 就能看到影片。MKV 可直接切换字幕，20 多 G 的片子拖动进度条也不卡 —— 他用的还是七八年前的机械硬盘。
没自动识别就手动加：在电脑 “以太网 → 网络” 里记下 IPv4 地址，播放器里取消匿名登录，填 IP + 账号密码连接。

电视端（安卓电视）

下载 Kodi，按电视架构选 32/64 位安装包，拷到 U 盘插电视安装。
先改中文：设置 → Interface，字体先改成 Arial based，再到 Region 里选简体中文。
文件管理 → 添加源 → 浏览 → 添加网络位置，协议选 SMB，填 IPv4 地址和 smb 账号密码，就能看到共享目录。

局限与补充：这套方案只能在局域网内看，外网访问属于 “内网穿透” 的另一个话题。片源方面他提到音范丝、Grab4K 两个 4K 下载站（地址需私信获取）。

评论区补充了几点实际经验：有人用淘汰旧手机 + KSweb 做更省电的替代方案；20 多 G 的 4K 卡顿、1080P 正常，通常是电脑、网线、路由器、机顶盒、电视任一环节的瓶颈；另有用户反馈 Win11 家庭版没有 SMB 直通选项，这点值得留意。
