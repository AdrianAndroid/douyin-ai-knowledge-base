这是一个 Python 入门小技巧视频，作者「技术爬爬虾」用水果列表 bag = ["apple", "banana", "orange", "kiwifruit"] 演示了循环打印列表的三种写法，从 “笨办法” 逐步优化到更 Pythonic 的写法。

三种写法对比

索引遍历（作者称为 “比较笨的写法”）：for i in range(len(bag))，再用 bag[i] 按索引取出元素打印。能跑通，但代码啰嗦。
直接遍历元素：for i in bag: print(i)，把 range(len()) 那套全删掉，直接拿到每个元素，效果一样。
需要索引时用 enumerate：for i, item in enumerate(bag): print(i, item)，同时拿到序号和元素，输出 “索引 + 水果名”。

关键概念

作者解释，enumerate 的本质是把列表 “转变成一个前面编上号的元素列表”，即 (0, "apple")、(1, "banana") 这样的带序号对，所以循环时能一次解包出两个值。视频结尾画面也展示了 enumerate(bag) 的实际结果，并提示点赞支持。

一句话记住：只要元素就直接 for x in 列表，既要序号又要元素就上 enumerate，别再用 range(len()) 绕一圈。

想继续的话，可以聊聊 enumerate 的 start 参数怎么让编号从 1 开始，或者遍历字典时该用 .items() 还是 enumerate。
