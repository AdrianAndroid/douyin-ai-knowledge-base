介绍Wireshark工具
Wireshark 是一款开源免费的网络抓包工具，能够深入解析网络层、数据链路层等底层协议。它可以清晰直观地展示 TCP 三次握手和 TLS 加密建立等数据结构，是学习网络协议和排查故障的首选工具。

下载与安装Wireshark
前往 Wireshark 官网根据操作系统下载对应的安装包，一路点击下一步进行安装。在安装过程中，务必勾选安装 npcap 插件，这是 Windows 平台下 Wireshark 用于底层抓包的核心引擎。

认识软件功能布局
打开软件后需先选择用于上网的网卡进行抓包，界面主要由工具栏、显示过滤器和数据包列表组成。选中具体数据包后，下方会直观展示其物理层、数据链路层、网络层、传输层及应用层的分层信息与原始数据。

使用过滤器筛选数据
面对海量数据，可通过显示过滤器对已抓取的数据包进行 IP 地址、协议类型、端口号及内容的模糊匹配筛选。此外，还可以设置捕获过滤器提前定义规则，让 Wireshark 只捕获符合条件的报文以提升性能。

实战分析ARP协议
ARP 协议用于在局域网中交换 IP 地址与 MAC 地址的对应关系。通过在过滤器中输入 “arp”，可以清晰看到设备广播的 ARP 请求以及目标设备回应的 MAC 地址，从而了解局域网内的设备映射情况。

06:07
实战分析DNS协议
默认配置下的 DNS 请求是明文传输的，在过滤器中输入 “dns” 即可看到域名与对应 IP 的解析过程。为了防止被窃听，可以在网络属性中开启 DNS over HTTPS（DoH）功能，将 DNS 查询流量完全加密。

07:35
实战分析TCP协议
通过命令行发起网络请求，结合 Wireshark 抓包可以完整分析 TCP 协议的通信流程。数据包会清晰展示出客户端与服务端之间建立连接的三次握手、数据传输过程，以及最终断开连接的四次挥手。

09:29
实战分析HTTPS协议
HTTPS 协议通过 TLS 进行加密，在过滤出 TLS 协议的数据包后，可以观察到客户端与服务端之间的四次握手过程。握手完成后，后续的应用数据交换都会被完全加密，直接抓包只能看到乱码。

10:55
解密HTTPS数据包
通过配置系统环境变量 “SSLKEYLOGFILE”，可以让浏览器将生成的预主密钥导出到指定文件中。在 Wireshark 的 TLS 协议首选项中加载该文件后，软件就能自动推断出会话密钥，并将加密的 HTTPS 流量解密为可读的明文数据。
