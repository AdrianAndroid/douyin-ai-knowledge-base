核心内容

画面里先写了一个普通函数：

python
def is_even_number(x):     return x % 2 == 0


这是判断偶数的写法，用 x % 2 == 0 判断余数是否为 0。随后作者在下面改写成一行 lambda：

python
lambda x: x % 2 == 0


作者想讲的优点

写法更短：省掉 def、函数名和 return，一行就能表达同样的逻辑。
适合 “用完就扔” 的场景：像这种只在一处用一次的小判断，不必专门起名字，直接当参数传给 filter、map、sorted(key=...) 这类函数最方便。
代码更紧凑：逻辑简单时，读起来比多行函数更直观。

需要补充的一点

lambda 只能写单个表达式，不能包含多行语句、循环或复杂分支；如果逻辑一多，硬塞进 lambda 反而更难读。所以它更适合简单、一次性的小函数，复杂逻辑还是用 def 更清楚。

想继续看的话，可以聊聊它在 sorted 或 filter 里的实际用法，那才是 lambda 最常用的地方。
