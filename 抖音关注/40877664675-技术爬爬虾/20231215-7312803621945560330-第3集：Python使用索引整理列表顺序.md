这是「技术爬爬虾」的 Python 教程片段，讲的是用索引调整列表里元素的顺序，核心是 “先找到位置，再移动或交换”。

演示用的列表

视频里先定义了一个水果列表 bag，依次是：苹果、橘子、香蕉、芒果。

方法一：把某个元素挪到末尾（约 13 秒）

python
index = bag.index('橘子') item = bag.pop(index) bag.append(item)


思路是三步：用 index() 查出 “橘子” 的下标，用 pop() 把它从原位置取出来，再用 append() 追加到列表最后。结果 “橘子” 从第二位跑到了末尾。

方法二：交换两个元素的位置（约 30 秒）

python
index1 = bag.index('香蕉') index2 = bag.index('芒果') bag[index1], bag[index2] = bag[index2], bag[index1]


这里用的是 Python 的多重赋值写法，一行就能完成交换，不需要借助临时变量。这也是 Python 里交换两个值最常用的写法。

两个要注意的点

index() 只返回第一个匹配项的下标，列表里有重复元素时，它不会帮你区分。
pop() 会改变原列表长度，如果边遍历边 pop，下标容易错乱，最好先记下索引再操作。
