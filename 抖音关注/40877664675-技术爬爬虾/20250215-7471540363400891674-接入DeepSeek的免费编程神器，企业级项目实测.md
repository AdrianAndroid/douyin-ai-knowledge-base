实测流程（以开源项目 ContiNew Admin 为靶子）

作者选了 GitHub 上的前后端分离中后台框架 ContiNew Admin，技术栈是 Spring Boot 3 + Java 17 + Vue 3，从 “角色管理” 功能切入：

装插件：IDEA 里 Settings → Plugins → Marketplace 搜 “通义灵码” 安装，登录阿里云账号；VSCode 侧同样在扩展市场安装。
读懂代码：用智能问答 + codebase（把整个项目喂给 AI），让它找出实现角色管理功能的 Controller、Service 及实现类，作者评价 “分析基本精准”。
写新功能：需求是把删除的角色先归档到新表 sys_role_archive 再删除。AI 程序员一次改动了 4 个文件 —— 建表 SQL、实体类、MyBatis mapper 接口、Service 逻辑，作者逐个查看后点 “接收”。
