这条视频是博主「技术爬爬虾」的教程：用旧 Windows 电脑一键部署 Home Assistant（HA），把米家设备接进来，最后做一个进水微信告警的小应用。

为什么用 HA 作者认为普通智能家居有两个痛点：一是各厂商协议封闭、生态之间无法联动；二是 App 里拖拽几个流程就算 “智能”，定制空间太小。而 Home Assistant 是基于 Python 的开源智能家居中枢，能接入各家设备，也能自由编程做精细化联动。它最大的门槛是部署复杂，通常要碰 Linux、Docker、虚拟机、群晖、OpenWrt。

部署步骤（全程 Windows）

用开源项目 HassWP（Home Assistant Windows Portable），在 GitHub 的 release 页下载最新压缩包，解压即用。它已预装 Python、2023 版 HA、Notepad++ 和 HACS 插件商店。
运行 service 目录下的 install 脚本，可把 HA 加入开机自启；hass.cmd 双击即启动。
首次进入网页，创建账号（演示用 techshrimp）、填家庭位置和国家，完成初始化。
配置 → 设备与服务 → 搜索集成 HACS，勾选 5 项提交，打开给出的网址登录 GitHub、填 8 位验证码授权，装好 HACS。
在 HACS 里搜 “小米”，安装 Xiaomi Miot for Home Assistant（Miot 是小米多数设备的通讯协议），重启后添加集成、登录米家账号，家里的设备就同步进来了。

结尾的小应用 作者买了米家水浸卫士监测厨房进水，但嫌 App 推送不稳定，于是结合微信机器人写了个触发器，一旦检测到进水就直接微信告警。
