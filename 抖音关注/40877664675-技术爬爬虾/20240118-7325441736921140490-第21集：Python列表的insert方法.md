这是「技术爬爬虾」讲 Python 列表 insert 方法 的一个小知识点：当索引超出列表长度时，insert 不会报错，而是把元素追加到末尾。

视频里的两个演示

列表 a = [1, 2, 3]，执行 a.insert(4, 3)。列表只有索引 0、1、2，没有 4，作者先抛出疑问 “会不会报错”，答案是不会 ——超出范围的索引会被当作末尾，结果打印为 [1, 2, 3, 3]，实际运行也验证了这一点。
把索引改成 1，执行 a.insert(1, 3)，即在索引 1 之前插入，也就是插到 1 和 2 之间，结果变成 [1, 3, 2, 3]，运行结果一致。

关键理解：insert 的第一个参数是 “插入位置”，含义是插到这个索引对应元素的前面，而不是替换它。所以 insert(1, 3) 是插在 1 后面、2 前面；而索引大于等于列表长度时，Python 会把它当作追加处理，不抛 IndexError。

顺带一提，索引传负数也有对应规则（如 insert(-1, x) 会插到倒数第一个元素之前），这是视频没展开的部分。评论区目前只有两条无实质内容的短评，没有额外补充。
