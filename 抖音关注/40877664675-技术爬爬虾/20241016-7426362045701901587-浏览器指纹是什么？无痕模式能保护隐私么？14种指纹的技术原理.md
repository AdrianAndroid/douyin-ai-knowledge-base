什么是浏览器指纹
浏览器指纹是指网站在用户访问时悄悄收集的关于浏览器和设备的各种细节信息（如 IP 地址、User-Agent、时区、插件、系统字体等）。这些看似无关紧要的信息汇聚在一起，就形成了一个在大多数情况下独一无二的标识符。

这就像现实生活中的指纹，能让网站在不依赖传统 Cookie 的情况下，依然能够精准地识别出独立的访客。即使你开启了无痕模式或清除了 Cookie，网站依然可以通过这些技术手段收集到你的浏览器指纹。

为什么网站要收集指纹
网站收集浏览器指纹主要出于以下两个核心目的：

精准广告推送：广告联盟的推送服务会默默收集这些指纹并与当前网页进行绑定，以便更精准地识别用户喜好，推送个性化广告。
安全与防刷保护：电商和社交平台利用浏览器指纹来识别是否是同一个人在操作多个账号，从而设置相应的安全策略，有效防止爬虫和恶意刷数据的行为。

IP地址与地理位置
每个接入互联网的设备都有一个唯一的 IP 地址用于通讯。网站通过解析网络层的数据报文，可以获取到用户的公网 IP 地址。

利用 IP 地址，网站可以进行定位、定制内容及安全检查（如识别异常登录或防止欺诈）。通过查询 IP 地理位置数据库，网站能大致确定用户所在的国家、地区、城市甚至经纬度。此外，结合 IP 信息推算出的时区与浏览器本地 JS 代码获取的时区进行比对，还能作为检测用户异常行为的重要指标。

Canvas指纹追踪技术
Canvas 是网页上一个可以让程序绘制图形的区域。网站通过在 Canvas 上绘制复杂的图形和文字，然后分析这些内容在电脑上的具体显示方式来生成指纹。

由于每台电脑的屏幕分辨率、使用的字体、显卡等配置不同，绘制出的图形在轮廓、阴影、颜色和像素排列上会有极其微小的差异。通过提取这些像素并计算其 MD5 哈希值，就能得到一个独特的 Canvas 签名。这种技术配合其他浏览器指纹，可以做到非常精准的用户识别与追踪。

WebGL与音频指纹
除了 Canvas，网站还可以通过其他硬件和软件特性生成更丰富的指纹：

WebGL 指纹：作为一种利用显卡绘制三维图形的 JavaScript API，网站通过绘制特定的三维图像并分析其细节差异生成哈希值，以此反映电脑显卡的硬件特性。
音频指纹：利用浏览器提供的 Web Audio API 处理并播放声音。由于每个设备处理声音的细微差异会被网站捕捉，通过计算这些差异的哈希值，就能形成反映不同音频硬件和软件设置的特殊声音指纹。

User-Agent与浏览器语言

User-Agent：这是浏览器发送给网站的字符串，包含了浏览器类型、版本以及操作系统等核心信息。尽管其中包含了大量为了兼容而保留的历史遗留冗余字符串，但它依然是网站判断提供何种设备兼容内容的重要依据，也是浏览器指纹的重要组成部分。
浏览器语言：通过 HTTP 请求头中的 Accept-Language 字段，网站可以获取用户在浏览器中设置的首选语言及其偏好排序。这个语言顺序列表同样可以用于区分不同的访客。

系统字体与屏幕分辨率

系统字体：浏览器可以通过复杂的 JavaScript 脚本（如利用开源库中的相关代码）逐个尝试绘制字体列表，通过判断绘制是否成功来枚举用户设备上安装的所有可用字体。即使两个用户使用相同的浏览器和操作系统，安装的字体差异也能成为区分他们的关键。
屏幕与窗口分辨率：物理屏幕的实际像素数，以及浏览器内部除去工具栏、标签栏后的实际可用窗口大小，都是因人而异的。通过这些取值，也能取得一个相对独特的指纹。

语音列表与硬件指标

语音列表：浏览器 “大声朗读此页面” 功能中提供的 AI 语音列表，同样可以被网站通过 JS 代码获取，作为区分不同用户的一个维度。
硬件指标：网站还可以通过 JS 代码直接获取用户电脑的核心硬件配置，例如 navigator.hardwareConcurrency（表示电脑的线程数）以及 navigator.deviceMemory（表示电脑的内存大小）。
