这是「技术爬爬虾」的一期工具盘点视频，主题是四款开源免费、可本地离线使用的开发工具，核心出发点是：程序员常要在软件里存 API 密钥、数据库密码这类敏感数据，开源工具代码可审查、数据留在本地，能降低后门和数据泄露风险，而且都采用 MIT 或 Apache 协议，可免费商用。

四款工具及演示重点

Tabby（虎斑猫，GitHub 6 万多 star）：跨平台终端，支持 Windows/Mac/Linux，自带 SFTP、主题和插件。演示了从 Releases 下载安装、新建 SSH 配置连服务器、改用私钥登录、用 SFTP 拖拽上传下载、右键调用 VS Code 编辑远程文件。作者还对比了 WindTerm，指出其源码三年未更新、部分代码未完全开源，而 Tabby 的源码与安装包同日更新、由 GitHub Action 构建，全流程透明，因此更推荐 Tabby。
Bruno（约 2.8 万 star）：Postman 的开源轻量替代品，仅支持离线，作者称永远不会加云同步。概念与 Postman 一致，上手快。演示了创建 collection 存本地、发 POST 请求、生成 cURL 代码，以及 OAuth2 鉴权、请求前后 JS 脚本（加 timestamp 参数、断言测试）、多环境变量切换。
DBeaver：免费跨平台数据库工具，社区版开源。演示连 PostgreSQL（Maven 自动搜 JDBC 驱动）和本地 SQLite，建表、加列、设主外键，右键生成 SQL、多 Tab 写脚本、自动 / 手动提交事务，以及丰富的导入导出。
VS Code：微软的全平台开源免费编辑器，靠插件生态成为热门 IDE。演示网页版（GitHub 仓库按句号键直接打开）、打开文件夹写 Python、按提示装官方 Python 插件获得补全、运行文件，以及创建 venv 虚拟环境、初始化 Git 仓库。

评论区主要在补充和纠偏：不少人指出 VS Code 装太多插件、开大项目时吃内存、风扇狂转，“轻量” 要看场景；也有人认为前端后端乃至 Postman、Xshell 的功能都能用 VS Code 插件替代，但专业场景 IDEA 更合适（代价是体积大、吃内存）。终端替代品上，有用户不推荐 Tabby，转而推荐 WindTerm、iTerm2、MobaXterm。另有评论认出片中开源协议流程图出自阮一峰版本。
