部署流程（按视频顺序）

在开源主页点 Code → Download ZIP，解压到云服务器目录（示例为 Wechat official AI）。
打开配置文件，填入 3 个讯飞星火 API 参数（获取方法见作者另一期视频）。
安装依赖：pip3 install -r requirements.txt，然后执行 sh start.sh 启动。
进微信公众平台注册，类型选订阅号，主体选个人并完成实名认证。
后台「设置与开发 → 基本配置」里成为开发者，再修改服务器配置：URL 填服务器公网 IP，端口 80，后缀 wx，Token 随意填，EncodingAESKey 点随机生成，加密方式先选明文模式，保存后点启用。

最值得看的技术点：公众号开发文档要求每条回复必须在 5 秒内返回，但大模型往往答不了这么快。作者的解法是在代码里加缓存 handle.cache—— 第一次请求时故意等 5 秒让接口超时，触发微信的重试机制；重试时再检查缓存里是否已有星火返回的答案，没有就继续超时，直到字符串不为空才真正把答案发出去。等于借微信的重试机制绕开了 5 秒限制。
