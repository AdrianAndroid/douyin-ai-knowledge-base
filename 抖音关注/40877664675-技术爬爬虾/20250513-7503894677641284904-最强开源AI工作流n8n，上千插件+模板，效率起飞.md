实战：构建新闻简报工作流
通过一个定时收集并推送新闻简报的实战案例，展示了 n8n 的核心功能。工作流的构建主要包含以下几个关键步骤：

获取数据源：使用 RSS 订阅机制，从 Hacker News 等网站获取最新的新闻列表。
网页爬取与内容提取：通过安装社区节点集成 Firecrawl 爬虫工具，自动读取新闻链接的具体内容。
AI 智能处理：接入 DeepSeek 等大模型，编写自定义提示词，将爬取到的零散数据整理成规范的新闻简报。
数据格式化与推送：将 AI 生成的 Markdown 格式内容转换为 HTML，配置 QQ 邮箱的 SMTP 服务，最终将简报发送至指定邮箱。
定时触发：将工作流的启动节点从手动触发改为定时触发（如每四个小时），实现自动化运行。

管理与分享工作流数据
默认情况下，n8n 的所有数据都存储在本地的 SQLite 数据库中。为了实现数据的永久保存，可以在生产环境中将其切换至 MySQL 或 PostgreSQL 等关系型数据库。此外，用户还可以将构建好的工作流导出为 JSON 文件进行本地备份，或分享给其他人直接导入复用。

探索社区工作流模板
n8n 官网的 Workflows 板块提供了丰富的社区模板。这些模板涵盖了市场营销线索评分、全自动视频生成与多平台发布、以及 AI 智能解析邮箱发票等多种实用场景。用户可以直接复制这些模板的 JSON 文件并导入自己的 n8n 实例，快速搭建出复杂的自动化流程。

配置双向MCP服务
n8n 具备强大的双向 MCP（Model Context Protocol）能力。一方面，它可以作为 MCP Server 暴露 SSE 协议的接口，供 Cherry Studio 等 AI 客户端远程调用其工作流；另一方面，通过安装社区节点，n8n 也可以作为 MCP Client，使用 STDIO 协议去调用如 Fetch 等外部 MCP 工具，从而极大地扩展大模型的行动能力。

使用Docker部署到服务器
当工作流需要转变为生产力时，建议使用 Docker 将其部署到 Linux 云服务器上。在服务器安装好 Docker 环境后，执行官方提供的挂载卷和容器启动命令（添加后台运行及 HTTP 访问参数），即可成功在公网上部署 n8n 服务。对于生产环境，务必在 Docker 启动命令中配置环境变量，将数据持久化存储到专业的关系型数据库中。
