四个脚本分别对应这四个核心功能：

切换回 Win10 风格右键菜单：针对 Win11 右键菜单需要多点击一次 “显示更多选项” 的麻烦，用管理员身份运行 CMD 后输入两行命令，就能直接恢复成 Win11 之前的完整右键菜单样式，也有对应命令可以随时切回 Win11 原生菜单。
永久暂停 Windows 更新：解决系统自带设置最多只能暂停 1 个月更新、还可能强制重启的问题，执行脚本后系统设置里的暂停更新时长会变成 1000 多周，后续想恢复更新点击对应按钮即可。
彻底卸载任务栏小组件：不止是在设置里关闭小组件按钮，而是通过命令直接卸载这个后台占用 CPU 和内存的广告组件，卸载后任务栏设置里的小组件选项也会完全消失，同时提供了重新安装的命令。
家庭版系统开启 Hyper-V：原本 Hyper-V 仅支持 Win10/11 专业版、旗舰版，家庭版用户可以新建文本文档写入指定脚本，改名为hv.bat后以管理员身份运行，操作完成后就能在家庭版系统里启用这个自带的虚拟机平台。
