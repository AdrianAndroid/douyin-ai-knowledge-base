一、网络环境：让检测页全绿

博主先打开网页版 Claude 检测器，目标是让各项指标都变绿，其中最关键的是 IP：

用海外服务器中转流量，让电脑出口 IP 变成服务器 IP；他提到 Claude 有 “连坐” 机制，同 IP 有人被封可能被牵连，所以要独享干净 IP。
检测发现 IPv6 还暴露本地地区，于是进网卡属性取消 IPv6 协议，刷新后三个 IP 都变成服务器地址。
时区要和服务器一致（他的服务器在纽约，就设成 UTC-4 大西洋时区，并开启自动夏令时）。
浏览器 DNS 选 Cloudflare 的安全 DNS。
浏览器语言只留英语，删掉中文。
唯一没解决的是 “机房 IP 而非家用宽带”，他认为不关键，因为自己一年都用服务器 IP。

他强调顺序：每次开机先确认检测页全绿，再去登录 Claude 或使用 Claude Code。

二、注册与订阅

登录推荐用谷歌账户，IP 够干净就不会弹 KYC 或手机号验证；也可以用自己域名做邮箱（他另有视频讲这个）。
订阅以安卓为例：手机要有美国网络环境，装 Claude App 和 Google Play；在 Play 里把国家地区改成美国、付款方式绑国内卡，再从 App 内升级，走 Google Play 渠道订阅。建议先上 Pro 用几个月养号。

三、Claude Code 的隔离使用

他在 Windows Hyper-V 里单独开虚拟机，只装浏览器、VS Code 和 Claude 桌面端，时区语言都改成美国 / 英语，坚持一机一号，不来回切账号，也不把 Claude Code 接国产模型。想折腾别的就回宿主机或另开虚拟机。

四、养号节奏

先注册免费号，隔三差五聊聊天，几个月后升 Pro 开始用 Claude Code；额度别用满，每月留 20%–30% 余量，同时继续用网页版聊天；稳定几个月再升 Max。大号之外常备 2–3 个小号在养。他还否定了 “只能美国白天用、必须英语对话” 的说法，说自己就是中国时区作息加中文对话。
