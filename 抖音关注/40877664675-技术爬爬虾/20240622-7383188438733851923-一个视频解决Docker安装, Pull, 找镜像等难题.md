一、安装 Docker

Linux：用一键安装脚本，作者用 GitHub Action 每天从官网 get.docker.com 定时抓取脚本存到自己项目的 release 里，效果等同官方脚本；网络不通时可换成 Gitee 版地址。演示在北京的一台云服务器上回车安装、启动成功。
Windows：先在 “启用或关闭 Windows 功能” 里勾选 “适用于 Linux 的 Windows 子系统” 和 “虚拟机平台” 并重启；再用管理员 CMD 执行 wsl --set-default-version 2 和 wsl --update --web-download（国内网络建议加 --web-download 减少失败）；最后装 Docker Desktop，想自定义目录可用命令行加 --installation-dir 参数。
Mac：苹果芯片装 arm64 版，英特尔芯片装 x86 版，双击安装即可。

二、拉取镜像的五个方案

用 GitHub Action 转存到阿里云私有仓库（作者自己的项目 Docker Images Pusher，支持 40GB 大镜像）；
配置镜像站：Linux 改配置文件换源后重启 Docker，Windows/Mac 在 Docker Engine 配置里加大括号内的换源段落，注意 false 后补逗号，再 Apply and restart；
用 GitHub Action 下载离线镜像（国内博主 @悟空的日常 的项目）；
一键脚本，自动测速各镜像源后选最优下载；
