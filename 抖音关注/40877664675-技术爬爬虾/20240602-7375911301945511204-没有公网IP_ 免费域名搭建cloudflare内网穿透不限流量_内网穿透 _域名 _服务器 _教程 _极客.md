本视频详细讲解了如何在没有公网 IP 的情况下，利用 Cloudflare Tunnel 配合免费域名，搭建完全免费且不限流量的内网穿透方案。

00:00
介绍内网穿透方案
如果无法申请到公网 IP，要想在外网访问家里的设备，就必须进行内网穿透。本视频介绍了一种使用 Cloudflare Tunnel 实现的免费方案，该方案配置相对简单，且没有节点和流量限制。

00:38
托管域名至Cloudflare
使用该方案的前提是拥有一个域名。登录 Cloudflare 并点击添加站点，输入域名后选择免费计划。接着，将 Cloudflare 分配的两个名称服务器复制，并在域名购买网站上删除原有的 NS 记录，替换为新的地址。

01:26
配置Zero Trust网络
在 Cloudflare 后台点击 Zero Trust，随意输入一个名称并选择免费计划。在没有添加付款方式的情况下，可以直接返回主页再次点击 Zero Trust 进入管理界面。

01:52
创建隧道并安装客户端
在 Network 的 Tunnels 页面添加一条新隧道并命名，选择对应系统（如 Windows 64 位）的安装包进行下载。随后在家庭服务器上以管理员身份运行命令提示符，粘贴页面提供的一键安装命令并执行。

03:00
配置隧道域名与协议
回到 Cloudflare 继续配置，输入一个子域名并选择之前托管的主域名。根据内网服务的实际情况选择协议（如 HTTP），并在 URL 中填写localhost加服务端口号。保存后，当隧道状态显示为 Healthy 时即代表配置成功。

03:51
分析方案的优缺点
该方案的优势在于免费且不限流量，但也存在两点不足。首先，由于 Cloudflare 是国外企业，国内连接可能存在网速慢或不稳定的情况；其次，对于 SSH、RDP、SMB 等非 HTTP 协议，需要在客户端进行繁琐的额外代理配置。因此，此方案更适合轻量级的 HTTP 服务。

04:49
申请并配置免费域名
如果不想购买域名，可以前往 ClouDNS 等网站注册账号并申请免费域名。创建免费区域后，将该域名添加至 Cloudflare 并获取其 NS 记录。最后，返回 ClouDNS 在域名的 DNS 记录中，为主域名和子域名分别添加指向 Cloudflare NS 服务器的记录。
