视频讲了什么

画面是 PyCharm 编辑器，作者先定义了两个带重复元素的列表：

array1 = [4, 5, 6, 1, 8, 9]
array2 = [2, 4, 5, 8, 2, 9]

随后在代码注释里列出三个步骤：① 定义两个列表；② 去重；③ 排序。关键操作是 set(array1 + array2)：先把两个列表拼接，再转成集合，利用集合元素不重复的特性自动去掉重复项。运行结果显示为 [2, 4, 5, 6, 8, 9] 这类去重后的结果。

需要补充的一点

集合本身是无序的，所以 set() 去重后元素的顺序并不保证稳定。视频里注释写了 “排序”，画面中也出现了 sorted(...) 的提示，说明作者是用 sorted() 把去重结果再排成有序列表 —— 这也是实际写代码时更稳妥的写法：sorted(set(array1 + array2))。

另外，set 去重只适用于元素可哈希的情况（数字、字符串、元组等），列表、字典这类不可哈希对象不能直接放进 set。

想继续看的话，可以聊聊 set 的 &、|、- 这几个集合运算在去重之外还能怎么用。
