这是博主技术爬爬虾的一期实操教程：用免费容器平台 Claw Cloud Run（网友叫它 “爪子云”）零成本部署 6 类 Docker 应用，中间穿插讲 Docker 基础概念。

核心玩法与前提

用 GitHub 账号登录 run.claw.cloud，注册满 180 天的账号每月送 5 美元额度，够跑 2—3 个小应用；区域建议选新加坡。
平台分两块：App Store（模板商店，一个模板对应一个镜像，一键部署）和 App Launcher（自定义填镜像、端口、环境变量、挂载卷）。
顺带科普：镜像 = 打包好的程序 + 依赖 + 文件系统；docker pull 拉镜像、docker run 起容器；-p 是端口映射，冒号前是宿主机端口、后是容器内端口，而爪子云只填容器内端口，外部端口自动分配。

六个实战项目

Lobe Chat：开源网页版 AI 客户端。接 DeepSeek API（与 OpenAI 格式兼容，地址填 v1 结尾那串，模型填 deepseek-chat 即 V3），设访问密码后部署，公网域名等了约 15 分钟生效。
Gemini 接入：在 Lobe Chat 设置里加 Gemini 2.5 Flash（每天 500 次免费请求），因容器在新加坡，可绕开谷歌地域限制在国内网页使用。
自定义域名：在 Cloudflare 加 CNAME 记录、关代理，回平台绑定，作者等了约 3 小时才生效，之后国内可直连。
n8n：开源 AI 工作流工具，类似 Coze/Dify，无环境变量直接部署，作者拖了个 “对话触发→DeepSeek→输出存文件” 的极简流程，说后面单独出视频讲。
Alist：网盘聚合工具。按官方 docker run 命令填镜像、端口、PUID/PGID/UMASK 三个权限变量和 1G 挂载卷；账号密码在日志里找（admin + 一串密码），再挂百度网盘（填刷新令牌），即可在线看片、下载。
数据库：建 PostgreSQL，新加坡节点申请公网域名提示 “范围已满”，换德国节点成功，用 DBeaver 连上建表。

评论区补充的现实问题：不少人反馈域名长期 pending、资源被 “薅秃”，有人称产品要下线、没端口了；也有经验说 CPU + 内存 + 存储的日费用合计别超 0.16 美元，否则 5 美元不够用，CPU 可少配、内存可多配。另外有说法称它基于 sealos 开发、每月 10G 流量。
