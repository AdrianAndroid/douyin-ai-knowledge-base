这是数码博主「技术爬爬虾」对华为 小艺 Work 的实测体验。作者的核心观点很明确：AI Agent 的竞争胜负不在能力上限，而在使用门槛—— 过去做图、做视频、做播客都要自己接第三方服务、配 API Key 和付费渠道，小艺 Work 把这些能力打包成开箱即用的 Skill，一个平台就能搞定。

实测的几项能力

教案批量生成：给一份课程表和一份教案模板，小艺 Work 自动调用 Word 技能，遇到疑问点会弹窗确认，最后交付完整 Word 文件；还能把整套流程封装成可复用的 Skill，下月只需上传新课表。
技能连接器：内置 21 个技能，加上自建的共 22 个。视频创作技能可把 PPT 前两页配图做成动态视频，生成前会先列出所需订阅点数，不用另配模型和付费渠道。
儿童绘本：同时调用图像创作和语音合成，先规划大纲、定角色基准图，再逐章画插图、配音，做出图文声俱全的《小马过河》HTML 绘本。
小艺播客：把 OpenAI 官方技术博文一键转成双人对话播客，可调语速；作者称做播客不消耗订阅积分。配合飞书连接器还能建定时任务，每天早八点自动生成并推送到手机。
鸿蒙开发陪练：专家团里的「鸿蒙启航新手陪练团」用大白话带小白搭环境、装 DevEco Studio、建工程、跑模拟器，主 Agent 会把任务分派给环境搭建向导、首个 App 陪练等子 Agent。
跨设备与云电脑：手机端小艺可远程查看电脑端进度、让电脑找文件发回来；电脑关机时可切到云电脑继续跑任务。

技术背景：作者转述小艺介绍，小艺 Work 由华为终端小艺团队联合 2012 实验室九问团队打造，底层用 openJiuwen 平台和蜂群智能体 WorkSwarm，与 openJiuwen 属不同产品线但架构一脉相承。

评论区补充：目前仅支持 Windows 和鸿蒙电脑，手机端集成在小艺 App 里；并非所有 Skill 免费，生图生视频收费，10 秒视频约消耗 30—40 点数；有用户提到标准版 199 元，也有人拿它和 WorkBuddy 比较，但没有定论。最高赞的「史上公务员老师最幸福的时代」属于玩梗反讽，不必当真。
