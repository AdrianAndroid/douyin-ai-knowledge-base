这是「技术爬爬虾」的 Hyper-V 虚拟机安装 Ubuntu 教程，核心思路是用虚拟机代替双系统或物理机安装，避开硬件差异导致的踩坑，作者称这种方式 “简单易上手、0 失败率”。

为什么选 Ubuntu 作者认为 Linux 发行版虽多，主流是 CentOS（红帽系）和 Ubuntu（Debian 系）两支；由于 CentOS 在 2024 年 6 月停止更新，他更推荐新手从 Ubuntu 起步。

操作主线

查系统版本：设置 → 系统 → 系统信息。专业版 / 旗舰版可直接用 Hyper-V；家庭版或未激活需用脚本强制开启，脚本要关注后私信或从公众号 “技术爬爬虾” 获取。
开启功能：搜索 “功能”→ 启动或关闭 Windows 功能 → 勾选 Hyper-V → 重启。
改存储位置：Hyper-V 管理器 → Hyper-V 设置，把虚拟硬盘和配置文件改到 D 盘，避免占用 C 盘。
快速创建：点 “快速创建”，系统选 22.04 长期支持版，等进度条走完即创建成功。
初始化：连接并启动，语言选简体中文、键盘选汉语拼音，用户名密码都填 techshrimp。
关键一步：配置完成后若出现登录界面，填什么都不管用，要 ** 切换到 “基本会话”** 再输密码，才能进入桌面。

评论区反馈的实操问题 有观众指出还需 Windows 7 以上系统；也有人遇到 “创建” 按钮点不动、怀疑 Ubuntu 版本不兼容，以及太卡、装驱动、登录要填邮件、桌面放大等问题，这些在评论里暂无明确解答。

先查系统信息判断版本，家庭版需脚本开启，再在 “启动或关闭 Windows 功能” 里勾选 Hyper-V 并重启。

在 Hyper-V 设置里把虚拟硬盘和配置文件路径改到 D 盘，避免拖累 C 盘空间。

点 “快速创建” 选 22.04 长期支持版，等待创建完成后连接、启动。

语言、键盘、账号设置完成后，若登录界面填密码无效，选择 “切换到基本会话” 再输入密码即可进桌面。

如果你卡在 “创建” 按钮点不动那一步，可以告诉我你的 Windows 版本和 Hyper-V 管理器里的具体提示，我帮你对一下原因。
