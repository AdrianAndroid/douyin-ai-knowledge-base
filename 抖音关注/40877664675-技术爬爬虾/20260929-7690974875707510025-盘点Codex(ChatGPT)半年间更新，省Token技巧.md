这是「技术爬爬虾」的一期 Codex 进阶汇总，核心是盘点 Codex 半年更新 + 4 个省 Token 技巧 + 新奇玩法。基础操作他之前那期（今年 4 月）已经讲过，这期只讲新东西。

最大变化：三合一桌面端 Codex 已和 ChatGPT 桌面端合并成同一个 APP，进去有三个模式：

Chat：对话问答，问问题、解释代码、查资料，不消耗订阅额，但默认读不了本地文件、不能操作电脑；
Work：通用办公，做调研、文档、表格、PPT，可以操作本地电脑；
Codex：软件开发向，改代码、跑命令、测试修 bug。比 Work 多了 Git 分支管理、代码变更审查、内置终端、项目文件树，左侧边栏也只显示工作对话。

作者实测 Work 和 Codex 功能高度相似，主要差在 UI 细节和代码相关功能。额度在头像处可查，有五小时和一周两个限额，任一用光就停用。

省 Token 的四个思路（视频重点讲了前两个）

先用 Chat 模式把方案聊透：Chat 不扣额度，可以把思考强度拉满做调研、出几万字方案文档，额度仍是 100%；敲定后切到 Codex 模式建项目执行，再用 @ 跨项目引用那段对话，省掉复制上下文，作者估计至少省一半 Token。新版还支持一个项目挂多个文件夹（如前端、后端分开）。
插件让 Chat 读写本地文件：在网页端装 Remote Desktop Commander，复制一键安装命令到终端执行、浏览器点 verify 配对，之后 Chat 模式就能直接读目录、review 未提交代码，全程不扣额度；重启电脑后重跑 npx 命令即可重新配对。GitHub 上还有 Codex with ChatGPT、Codex ChatGPTWeb 等同类项目。
用 Luna 小模型：价格比 DeepSeek V4.1 Flash 还低，适合定时任务、重复 Skill、浏览器自动化这类简单活。
视频后段还涉及把订阅额度接入自己项目、0 成本部署网站、给 Codex 接国产模型等玩法。

评论区补充了两点实用经验：省 Token 更要防返工，把大任务拆成可逐步验证的小目标、同一项目尽量复用会话以保住缓存；另外作者确认接 DeepSeek 只能用到基础功能，侧边栏很多功能没有。
