这是一个用 Python 校验用户输入 的编程教学短视频，作者是「技术爬爬虾」。核心讲的是：input() 拿到的永远是字符串，直接参与数值运算会出错，必须先校验再转换。

演示主线（按代码演进）

初始代码：balance = 945.55，然后 num = input("Deposit: ")，直接 balance += num—— 这里埋了坑。
修正类型：把加法改成 balance += float(num)，输入 55 时能正常跑通。
暴露问题：输入 abc 这类非数字时，程序直接抛 ValueError: could not convert string to float，崩溃退出。
最终方案：用 while True 循环包住输入，配合 if num.isnumeric(): 判断，合法才 float() 转换并 break；否则走 else 分支打印 Please input number，让用户重新输入。

关键知识点

input() 返回的是字符串，float() 转换失败会抛异常，所以不能裸转。
str.isnumeric() 只能挡住明显非数字，它不认小数点、负号，像 -5、3.14 会被判为不合法。想更严谨可以用 try/except ValueError，这也正好呼应评论区那条「直接 try」—— 用异常捕获代替预判，是更通用的写法。
