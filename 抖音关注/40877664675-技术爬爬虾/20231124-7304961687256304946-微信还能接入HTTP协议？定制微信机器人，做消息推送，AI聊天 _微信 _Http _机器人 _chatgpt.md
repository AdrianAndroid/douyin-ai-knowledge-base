这是「技术爬爬虾」的一期编程教程，核心是介绍开源项目 WechatFerry：把 Windows 版微信变成可以被 HTTP 接口调用的 “机器人”，从而实现收发消息、群管理、朋友圈操作，以及运维告警、办公自动化、接 ChatGPT 聊天等玩法。

原理与前提 作者强调，这个项目没有走传统的微信网页版，因为腾讯已逐步停止支持，新注册账号基本登不上网页版；它改为 Hook Windows 版微信客户端。所以它只能在 Windows 上跑，评论区有人问 Mac 微信能不能用，回复是 “不可以”。

操作流程（作者演示顺序）

装 Python（不熟的话他另有视频）；
下载并安装指定版本的微信客户端 3.9.2.23，只有这个版本可用，链接在项目主页的百度网盘；
扫码登录，作者特意 “叠甲”：建议用微信小号，自动化工具可能给账号带来风险，不要商用；
登录后务必禁止微信自动更新，弹窗时点 “忽略本次升级”；
打开 CMD，先更新 pip，再安装微信机器人 HTTP 客户端，然后一条命令启动；
用 Postman 测试：GET localhost:9999/contacts 拉取全部联系人（wxid 开头是好友，chatroom 结尾是群）；POST /text 发消息，body 用 JSON，填 msg 和 receiver（好友或群都行），实测成功发到自建群；
更多功能看 GitHub 上的接口清单文件。

实战例子：用 Python 故意造一个除零异常并捕获，把异常信息打包成 message，调 HTTP 接口发到开发者群，实现 “程序出错自动微信告警”。

评论区里，“是否替代 itchat” 的回复更像配合式互动，不算确证；“很容易被封” 只是个人经验，作者本人的说法是 “可能带来风险”，两者都别当成定论。真正确定的使用限制是：仅 Windows、仅 3.9.2.23 版本、需关闭自动更新。
