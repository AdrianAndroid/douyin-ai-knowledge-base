这是「技术爬爬虾」的一期实操教程：用字节跳动的免费 AI 编程工具 Trae 的新功能，从零做一个「你画我猜」网页游戏，由 AI 当裁判猜你画的是什么。

视频主线

装软件：演示用海外版 Trae（需海外网络环境，GitHub 登录），国内版除模型不同外功能一致，下载地址放在评论区置顶。
配 MCP：MCP 被作者比作「AI 的外挂工具箱」，让 AI 能调用外部工具。他先在 Trae 的 MCP 市场里添加 GitHub 服务，生成 Token 并授权仓库权限，然后让 AI 查询自己名下的仓库；接着再接入 Git 服务（需先装 uv 工具），把两个服务组合成「Git 专家」智能体，实测自动初始化仓库、推送到 GitHub，还让 AI 合并 feature 分支到 main 并解决冲突。
写规则（Rules）：Rules 相当于项目级系统提示词，写明项目是「你画我猜网页游戏」、技术栈和开发习惯。之后让 builder 智能体按规则拆解任务、生成 task.md 清单，再逐项开发，前端一次调用就生成了 16 个文件。
调试：前端画板能画但缺「让 AI 猜」的按钮，作者截图贴进 Trae，靠多模态能力补上；报错则手动粘贴控制台信息。进阶做法是接入 Browser Tools 这个 MCP（装浏览器插件 + 配置 + 执行命令三步），创建「浏览器专家」智能体，让 AI 直接读浏览器控制台报错，定位到前后端接口路径不匹配，再交给 builder 修复。
成果：前后端分别跑在 3000 和 5173 端口，画「a」被猜成蜜蜂、画房子被认出、画大象也猜对了，作者调侃「本来想画个蝴蝶的」。

核心看点：MCP 负责「让 AI 能动手」，Rules 负责「让 AI 懂项目」，Agent 负责「把工具打包成专家」，三者配合把开发流程串起来。视频里也如实暴露了 AI 会写错接口、需要反复贴报错修正的过程，不是一次成型。
