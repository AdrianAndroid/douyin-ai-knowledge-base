这是「技术爬爬虾」的一条 Python 编程技巧视频，主题是如何从文件名中取出 “主名”，也就是去掉扩展名后剩下的部分。视频用同一个例子演示了从 “手动切字符串” 到 “用标准库一行搞定” 的进阶过程。

演示对象：一个文件名列表，包含 info_3.txt、test.png、haha_364_on.jpg 三个文件。

三种写法，层层递进

split('.') 手动拆分：把 info_3.txt 按点切成 ['info_3', 'txt']，再取第 0 个元素得到 info_3。作者接着指出问题：文件名里如果带多个点（比如 haha_364_on.jpg），或者路径里有点，这种写法就容易出错，需要额外判断。
os.path.splitext：用 os.path.splitext(file)[0] 循环处理整个列表，输出 info_3、test、haha_364_on。这是传统做法，能正确处理 “只切最后一个扩展名”。
pathlib 的 Path(file).stem：视频最后用 from pathlib import Path，一行 Path(file).stem 得到同样结果。这是作者推荐的现代写法，更简洁、可读性更好，也是 Python 3 官方更鼓励的路径处理方式。

核心结论：处理文件名别用字符串 split 硬切，用 os.path.splitext 或 pathlib.Path().stem 更稳妥；新代码优先选 pathlib。

顺带一提，stem 只去掉最后一段扩展名，像 .tar.gz 这种双扩展名只会得到 xxx.tar，需要自己再处理。想继续了解 pathlib 里 name、suffix、parent 这些属性的区别吗？
