使用 GitHub Action
GitHub Action 是一款自动化流水线工具，通过编写脚本可自动完成代码测试、编译、部署等一系列 DevOps 操作。

核心概念：工作流（Workflow）由事件（Event）触发，包含多个并行运行的任务（Job），每个任务又包含顺序执行的步骤（Step）。
计费规则：公开仓库完全免费；私有仓库每月享有 2000 分钟免费时长及 500MB 存储空间。

使用 GitHub Package
GitHub Package 是 GitHub 提供的包管理仓库，支持 npm、Maven、Docker 等多种包管理工具，方便开发者推送和使用自己的软件包。 对于公开仓库，该功能完全免费；私有仓库则提供 500MB 的免费存储空间，且与 Actions 共享额度。

使用 Git LFS 管理大文件
为解决 Git 因频繁保存大文件快照而导致仓库臃肿的问题，Git LFS（大文件系统）将大文件存储在独立的远程服务器中，本地仅保留引用。 通过简单的命令即可在仓库中启用 LFS 并指定需要管理的文件类型，从而轻松推送超过 100MB 限制的大文件。不过需注意，LFS 免费额度仅提供 1GB 的存储空间。
