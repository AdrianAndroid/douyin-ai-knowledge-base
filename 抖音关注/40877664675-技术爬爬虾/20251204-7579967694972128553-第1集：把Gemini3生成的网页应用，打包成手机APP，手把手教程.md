这是「技术爬爬虾」的实操教程：把 Gemini3 生成的网页应用改造成手机 APP，分 PWA、安卓 APK、iPhone IPA 三条路线，全程用 AI 编程工具代写代码。

准备工作：在谷歌 AI Studio 的 build 里打开官方案例库，挑一个 3D 跑酷游戏，切到 Mobile 预览。发现手机没有上下左右键，于是让 Gemini 生成三个虚拟按键（左、右、跳跃），完成手机端适配。代码保存到 GitHub（项目名 RunnerMobile），在 index.html 底部补上 React 入口引用，再用 Netlify 选 GitHub 登录部署，环境变量里 Gemini API Key 随便填（纯前端项目不涉及 AI 功能）。

路线一：PWA。手机浏览器打开时有两个问题：虚拟键被挡、顶部有地址栏。用 vite-plugin-pwa 插件改造，在 public 目录放图标，让 Codex 改 vite 配置（应用名、全屏显示、主题色、图标）。推送后 Netlify 自动部署，手机再打开会弹出安装提示，装到桌面后全屏无地址栏、按键完整，飞行模式下也能用。原理是两个文件：manifest 定义应用身份，sw.js（service worker）负责拦截请求、缓存资源，实现离线与快速启动，都由插件自动生成。

路线二：安卓 APK。用 Capacitor 框架，从 PWA 那次提交前新建分支（避开 PWA 改动），依次安装 Capacitor、初始化、npm run build、npx cap sync、加安卓目录，再用 Android Studio 打开，模拟器验证正常后 Generate APK，数据线传到手机安装。

路线三：iPhone IPA。前提是必须有 Mac，Windows 做不了；装 Xcode 时务必勾选 iOS 开发环境，之后命令流程与安卓基本一致。

评论区补充了几点值得注意的：苹果禁止的是纯 webview 套壳上架，把网页源码打包进 IPA 则可行；这类低代码方案更适合个人自用，商用价值有限；也有人反馈照做后出现白板、黑屏，多与配置或网络环境有关。
