这条视频是技术博主「技术爬爬虾」的实操教程：用字节跳动的 AI 编程工具 Trae，在几分钟内写一个「今天吃什么」MCP Server，再把它接回 Trae 搭成菜谱推荐智能体。

前半段：cue 和 Tab 键 作者先演示 Trae 新上线的 cue（上下文理解引擎）。他只把函数参数从字符串改成 list，编辑器就自动预测出下一个要改的位置，提示按 Tab 跳转，再给出「删除 split 方法」的修改建议，一路按 Tab 就改完了。作者评价这是「AI 编程工具里最好用的 Tab 键」，并称这次更新还接入了 Doubao-Seed-1.6 模型。

后半段：手搓 MCP Server

下载国内版 Trae（作者说可免费用最新模型、不排队），手机号登录；
用 UV 做 Python 环境管理，uv init -p 3.13 初始化工程，uv add "mcp[cli]" 装官方 SDK；
复制 MCP 官方 Python SDK 的样例代码，用 Ctrl+U 打开 AI 对话，提示词是：按用户给的原料和就餐人数推荐菜，菜品数等于人数，三人以上必须有一个汤；
让 AI 改数据结构（type→category）、把传参改成列表，全程靠 Tab 采纳；再让 Trae 自动补上文档字符串（告诉 AI 这个工具干什么、怎么传参、何时调用）；
运行后拿到地址，在 MCP 配置里手动添加，传输协议从 sse 改成 Streamable HTTP，打上绿勾即成功；
新建智能体「今天吃什么管理员」，勾选这个 MCP 工具，输入「五种食材、3 个人」，AI 调用工具后输出两菜一汤。

作者也说明这只是小 Demo，食谱不多，可以自己加菜，也能发布到公网给朋友用（并推荐了「爬爬虾」另一期讲发布到公网的视频）。结尾他的观点是：编码只占软件开发不到 40% 的工作量，Trae 正从 AI coding 工具进化成 AI Development 综合平台。

评论区主要在拿它和 Cursor、Windsurf 对比：有人夸 Cursor 的 Tab 交互，自嘲成了「Tab 工程师」；也有人觉得 Trae 国内版只能用豆包、DeepSeek 等模型，体验一般，国际版配 Claude 4、GPT-4.1 更好。这些是网友个人体验，不是作者结论。
