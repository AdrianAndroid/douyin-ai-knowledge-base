这是「技术爬爬虾」的一期手把手建站教程：用 GitHub 的免费服务，把开源项目「抖音」部署成一个能轮播自己视频的仿抖音网站，再绑定自己的域名。

核心流程（作者实际演示的步骤）

选项目：GitHub 上一个叫「抖音」的开源项目，当时有 8000 多 star，用 Vue 技术栈模仿抖音移动端短视频效果，作者评价其体验接近原生 App。
Fork 并命名：把项目 fork 到自己名下，仓库名按 英文名.github.io 格式起，GitHub 会据此分配免费域名。
开启 Pages：在 Settings → Pages 把来源改成 GitHub Actions，再到 Actions 里启用工作流，选 deploy on GitHub Pages 手动运行。
看构建逻辑：工作流在 Ubuntu 虚拟机上依次检出代码、装 pnpm、设 Node 18、安装依赖、打包，再把产物上传并发布到 Pages。作者说这套模板基本可复用于任何前端项目。
换数据源：项目没有后端，数据是 src/assets/data 下的静态 JSON。作者打开自己抖音主页的 F12 网络请求，找到 post 请求里的 aweme_list，整理成同样的 JSON 列表替换进去；再把 url_list 里前两个疑似做了防盗链的地址删掉，只留 www.douyin.com 那条，否则浏览器里播不了。
绑自定义域名：在 Cloudflare 的 DNS 里加一条 CNAME，名称 douyin，目标填 GitHub 要求的地址（把用户名换成自己的），回 GitHub Pages 填入 douyin.tech-shrimp.com，等 DNS 检查通过。作者特意提醒不要勾选 Enforce HTTPS。

几个容易误解的点

这只是前端演示版：作者在评论里也承认，视频里是随手改的版本，没有后台，不能真正发布视频，要接完整发布流程还得改更多代码。
视频里穿插的 Vue 知识是科普性质：渐进式框架、响应式数据绑定、v-if / v-on:click 模板语法，以及 Vite 5 构建工具、Pinia 状态管理。
评论区问得多的两点：GitHub Pages 服务器在国外，不需要国内 ICP 备案；GitHub Actions 和 Pages 本身免费，不用充钱。
「拿这源码去非洲做当地抖音版」是评论区的夸张玩梗，不是可行性判断。

想继续的话，可以聊聊怎么把静态 JSON 换成真正能上传视频的后台方案，或者自定义域名那步的 DNS 记录具体怎么填。
