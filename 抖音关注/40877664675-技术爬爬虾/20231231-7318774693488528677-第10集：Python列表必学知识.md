这是「技术爬爬虾」的一条 Python 教学短视频，主题是用列表操作把指定元素移到列表最前面，全程在 PyCharm 里演示，代码写在 main.py。

演示的列表

python
bag = ["apple", "orange", "banana", "strawberry", "grape"]


核心三步

index = bag.index("banana")：先找到 "banana" 在列表中的位置。
item = bag.pop(index)：用 pop 按索引把它取出来，同时从原位置删除。
bag.insert(0, item)：再把它插到索引 0，也就是列表开头。

最后 print(bag) 输出 ['banana', 'apple', 'orange', 'strawberry', 'grape']，画面里还配了个点赞手势，表示运行成功。

值得注意的点

顺序不能反：必须先 pop 再 insert，否则索引会错位。
pop 会改变原列表，index 找不到元素时会直接报 ValueError，实际用的时候最好先判断一下。
这个 “取出再插回” 的思路，是 Python 里调整列表顺序最直观的写法；如果只是要排序，用 sort 或 sorted 更合适。

想接着看的话，可以聊聊 remove、del 和 pop 在删除元素时到底差在哪，或者列表去重、按条件筛选这类常见操作。
