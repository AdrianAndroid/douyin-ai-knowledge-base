这是「技术爬爬虾」的 OpenClaw 进阶教程，接续他此前播放量超 500 万的入门视频，主题是把 OpenClaw 从 “能聊天” 调到 “能干活”。全片按章节走：安装、记忆系统、搜索修复、skills、聊天工具接入。

安装与关键配置 以 Mac mini 为例，先装 Node.js，再用 npm 装 OpenClaw，跑 openclaw onboard 初始化。作者建议用国内厂商的 Coding Plan（以 MiniMax 为例）对接模型，因为按次数计费比按 Token 划算。装完第一件事是改配置：把 messaging 默认权限从 default 改成 full，否则它只能聊天、几乎不能调用工具。

记忆系统 在 ~/.openclaw/workspace 里，AGENTS.md 是工作规范（最值得读），IDENTITY.md/SOUL.md 是自我认知，USER.md 是对用户的认知，TOOLS.md 是工具知识，MEMORY.md 是长期记忆，memory 文件夹按天存短期记忆。行为不对就改这些文件纠正。

修复搜索 新装的 OpenClaw 原生搜索依赖 Brave API Key，会报 missing BRAVE API Key。作者的方案是从官方市场 ClawHub 装 Tavily Web Search（免费额度每月 1000 次），再装无需 Key 的 Multi Search Engine 作备选，并在 openclaw.json 关掉默认搜索、在 TOOLS.md 写提示词指定优先用 Tavily。

skills 三种来源 内置技能（如 apple-reminder，可同步到 iPhone 提醒事项）、ClawHub（1.6 万多个，鱼龙混杂，挑 star 高的，不建议用 findskills 自动安装，要人工审核）、GitHub 的 awesome-openclaw-skills（5000 多个，按行业分类）。演示了用 Summarize 技能总结 PDF 论文。

接入飞书 装飞书插件后跑 openclaw channels add，在飞书开放平台建企业自建应用，填 App Secret/ID，选 WebSocket 长连接、国内域名，群聊设为 disable，再批量导入权限、开启机器人、订阅 “接收消息” 事件、创建版本发布，手机端即可对话。视频后段还演示了微信接入与多 Agents（“机器人分身”）、心跳机制。
