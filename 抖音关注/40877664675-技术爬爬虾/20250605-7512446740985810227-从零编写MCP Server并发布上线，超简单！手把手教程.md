了解 MCP 运行原理
MCP（模型上下文协议）是 AI 大模型的标准化工具箱，作为中间层代替人类访问外部工具。它本质上是一段 Python 或 Node.js 程序，通过标准输入输出或 SSE 等协议与大模型进行消息交互，从而完成特定任务。

01:24
配置 Python 开发环境
以官方 Python SDK 为例，首先需要安装 UV 作为 Python 环境管理工具。通过 PowerShell 命令行安装 UV 后，使用 uv init 命令将新建文件夹初始化为 Python 工程，并添加 MCP SDK 依赖，最后在 VS Code 中打开该文件夹准备编写代码。

03:43
编写本地 MCP Server
在代码中导入 fastmcp 并初始化 MCP 对象，使用装饰器声明工具函数。必须为函数添加自然语言注释以告知大模型其功能，并严格定义参数与返回值的类型修饰符。最后，通过添加 mcp.run() 语句使程序成为可独立运行的程序。

05:45
本地测试 stdio 协议
在 Cherry Studio 等 AI 客户端中添加 MCP 服务器，协议选择 stdio，并填写 uv 命令及相关目录和文件名参数。保存后，使用大模型进行对话测试，验证客户端是否能够正确调用本地编写的 MCP 工具并获取结果。

07:11
本地测试 SSE 协议
将代码最后一行的运行协议改为 sse 并在 VS Code 中启动服务。回到 AI 客户端，将 MCP 服务器的类型改为 sse，并填入服务端监听的地址加 /sse 后缀。再次测试对话，确认客户端能够通过 SSE 协议远程调用本地服务端的方法。

10:48
发布 Server 到 PyPI
将项目初始化为 Python 包，修改代码并使用 uv build 命令进行打包。随后注册 PyPI 账号并完成双重身份验证，生成 API Token 后通过 uv publish 命令将包发布。其他人只需在客户端配置中使用 uvx 命令加上包名，即可自动下载并本地调用该 MCP Server。

14:02
部署 Server 到云服务器
另一种发布方式是将程序部署到拥有公网 IP 的云服务器上。在服务器中安装 UV 并配置虚拟环境，将修改为 SSE 协议且绑定了 0.0.0.0 的代码上传并启动。最后，在 AI 客户端中使用服务器的公网 IP 和端口配置 SSE 类型的 URL，即可实现远程的公网调用。

总结与场景扩展
