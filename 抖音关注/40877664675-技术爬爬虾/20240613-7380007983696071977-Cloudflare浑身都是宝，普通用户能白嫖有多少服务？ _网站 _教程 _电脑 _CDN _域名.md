这是「技术爬爬虾」做的一期盘点视频，主题是普通个人用户能从 Cloudflare 免费使用哪些服务。作者开头就强调：全片没有广告，也不涉及任何付费业务，只讲免费的部分。

Cloudflare 是一家提供 CDN、网络安全、DDoS 防御和域名服务的美国公司，全球约 20% 的互联网流量会经过它的网络代理，因此被网友戏称为 “大善人”“赛博活佛”。

视频按顺序盘点的免费服务：

DNS 解析：全球最大的 DNS 服务商，把域名托管过去就能免费添加任意类型的解析记录。
CDN 加速：打开 “小黄云” 代理后，静态资源（js、css、图片、视频）会从离访客最近的节点读取。作者也承认国内用免费版可能反而变慢，并推荐了一个能按联通、移动、电信、国外分别优选节点的开源项目。
SSL 证书与 HTTPS：开启代理后自动签发证书，还能把 HTTP 自动跳转到 HTTPS。
隐藏源站 IP 与 DDoS 防御：攻击者只能打到 CDN 节点；作者提到 Cloudflare 曾免费为客户挡下每秒 2600 万次的史上最大 DDoS 攻击。
Pages：静态网站托管，把 GitHub 仓库连上就能自动构建部署，自动分配域名。
Workers：无服务器计算，支持 JS、TS、Python，代码跑在全球边缘节点上，也就是 “边缘计算”。可做重定向、过滤、代理、内网穿透、缓存等，免费额度是每天 10 万次请求；还接入了 AI 模型调用能力。
R2：对象存储，每月 10GB 存储、1000 万次免费请求，额度比同类厂商高一个数量级。
Tunnel：没有公网 IP 也能做免费内网穿透，不限节点数、不限流量。
Turnstile：就是常见的 “人机验证” 页面，俗称 5 秒盾，一段代码即可防爬虫，不用拼图。
Images：通过 URL 规则做图片缩放、裁剪、格式转换、加水印和自动优化。
邮件路由：可建最多 200 个临时邮箱，配合 catch all 能把发到该域名的邮件全部转发到指定邮箱，相当于无限收件地址。
