这是科技博主 “技术爬爬虾” 的实测视频，核心围绕MiniMax M3展开，博主认为它是首个在开源模型里凑齐了 “强大 Agent 与代码能力、原生多模态能力、百万上下文” 这三块旗舰模型拼图的产品，全程不看榜单，用 5 个高难度案例横向对比了国内外多款主流大模型的真实表现。

测试在统一环境下完成：所有模型都接入同一个 Agent 框架 OpenCode，国内模型通过官网订阅接入，海外模型通过 OpenRouter 接入，保证对比公平。

小球 3D 迷宫运动测试：考验迷宫生成、物理碰撞、空间关系与镜头控制，MiniMax M3 是国产模型里表现最好的，场景清晰、按键控制和摄像机调整均正常，仅存在摄像头旋转 90 度时左右方向键反向的小问题；综合表现最优的是 GPT-5.5，Claude 系列、某 LM5.1、K2.6、Deepseek V4 Pro 等模型都出现了功能缺失或逻辑错误。
3D 怀表拆解动画测试：MiniMax M3 和 GPT-5.5 表现最佳，生成的表盘美观、零件拆解动画完整，达到了产品展示级效果，其余多数模型都出现了形态走样、动作逻辑错误的问题。
信息图转分步动画 HTML PPT 测试：依托 MiniMax M3 新增的原生多模态能力 —— 模型训练时就在文本和视觉混合数据上联合学习，没有外挂多模态方案的信息折损，它能精准识别图片内容，用和背景色相近的遮罩按讲解逻辑分步显示内容，效果优于其余参与测试的多模态模型。
视频关键帧截取测试：针对 Git 分区讲解视频的快节奏知识点，MiniMax M3 会先粗定位关键时间点，再在每个位置连续截多张图筛选最优帧，最终所有截图都卡在了线条刚画完的最佳时机，画面清晰无拖影，和 GPT-5.5 同为完成度最好的模型。
自制 Computer Use Skill 测试：MiniMax M3 仅凭提示词就用 mss 与 pyautogui 写出了可循环 “截图 - 思考 - 操作” 的电脑控制 Agent，完成了打开 Chrome 搜索信息、把项目上传到 GitHub 等精准操作，还能把该能力封装成可复用的 Skill；同时博主也提到搭载 M3 的国产 Codex 产品 “MiniMax Code” 桌面客户端，本身就内置了 Computer Use 功能，还支持连接手机操作。

博主总结，MiniMax M3 最适合需要多模态自动化工作流的开发者、团队 Agent 玩家，或是零代码基础但想尝试 Web 编码的内容创作者，目前它的 Token 费用约为一块多一百万 Token。评论区也有不同实测反馈：有用户认为它在国产模型里编程和 Debug 能力较强，也有观点觉得它和 Claude Opus 相比仍存在幻觉偏多的问题。
